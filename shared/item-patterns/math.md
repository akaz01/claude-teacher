# 수학 출제 패턴 참고 자료

assessment-items 스킬로 고등학교 수학 문항을 수능형으로 만들 때 참고하는 자료다. 평가원 문항을 옮기지 않고, 유형·구조·발문 틀·선지 설계 규칙만 정리했다.

> **이 문서의 수치는 관찰값이다.** 공개 시험지를 세어 낸 값이고 평가원 내부 규정이 아니다. 앞으로 달라질 수 있다. 학교 시험에는 학교 규정과 시·도 지침이 먼저다.

- 분석 대상: 2022~2027학년도 평가원 6월·9월 모의평가 12회와 2022~2026학년도 대학수학능력시험 5회, 모두 17회(수능 짝수형까지 22판). 2027 수능은 아직 시행되지 않았다(2026.11 예정). 기준값은 수능 홀수형과 모의평가다.
- 집계 범위: 번호별 배점, 번호별 과목 변화, 선지 배열, 정답 번호(1장, 2장 앞머리, 5-1장)는 17회 실측이다. 번호별 내용과 고난도 패턴은 2025~2027학년도 8회를 중심으로 적었고 다른 시기는 따로 밝혔다.
- 근거 자료: 한국교육과정평가원 수능 누리집 기출문제 게시판의 문제지와 정답표, 교육부 「2026학년도 대학수학능력시험 시행기본계획」 별첨(2025.3.25.).
- 출처 표기: `2026수능 15번`, `2027-09 기하 30번`처럼 쓴다(학년도-월).
- 정답률이나 난이도 수치는 공식 근거를 확보하지 못해 쓰지 않았다. 이 문서에서 "고난도"는 배점(4점)과 문항 번호, 조건 수로 판단한 것이다.
- 저작권: "이 문제지에 관한 저작권은 한국교육과정평가원에 있습니다." 문항, 그림, 수치를 그대로 쓰거나 일부만 바꿔 쓰지 않는다.

## 3. 고난도 문항의 구조 패턴 (공통 15·20~22, 선택 28~30)

### 패턴 A. 구간별로 정의한 함수 + 조건 상자 (공통 15·21)
- 구조: 최고차항의 계수나 상수항 같은 정보 일부만 준 다항함수 f를 놓고, 구간별 함수 g(x)를 정의한 뒤 "(가)", "(나)" 조건 상자를 준다.
- 조건은 미분가능, 극값 개수, 실근 개수, "모든 실수 a에 대하여 극한값이 존재" 같은 존재·개수 진술로 준다.
- 묻는 값은 조건을 만족하는 함수의 특정 함숫값이나 최댓값·최솟값이다.
- 출처: 2025-06 15번, 2025수능 15번, 2026-06 15번, 2026수능 15·21번, 2027-09 15번
- 핵심 장치
  - 분모가 0이 되는 점에서 극한이 존재하려면 분자도 0이어야 한다. 이 사실로 인수를 찾게 한다(2025수능 21번, 2026-09 13번, 2027-09 15번).
  - 정적분으로 정의한 함수의 극값 개수에서 도함수의 부호 변화를 추론하게 한다(2026수능 15번).
  - 조건을 만족하는 매개변수의 집합(예: "양수 t의 집합은 {t | t ≥ 상수}")을 주고 거꾸로 함수를 결정하게 한다(2027-09 15번).

### 패턴 B. 부등식으로 함수 범위 가두기 (공통 19·21)
- 모든 실수(또는 정수, 구간) x에서 "g(x) ≤ f(x) ≤ h(x)"가 성립하도록 해 접하는 조건을 끌어낸다.
- 출처: 2025-09 21번, 2026-09 21번, 2026수능 19번

### 패턴 C. 수열 귀납 추론 (공통 22)
- 22번 자리는 2025학년도부터다. 2022~2024에는 15번 9회 중 6회가 이 패턴이었고, 22번은 9회 모두 수학Ⅱ의 다항함수 추론이었다.
- 홀수·짝수, 부호, 크기에 따라 다음 항을 다르게 정하는 점화식을 준다. 예: "aₙ이 홀수이면 …, 짝수이면 …"
- 거기에 "|aₘ| = |aₘ₊₂|인 m의 최솟값은 3" 같은 사후 조건을 더해 가능한 첫째항을 모두 찾게 한다.
- 묻는 값은 "가능한 모든 a₁의 값의 합(곱)"이다.
- 출처: 2025-06 22번, 2025-09 22번, 2025수능 22번, 2027-06 22번
- 풀이 구조: 조건이 걸린 항에서 거꾸로 거슬러 올라가는 수형도 케이스 분류. 경우가 4~8가지 안에서 끝나도록 수치를 설계했다.

### 패턴 D. 지수·로그 곡선의 좌표 추론 (공통 10·12·22)
- 22번 자리는 2025학년도 이후의 모습이다.
- 두 곡선(지수와 로그, 밑이 다른 로그 등) 위의 점을 직선 y = x에 대한 대칭, 축에 평행한 직선, 중점·넓이 조건으로 묶는다.
- 묻는 값은 "a × b = q/p일 때 p + q"처럼 서로소 분수로 만든 단답이다.
- 출처: 2026-06 22번, 2026-09 22번, 2026수능 22번, 2027-09 22번

### 패턴 E. 풀이 과정 빈칸 채우기 (공통 20)
- "다음은 …의 값을 구하는 과정이다." 뒤에 상자로 풀이를 보여 주고 (가), (나), (다)에 알맞은 식이나 수를 쓰게 한다.
- 답은 "(가)에 알맞은 식을 f(n), (나)·(다)에 알맞은 수를 p, q라 할 때 p×q/f(12)" 같은 조합 값이다.
- 출처: 2026-06 20번(주기함수와 등차수열), 2026-09 20번(원에 내접하는 사각형), 2026수능 20번(Σ로 정의한 수열), 2027-06 20번(지수·로그 그래프 교점)
- 22수 15번, 24-9 20번으로 두 번 나온 뒤 2025학년도 3회에는 없고 2026-06부터 4회 연속 나왔다. 2027-09 20번은 삼각함수 그래프 문항이다.

## 5. 선지·조건 설계 규칙

1. **5지 수치 선지는 크기순 등차 배열**이 기본이다(예: 12, 14, 16, 18, 20 / 9/2, 11/2, …, 17/2). 값이 등차인 문항은 550문항 중 444문항(80.7%)이고 28번은 65%다. 로그나 근호가 들어가면 같은 꼴로 계수만 바꾼다(예: ln 항 계수를 1~5). 음수만 있거나 분자가 같은 분수이면 표기가 커지는 순서도 쓴다.
2. **오답 값은 흔한 실수 결과에서 나오게 한다.** 연속 조건 한쪽만 쓴 값, 극한에서 부호를 놓친 값, 케이스 하나를 빠뜨린 합 같은 것이다. 이렇게 하면 오답이 등차 배열 안에 자연스럽게 들어간다.
3. **조건 상자는 2개 이하**로 쓴다((가), (나)). 각 조건이 함수를 하나씩 좁히는 역할을 하고, 군더더기 조건은 없다. 2025학년도 이후의 모습이고, 2022~2024에는 3개 조건이 13문항 있었다. 조건은 길이 순이 아니라 풀이 순서로 놓는다.
4. **정보 숨기기**: 최고차항의 계수, f(0), f′(a) 중 일부만 주고 나머지는 조건에서 끌어내게 한다.
5. **답이 하나로 정해지는지 확인하는 단서**를 둔다. "(단, g(−1) ≠ −(7/2)g(1))"처럼 예외 경우를 막는 단서를 붙인다(2026수능 21번).
6. **단답형 답 범위**: 자연수 세 자리 이하. 분수 답은 서로소 처리, 무리수 답은 제곱하거나 계수를 곱해 정수로 만든다.
7. **합답형 <보기>**는 ㄱ 쉬움(대입), ㄴ 중간, ㄷ 일반화 순서로 둔다. 선지는 개수 순, 같은 개수는 사전 순이다(11/11). 가장 흔한 세트는 ㄱ / ㄱ,ㄴ / ㄱ,ㄷ / ㄴ,ㄷ / ㄱ,ㄴ,ㄷ(7/11)다. 세 보기가 모두 든 조합은 8/11문항의 선지에 있고 4/11문항에서 정답이다.

### 학교 시험에 옮길 때

- 수 선지는 크기 순으로 놓는다. 문장 길이 규칙을 수에 쓰지 않는다.

- 5지 뒤에 단답을 둘 때 단답을 다시 쉬운 문항부터 시작한다.
- 과목이나 단원을 번갈아 놓는다. 학교 시험은 범위가 좁으므로 단원 단위로 쓴다.
- 2단 시험지에서 짧은 수 선지는 한 줄에 5개, 넓은 선지는 3개와 2개로 나눈다.

## 6. 새로 쓴 짧은 예시 (원 문항과 무관, 정답 확인함)

**예시 1 — 수열 귀납 (패턴 C 축소형, 단답 3점급)**
수열 {aₙ}은 a₁ = 5이고, 모든 자연수 n에 대하여 aₙ이 홀수이면 aₙ₊₁ = aₙ + 3, 짝수이면 aₙ₊₁ = aₙ/2이다. a₁ + a₂ + … + a₁₀의 값을 구하시오.
- 정답 33 (5, 8, 4, 2, 1, 4, 2, 1, 4, 2)

**예시 2 — 구간별 함수의 미분가능 (패턴 A 축소형, 5지 4점급)**
함수 f(x) = x² − 4x (x < a), 2x + k (x ≥ a)가 실수 전체의 집합에서 미분가능할 때, f(4)의 값은? (단, a, k는 상수이다.)
① −3 ② −2 ③ −1 ④ 0 ⑤ 1
- 정답 ③. 미분계수가 같아야 하므로 2a − 4 = 2에서 a = 3이다. 연속이려면 −3 = 6 + k이므로 k = −9이고, f(4) = 8 − 9 = −1이다.

**예시 3 — 빈칸 추론 (패턴 E)**

n = k일 때 성립한다고 가정하면 1 + 3 + … + (2k − 1) + ( (가) ) = k² + ( (가) ) = ( (나) )이다.
(가)에 알맞은 식을 f(k), (나)에 알맞은 식을 g(k)라 할 때 f(3) + g(3)의 값은?
- 정답 23 (f(k) = 2k + 1, g(k) = (k + 1)²이므로 7 + 16)

**예시 4 — 중복조합 (확률과 통계 3점급)**

**예시 5 — 등비급수 (미적분 3점급)**
급수 Σ((x − 1)/3)ⁿ이 수렴하도록 하는 정수 x의 개수는? (n = 1부터 ∞까지)
- 정답 5 (|x − 1| < 3이므로 x = −1, 0, 1, 2, 3)

## 7. 학교 정기시험(내신)으로 옮길 때 주의점

1. **교육과정 확인이 먼저다.** `curriculum-transition.md`로 학년을 판별한다.
   - 2026학년도 고3은 2015 개정이다(수학Ⅰ, 수학Ⅱ, 확률과 통계, 미적분, 기하). 이 자료의 평가원 문항도 모두 2015 개정 과목 기준이다.
   - 2026학년도 고1·고2와 2027학년도부터의 모든 고등학생은 2022 개정이다(공통수학1·2, 대수, 미적분Ⅰ, 확률과 통계, 미적분Ⅱ, 기하 등). 단원 이름과 내용 배치가 2015 개정과 다르므로, 성취기준은 `curriculum/2022/high/수학_*.md`에서 찾는다.
2. **2028학년도 수능부터 체계가 바뀐다.** 평가원 "2028학년도 예시문항"(2025.4.15. 게시) 수학 문제지에는 선택과목 구분 없이 30문항이 실려 있다. 문항 안에 중복순열, 모비율 같은 확률과 통계 내용이 함께 들어 있다. 이 문서의 공통/선택 번호 배치(1~22 / 23~30)는 2027학년도 수능까지에만 해당한다.
3. **학교 시험은 수업한 범위 안에서만** 낸다. 수능처럼 Ⅰ·Ⅱ를 섞거나 이전 과목 개념을 통합하는 것은 그 학교 시험 범위가 허용할 때만 한다.
4. **배점과 문항 수는 학교 학업성적관리규정을 따른다.** 2·3·4점 체계나 단답형 30%는 수능 규칙일 뿐이다. 내신은 서답형·서술형 비율과 소수 배점을 교사에게 확인한다.
5. **고난도 패턴은 축소해서 쓴다.** 조건 상자 하나, 케이스 2~3개 수준으로 줄이고 서술형으로 바꾸면 풀이 과정에 부분 점수를 줄 수 있다. 패턴 E(빈칸 추론)는 서술형 채점 기준으로 바꾸기 쉽다.
6. **수능 문항을 일부만 바꿔 쓰지 않는다**(저작권, 출제 보안). 이 문서의 패턴은 구조 참고용이다. 수치, 함수, 맥락은 새로 만들고 반드시 직접 풀어 답이 하나인지 확인한다(item-quality Q1·Q2).
7. **단답형 답 형식**: 학교 OMR이나 답지 칸에 맞춰 답의 형태(정수, 기약분수 허용 여부)를 정답지에 적는다.

## 8. 확인 못 한 것

- 공식 정답률, 오답률, 문항 난이도 지표는 찾지 못했다. 그래서 "킬러·준킬러"라는 말은 배점·위치·조건 수에 기댄 판단이다.
- 단원 분류는 텍스트 추출본(수식이 빠짐)의 문두로 했고, 그림으로 직접 확인한 것은 일부 쪽뿐이다(2026수능 6~8쪽, 2025수능 8쪽, 2027-09 6쪽, 2026-06·2027-09 5번, 2025수능·2026-06 20번). 그래서 일부 문항의 세부 내용(예: 2025-06·2025-09 9번의 계산 종류)은 근사로 적었다.
- 선택과목 문항은 텍스트로만 분류했다. 각 회차 28~30번의 그림은 보지 않았다.
- 6월 모의평가의 과목별 출제 범위 공지 원문은 확인하지 않았다.
- 판별 단계 수, 오답 설계, 행동 영역은 17회로 재지 못했다. 2022~2025·2027학년도 시험 시간의 근거 문서는 열지 않았다.
