# 평가 문항 품질 체크리스트

문항을 출제한 뒤 문항마다 이 항목을 점검한다. 학교 규정과 시·도 지침이 이 표의 값보다 먼저다. 평가원 수치는 공개 시험지를 세어 낸 관찰값이고 내부 규정이 아니다.

## 공통

| # | 항목 | 확인 내용 |
|---|---|---|
| Q1 | 정답 | 정답이 확실히 맞는가. 직접 풀어서 확인한다 |
| Q2 | 복수 정답 | 정답 외에 맞다고 볼 수 있는 선지가 없는가 |
| Q3 | 정답 단서 | 문두나 다른 문항이 정답이나 정답의 근거를 알려 주지 않는가. 문두 없이 답지만 읽어도 답이 나오지 않는가. 다른 문항과의 대조는 "시험지 전체"의 문항 간 단서에서 모든 쌍으로 한다 |
| Q4 | 성취기준 | 문항이 겨냥하는 성취기준이 분명한가 |
| Q5 | 범위 | 수업에서 다룬 내용 안에서 출제했는가. 선행 내용이 없는가 |
| Q6 | 문장 | 문두가 명확한가. 이중 부정이 없는가. 문항에 필요한 조건이 모두 있고, 조건을 대입하면 답이 성립하는가. 부정형 문두("옳지 않은 것은")는 굵게 표시했는가. 긍정문으로 바꿀 수 있지 않은가. 자료 상자가 문두 아래에 있으면 "다음 ~", 앞에 놓인 공통 지문이면 "윗글"이라 했는가("위 규정"처럼 아래 자료를 '위'로 가리키지 않는다) |
| Q7 | 편향 | 성별, 지역, 가정 환경 등에 대한 고정관념이 없는가 |
| Q8 | 사실 | 지문과 자료의 사실관계가 정확한가 |
| Q9 | 재사용 | 교과서 문장을 그대로 쓰지 않았는가. 시판 참고서 전재나 일부 변경, 전년도 문항 재출제가 아닌가 (Claude가 확인할 수 없는 부분은 사람 확인 목록으로) |
| Q10 | 자료 | 자료가 평가 의도에 비해 길지 않고 답과 이어지는가 |
| Q11 | 행동 영역 | 문항정보표의 행동 영역이 학교 양식(없으면 교과별 기본 목록)의 말인가. 그 문항이 실제로 요구하는 일과 성취기준 동사에 맞는가 (예: 성취기준이 "추론할 수 있다"인데 용어 뜻만 묻는 문항을 '추리'로 적지 않았는가). 난이도 표기가 학교 양식의 말(상/중/하 등)인가 |
| Q12 | 자료 | 문항에 자료(가상 사료, 대화, 표·그래프, 사례, 그림, 지문, 상황·식)가 있고, 자료를 읽어야 풀리는가. 문두와 선지만으로 풀리지 않는가. <보기> 문항은 <보기> 앞에 해석할 자료가 있는가 |
| Q13 | 이름 맞히기 | 선지가 인물·사건·용어 이름만 늘어놓아 기억만으로 고르는 문항이 아닌가. 대상의 이름을 가리고 단서로 알아낸 뒤 그 대상의 다른 사실·영향·적용을 고르게 했는가 |
| Q14 | 밑줄 범위 | 문두 "밑줄 친 '○○'"의 따옴표 안 말과 본문 밑줄 범위가 글자 그대로 같은가 (수능처럼: '사건'이면 '사건'에만, '이 조약'이면 '이 조약' 전체에) |

## 선택형

**선지 순서**
- 위에서부터 먼저 맞는 근거를 따랐는가: 표지와 지문 순서 → 시간, 크기, 풀이 순서 → 단독, 비교, 공통·종합 → 근거가 없으면 짧은 것부터
- 길이는 글자 수가 아니라 인쇄된 폭으로 보았는가 (어림은 한글 1, 공백·숫자·문장 부호 0.5. 수식과 외국어는 보이는 폭)
- 길이 규칙은 순서 근거가 없는 문장 선지에만 썼는가. <보기> ㄱㄴㄷㄹ, (가)(나)(다)(라) 자료, 조건 상자를 길이로 다시 놓지 않았는가
- 수는 크기 순, 연도와 시기는 시간 순인가 (음수만 있거나 분자가 같은 분수이면 표기 순도 된다)
- 합답형 조합은 개수 순, 같은 개수는 사전 순인가
- 표 선지는 앞 칸이 같은 것끼리 붙였는가

**선지 품질**
- 선지 형식이 비슷한가 (정답만 유독 길거나 자세하지 않은가. 정답과 오답의 인쇄 폭이 비슷한가)
- "모두 옳다", "모두 틀리다"를 문장 선지에 쓰지 않았는가 (합답형의 ㄱ, ㄴ, ㄷ 조합은 쓸 수 있다)
- 답지끼리 겹치지 않는가. 한 답지가 맞으면 다른 답지도 맞게 되는 관계가 없는가
- 답지가 발문과 문법, 의미 모두 호응하는가
- 오답마다 틀린 까닭을 한 줄로 쓸 수 있는가. 관점에 따라 정답이 되지 않는가
- 오답이 그럴듯한가. 지나치게 낯선 답지가 없는가. 상식만으로 지워지는 오답 대신 다른 시기·다른 대상의 실제 사실로 헷갈리게 했는가
- 오답 셋 이상이 한 대상(같은 사건·같은 개념)을 설명해 정답만 홀로 다른 대상이 되지 않았는가
- 같은 오답 진술(예: "국제 연맹의 승인을 받았다")을 여러 문항에 되풀이하지 않았는가. 되풀이되면 "그 말은 늘 틀린다"는 요령이 생긴다
- 선지 짜임만으로 답이 나오지 않는가: 합답형에서 한 기호(ㄱ, ㉠)가 정답 선지에만 들어 있지 않은가. 여러 칸 선지에서 칸마다 가장 많이 나온 값만 고르면 정답이 되지 않는가
- 보기를 옮긴 뒤에도 정답 조합이 선지에 있는가

## 서술형·논술형

**문항**
- 무엇을 얼마나 써야 하는지 조건(분량, 포함 요소)이 명확한가
- 낱말 하나로 끝나는 문항을 서술형이라고 부르지 않았는가
- 범위가 지나치게 넓지 않은가
- 조건이 정답을 알려 주지 않는가

**채점표**
- 평가 요소 → 채점 요소 → 배점 → 수행 수준의 층이 있는가
- 조건이 모두 채점 요소에 있는가
- 예시 답안을 먼저 썼고, 드러난 허용 답을 인정 범위에 적었는가. 예시 답안이 채점 기준을 모두 충족하는가
- 부분 점수 기준이 있는가
- 수행 수준 칸끼리 겹치지 않고 어떤 답이든 들어갈 칸이 있는가. 같은 사유를 두 칸에 쓰지 않았는가
- 부사만 바꾸지 않고 빠진 내용으로 갈랐는가 (`performance-levels.md`의 축을 쓴다)
- 둘 중 고르는 판단의 결론만으로 점수를 주지 않는가
- 학생을 판단하는 문장이 없는가
- 채점 시 유의점(부분 인정, 다른 풀이 인정, 성취기준 밖 요소 제외)과 피드백 시 유의점이 있는가

## 시험지 전체

문항을 모두 쓴 뒤 시험지 전체를 놓고 점검한다. 고치면 정답이 움직이므로 모든 항목이 맞을 때까지 다시 확인한다.

| 항목 | 확인 방법 |
|---|---|
| 정답 번호 분포 | 선택형만 센다. 문항 수와 상관없이 번호별 정답 수 차이가 1을 넘지 않는가 (5지선다 20문항이면 번호마다 4개, 4지선다 20문항이면 5개). 같은 번호 4연속이 없는가 |
| 같은 번호 연속 | 4연속이 없어야 한다. 3연속은 되도록 피하되 내용 순서를 깨면서까지 막지 않는다 (주의로 보고) |
| 정답 번호 되풀이 | 정답 번호가 같은 순서로 되풀이되지 않는가(예: ③⑤②④가 두 번). 세 개 이상 같은 순서가 되풀이되면 선지 자리를 바꾼다. 출제자는 이것을 자주 놓치므로 `fill_exam.py`의 "같은 순서로 되풀이됨" 알림(네 개 이상)을 믿고 고친다 |
| 정답 자리 옮기기 | 표지, 값, 풀이 순서를 깨지 않았는가. 순서 근거가 없고 폭이 같은 선지 맞바꾸기 → 합답형 세트 바꾸기 → 오답 값 다시 정하기 → 문장 오답 고쳐 쓰기 순으로 했는가 |
| 문항 간 단서 (가장 중요) | **모든 문항 쌍을 대조한다.** 그다음 정답을 가린 채 다른 문항만 읽고 각 문항의 답을 알아낼 수 있는지 따로 시험한다(가능하면 출제하지 않은 검토자). 문항마다 "정답 / 정답의 근거가 되는 사실"을 한 줄씩 적는다 (서술형은 하위 문항마다 예시 답안의 핵심 근거). 그 줄을 다른 모든 문항의 문두, 자료, <보기>의 각 진술, 선지, 서답형·서술형 문제와 하나씩 견준다 (n문항이면 n×(n-1)번). <보기>의 옳은 진술과 정답 선지는 사실을 그대로 알려 주므로 빠뜨리지 않는다. 다른 문항의 정답이나 근거를 알려 주거나 좁혀 주면 한쪽을 고치고, 고친 문항으로 다시 견준다 |
| 정답 일치 | 자리를 옮긴 문항의 정답이 문제지 표시, 정답표, 해설, 문항정보표에서 같은가 |
| 배점 합 | 배점 합이 총점과 같고, 문제지와 문항정보표의 배점이 같은가 |
| 고배점 분산 (주의) | 고배점이 한 쪽에 몰리지 않았는가. 수학처럼 쉬운 문항에서 어려운 문항으로 놓는 시험은 예외다. 교사가 고배점 기준을 말하지 않으면 판정하지 않는다 |
| 세트 고배점 | 지문 세트마다 고배점이 1개이고 세트 끝이나 끝 앞에 있는가 |
| 정렬·배치 | `references/exam-layout.md` 6절 점검표대로인가: 선지 배치를 가장 긴 선지로 골랐는가(수·기호는 한 줄 5칸, 짧은 낱말과 합답형은 3+2, 문장은 한 줄에 하나, 국어는 늘 한 줄에 하나). 표지(갑:, (가)) 문단, 출처 줄, 빈칸 길이, 그림 설명 자리가 기준대로인가. 도구의 넘침 알림이 남지 않았는가 |
| 쪽·단 넘김 | 한 문항이 쪽이나 단을 넘지 않는가. 지문은 넘어가도 된다. 파일만으로 확인하지 못하므로 한글에서 확인해 달라고 알린다 |
| 가장 긴 선지 | 문장 선지 문항 가운데 정답이 가장 긴 선지인 비율이 20% 안팎인가. 문항이 적으면 1/3을 넘지 않게 본다 |
| 서·논술형 비율 | 교사가 준 값과 분모(이번 시험 만점, 학기 성적)로 맞는가. 단답형을 넣어 계산하지 않았는가 |
| 자료 형식 | 사료·글, 대화, 표·그래프, 연표·카드, 그림이 한 형식에 몰리지 않았는가. 인물 클립아트 대화 장면을 쓰지 않고 대화는 자료 상자 글(갑: …)로 썼는가 |
| 수준 분포 | 한 수준에 치우치지 않고 낮은 수준을 판별하는 문항이 있는가 |
| 부정형 비중 | 비중이 높지 않고 3연속을 넘지 않는가 |
| 분량 | 시험 시간 안에 풀 수 있는가. 어림값이라고 밝히고 빠듯하면 교사가 직접 풀어 확인하게 한다 |

## 사람 확인 목록

정기시험이면 답변 끝에 적는다. Claude가 확인할 수 없는 일이다.

- 시험 범위를 학급마다 같게 안내했는가
- 지도교사 모두가 가르친 내용인가
- 공동 출제와 검토를 했는가
- 자녀 재학 학년의 출제·검토·채점에서 빠졌는가
- 시판 참고서, 전년도 문항과 겹치지 않는가
- 서·논술형 공동 채점과 표본 가채점 계획이 있는가
- 학교 평가 보안 규정에 맞게 파일을 처리했는가
- 문항정보표와 원안지를 학교 규정대로 보관하도록 넘겼는가
