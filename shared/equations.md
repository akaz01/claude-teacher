# 한글 수식 쓰는 법 (`{{ }}`)

학습지, 문항, 지도안 어느 글에서나 `{{ }}`로 감싼 식은 한글 수식으로 들어간다. 안쪽은 LaTeX가 아니라 **한글 수식 문법**이다. 아래 식은 모두 한글 2024에서 PDF로 바꿔 눈으로 확인했다.

## 규칙

- `{{ }}` 안에는 **식만** 쓴다. 한글이 섞이면(`{{x=1일 때}}`) 수식이 되지 않고 글자로 남는다. 설명은 밖에 쓴다: `x=1일 때 {{x+2}}`.
- 한 줄 안에서 쓴다. 줄바꿈은 빈칸으로 바뀐다.
- `\frac`, `\sqrt`, `\leq` 같은 LaTeX는 쓰지 않는다. 생성기가 `\`를 만나면 경고한다.
- 지수와 아래첨자는 `x^2`, `a_n`처럼 한 글자(숫자, 변수, 그리스 문자 이름)면 그냥 쓴다. 생성기가 `x^{2}`로 묶어 `x^2+1`이 `x^(2+1)`이 되는 일을 막는다. 두 글자 이상은 직접 묶는다: `x^{n+1}`, `a_{n+1}`, `2^{10}`.
- 분수 밖 식은 `over` 앞뒤를 **중괄호로 묶는다**: `{-b +- sqrt{b^2-4ac}} over {2a}`. 묶지 않으면 `over`는 바로 앞 낱말만 분자로 삼는다.
- 숫자/숫자는 저절로 분수가 된다: `{{2/3}}`, `{{0.5/2}}`, 대분수 `{{1 7/12}}`. 날짜(`2024/12/25`)는 분수가 아니다.
- 수식은 둘러싼 글자의 색과 굵기를 따른다. 교사용 답이나 어두운 머리칸 안에서도 그 칸 모양대로 나온다.
- 긴 식은 칸이 좁으면 잘린다. 수식이 든 칸은 넓게 잡고, 식이 길면 둘로 나눈다. 생성기가 칸보다 긴 식을 경고한다.

## 자주 쓰는 식

| 쓰고 싶은 것 | 입력 | 모양 |
|---|---|---|
| 분수 | `{a+b} over {c}` | a+b 위, c 아래 |
| 제곱, 지수 | `x^2`, `2^{10}`, `e^-x` | x², 2¹⁰, e⁻ˣ |
| 아래첨자 | `a_n`, `a_{n+1}` | aₙ, aₙ₊₁ |
| 제곱근 | `sqrt{2}`, `sqrt{x+1}` | √2, √(x+1) |
| 세제곱근 | `root 3 of 8` | ∛8 |
| 극한 | `lim_{x->1} f(x)` | x→1일 때 f(x)의 극한 |
| 정적분 | `int_{0}^{2} x dx` | 0에서 2까지 적분 |
| 합 | `sum_{k=1}^{n} k` | 시그마 |
| 무한대 | `(-inf, 0)` | (−∞, 0) |
| 부등호 | `LEQ`, `GEQ`, `<=`, `>=` | ≤, ≥ |
| 같지 않다, 플마 | `a != b`, `a +- b` | a≠b, a±b |
| 곱하기, 나누기 | `3 times 4`, `8 div 2` | 3×4, 8÷2 |
| 그리스 문자 | `pi`, `theta`, `alpha` | π, θ, α (대문자 이름은 대문자) |
| 각, 삼각형 | `angle ABC`, `triangle ABC` | ∠ABC, △ABC |
| 선분 위 막대, 벡터 | `BAR{AB}`, `vec{v}` | AB 위 선, v 위 화살표 |
| 굵게 | `bold {x=2}` | 굵은 x=2 (색·굵기는 보통 칸 모양이 대신 정한다) |

## 이렇게 쓰면 안 된다

| 틀린 입력 | 까닭 | 바른 입력 |
|---|---|---|
| `{{\frac{1}{2}}}` | LaTeX는 뭉개진다 | `{{1/2}}` |
| `{{x=1일 때}}` | 한글이 있으면 글자로 남는다 | `x=1일 때 {{x+2}}` |
| `{{-b +- sqrt{b^2-4ac} over {2a}}}` | 분자가 `sqrt{...}`만 잡힌다 | `{{ {-b +- sqrt{b^2-4ac}} over {2a} }}` |
