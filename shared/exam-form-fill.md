# 학교 시험지 양식 채우기

문항 출제 스킬이 학교 시험지(원안지) hwpx 양식에 문항을 채울 때 쓴다. 일반 양식 채우기의 원칙(`references/form-fill.md`)을 함께 따른다.

## 시험지 양식 채우기

도구는 `scripts/fill_exam.py`다. 양식의 문항을 틀로 삼아 **같은 유형의 틀을 복제하고 글자만 바꾼다.** 문항 수가 양식과 달라도 된다. 머리 표, 유의사항, 단 편집, 꼬리 상자, 문단·글자 모양, 표 크기와 테두리는 양식을 따른다. 옛 문항의 글, 정답 표시, 그림, 미리 보기는 결과 파일에 남지 않는다.

1. 유형 읽기: `python scripts/fill_exam.py --inspect 양식.hwpx`로 단 수, 문항별 유형, 유형별 틀의 개수, 정답 표시 방식, 머리와 꼬리의 번호를 본다. 문항 글은 보여 주지 않는다.
2. 출제: 문항 유형을 양식에 있는 틀에 맞춰 쓴다. 양식에 없는 유형이 필요하면 쓰기 전에 교사에게 알린다.
3. `지시.json` 쓰기. 머리 표의 교과, 일시, 문항 수, 배점, 쪽 수는 `fills`로 고친다. 쓰는 법은 `references/form-fill.md` 3절과 같다. 칸에 문단이 여럿이면 `table`은 첫 문단만 남기므로 `find`로 글만 바꾼다.
4. 실행: 원안지와 학생용을 따로 만든다.
   - `python scripts/fill_exam.py 양식.hwpx 지시.json 원안지.hwpx`
   - `python scripts/fill_exam.py 양식.hwpx 지시.json 문제지.hwpx --student`
5. 실패하면 파일이 만들어지지 않는다. 문제가 있는 문항을 모두 번호와 까닭으로 알려 주므로 지시를 고쳐 다시 실행한다.
6. 출력의 "참고"를 읽는다. 가장 가까운 틀을 쓴 문항, 칸보다 긴 선택지, 머리에 적힌 문항 수·총점과 지시가 다른 곳을 알려 준다. 고친 뒤 다시 만들거나 답변에 적는다.
7. 답변에 알린다: "양식의 틀을 복제해 채웠습니다. 쪽과 단이 나뉘는 자리, 총 쪽 수, 머리 표의 값을 한글에서 확인해 주세요."

```json
{"fills": [
  {"find": "7면", "replace": "6면"},
  {"table": 1, "row": 3, "col": 3, "text": "한국사"}
],
"items": [
  {"type": "passage", "count": 2, "lead": "다음 글을 읽고 물음에 답하시오.",
   "paragraphs": [{"label": "(가)", "text": "지문"}, {"label": "(나)", "text": "지문"}]},
  {"type": "short_table", "stem": "문제", "points": 3.2, "choices": ["가", "나", "다", "라", "마"], "answer": 2},
  {"type": "combo_table", "stem": "문제", "points": 3, "bogi": ["첫째 글", "둘째 글", "셋째 글"],
   "choices": ["ㄱ, ㄴ", "ㄱ, ㄷ", "ㄴ, ㄷ", "ㄴ, ㄹ", "ㄷ, ㄹ"], "answer": 3},
  {"type": "grid_table", "stem": "문제", "points": 4, "head": ["ⓐ", "ⓑ", "ⓒ"],
   "rows": [["가", "나", "다"], ["가", "나", "라"], ["가", "라", "다"], ["나", "나", "다"], ["나", "라", "다"]], "answer": 4},
  {"type": "paragraphs", "stem": "**옳지 않은** 것은?", "points": 3, "box": "자료 글",
   "choices": ["긴 문장", "긴 문장", "긴 문장", "긴 문장", "긴 문장"], "answer": 5},
  {"type": "written", "stem": "서답형 문제", "points": 5}
]}
```

| `type` | 양식의 틀 | 쓰는 항목 |
|---|---|---|
| `short_table` | 선택지를 한 칸씩 넣는 한 줄 표 | `choices`, `answer` |
| `combo_table` | 합답형 선택지 표 (①ㄱ, ㄴ 등) | `choices`, `answer` |
| `grid_table` | 머리행과 ①~⑤ 행이 있는 표 | `head`, `rows`, `answer` |
| `paragraphs` | 일반 문단 선택지 | `choices`, `answer` |
| `written` | 선택지 없는 서답형 문항 | `stem`, `points` |
| `passage` | `[1~3]`으로 시작하는 공통 지문 | `count`(뒤따르는 문항 수), `lead`, `paragraphs` |

- 번호와 `[1~3]`의 범위는 도구가 다시 매긴다. `stem`과 `choices`에 번호와 ①를 쓰지 않는다.
- `answer`는 정답 선택지의 번호(1부터)다. 양식에 표시 방식이 있으면 원안지에 같은 방식으로 정답만 표시한다. 양식의 형광펜 색을 그대로 쓴다. 양식에 표시가 없으면 원안지도 표시하지 않는다.
- `--student`는 머리의 형광펜까지 모두 지운다. 글은 원안지와 같다.
- `box`(자료 상자, 글 하나나 문단 목록)와 `bogi`(ㄱ, ㄴ 글 목록)는 `written`을 뺀 어느 유형에나 더할 수 있다. 문제, 자료 상자, `<보기>`, 선택지 순서로 놓인다.
- 글에 `**굵게**`, `__밑줄__`, `{{2/3}}`(한글 수식, `references/equations.md`)을 쓴다. `references/form-fill.md` 3절의 도구와 달리 이 도구는 이 표기를 글자 모양으로 바꾼다. 양식에 같은 글꼴의 굵은 글자나 밑줄 글자가 없으면 오류로 알린다.
- 양식이 문제 끝에 배점(`[3점]`)을 적으면 `points`가 있어야 한다.
- 문항의 문단은 한 단에 함께 놓이도록 "다음 문단과 함께"만 켠다. 모양은 같다. 문항이 단보다 길면 한글에서 나눈다.

### 4지·3지선다 배치

선택지(`short_table`, `combo_table`, `paragraphs`)를 5개보다 적게 쓰면 도구가 5개짜리 선지 틀의 남는 칸을 지운다. 표의 바깥 너비, 칸 테두리·여백·글자 모양은 양식 그대로이고, 칸 수·행 수·칸 너비만 바뀐다. 양식에 같은 선택지 수의 틀이 따로 있으면 그것을 먼저 쓴다.

| 양식의 선지 틀 | 4지선다 | 3지선다 |
|---|---|---|
| 한 줄 5칸(1x5) | 한 줄 4칸(1x4), 칸 너비는 표 너비를 나눠 채움 | 한 줄 3칸(1x3) |
| 세로 5줄(5x1) | 세로 4줄(4x1) | 세로 3줄(3x1) |
| 2줄 3칸(2x3, ①②③ / ④⑤) | 2x2 (①② / ③④) | 1x3 |
| 문단 선택지 | 문단 4개 | 문단 3개 |

- `layout`은 줄인 뒤의 "행x칸"으로 고른다(4지선다 한 줄이면 "1x4"). 5지 틀의 이름(2x3, 5x1, 1x5)을 써도 줄인 배치(2x2, 4x1, 1x4)로 맞춰 받는다.
- 칸이 남는 배치(예: 3칸 틀에 4개를 3+1로)는 만들지 않는다. 합쳐진 칸이 있거나 선택지 칸이 표의 앞쪽이 아닌 학교 양식은 줄이지 못하고 "선택지가 4개인데 … 틀은 5개" 오류로 알린다. 표형 선지(`grid_table`)는 줄이지 않는다.
- 정답 번호 분포 점검은 3·4·5지선다를 따로 센다. 같은 번호 4문항 이어짐은 선지 수와 상관없이 문항 순서대로 센다.

시험지에서 할 수 없는 일:

| 원하는 것 | 도구 | 이렇게 한다 |
|---|---|---|
| 양식에 없는 유형 쓰기 | 오류로 막는다. 일반 문단으로 바꾸지 않는다. `short_table`과 `combo_table`은 서로 가장 가까운 틀로 쓰고 "참고"로 알린다 | 양식에 있는 유형으로 바꾸거나, 그 유형이 든 양식을 받는다. 어느 쪽인지 교사에게 묻는다 |
| 선택지를 틀보다 많이 쓰기, 표형 선지 칸 수를 틀과 다르게 쓰기 | 오류로 막는다. 표 구조를 바꾸지 않는다 | 틀에 맞춰 쓰거나 교사에게 한글에서 표를 고친 양식을 받는다 |
| 선택지를 틀보다 적게 쓰기 (4지·3지선다) | 선택지 수(2개 이상)와 같은 수의 틀이 없으면 더 많은 틀 가운데 가장 가까운 것을 줄여 쓴다. 남는 칸·줄을 지우고 표의 바깥 너비와 칸 모양은 그대로 둔다 | 위 "4지·3지선다 배치"를 따른다 |
| 그림 넣기 | 선택형 문항에 `picture`(PNG, JPG, GIF, BMP)로 넣는다. 목록으로 두 장을 주면 한 줄에 나란히 놓는다(`[{"file": "가.png", "caption": "(가)"}, {...}]`). 서답형과 공통 지문에는 오류로 막는다. 양식의 옛 그림은 쓰지 않는다 | 파일이 없는 그림(실제 사진·유물·지도)은 `box`에 `[그림: 무엇을 나타내는 그림]`으로 자리를 적고, 교사에게 한글에서 넣어 달라고 알린다 |
| 인물 대화 장면 넣기 | 도구에 `dialogue`(인물 클립아트 + 말풍선)가 있지만 출제에 쓰지 않는다 (교사 결정, 2026-11-18) | 대화는 자료 상자(`box`)에 "교사: …", "갑: …" 꼴의 글로 쓴다 |
| 자료 표(내용을 칸마다 넣는 표) 넣기 | 선택형 문항에 `table`(`head`, `rows`, 선택 `caption`·`widths`·`align`)로 넣는다. 순서는 문제 → picture → box → table → bogi → 선지. 머리 칸은 굵게·회색 바탕·가운데, 칸은 가운데 정렬, 왼쪽은 기준선·오른쪽은 단 끝. 양식 header에 실선 칸 모양을 더한다. 서답형과 공통 지문에는 오류로 막는다 | 칸보다 넓은 낱말은 "표 칸보다 넓어"로 알리니 `widths`를 고친다. 한글에서 표가 단을 넘지 않고 문항과 함께 놓이는지 본다 |
| 자료 상자·지문 글 모양 | 문단마다 자동이다. 표지(○ ◦ ● ※, ㄱ., ㉠ ⓐ, (가) (A), 교사: 갑: 학생 1:)로 시작하면 표지 폭만큼 내어쓰기(10pt 기준 ○ 1100, ㄱ. 1600, 갑: 1900, (가) 2100, 교사: 2900, 글자 크기에 비례, 같은 폭은 문단 모양 하나). 마지막 문단의 출처("- … -", "-『…』")와 "*낱말: 뜻" 각주는 오른쪽 정렬. 그 밖의 줄글은 첫 줄 1em 들여쓰기(소제목 <…>, 줄바꿈이 든 시, 식, 8자 미만은 제외). 양식 상자 본문에 이미 들여쓰기·내어쓰기가 있으면 그대로 둔다. 공통 지문(`passage`) 본문은 양식의 거꾸로 내어쓰기를 펴서 첫 줄 들여쓰기로 쓴다. 구현은 `fill_exam_text.py` | 표지 폭은 평가원 글꼴 기준이라 함초롬바탕에서 둘째 줄이 글 시작에 맞는지 한글에서 본다 |
| 선지 배치 고르기 | `layout`이 없으면 가장 긴 선지의 폭으로 1x5(글자 2.6개 폭까지) → 2x3(5.9개까지) → 5x1 중 가장 좁은 틀을 고른다(4지는 1x4 3.9개까지). <보기>가 있는 합답형은 2x3 이상. 양식에 그 틀이 없으면 더 넓은 틀을 쓴다. `layout`을 쓰면 그대로 따른다 | 유형(`short_table`/`combo_table`)을 잘못 적어도 폭에 맞는 틀로 간다 |
| 수식 넣기 | `{{ }}`로 넣는다. 한글이 없는 식만 수식이 된다 | 식이 잘못되면 "참고"로 알린다. 복잡한 식은 한글에서 확인해 달라고 적는다 |
| 총 쪽 수 알기 | 파일만으로는 모른다. 다만 꼬리말의 "전체 (0)쪽 가운데 (0)쪽"(괄호 없는 꼴, "중"도 같다)은 한글 자동 쪽 번호로 바꾼다 | 머리 글의 쪽 수("총 ○면")는 한글에서 확인해 달라고 적는다. 꼬리말 쪽 번호 자리는 `fills`로 숫자를 적지 않는다 |
| 쪽과 단을 옛 양식처럼 나누기 | 양식의 빈 줄과 단 나누기는 옛 문항에 맞춘 것이라 복제하지 않는다 | 한글에서 확인해 달라고 적는다 |
| 문항이 여러 구역에 나뉜 양식, 문항 사이에서 단 설정이 바뀌는 양식 | 오류로 막는다 | 교사에게 한글에서 고친 양식을 받는다 |
