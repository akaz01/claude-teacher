# 학교 양식에 채우기

교사가 양식 파일을 주면 새로 만들지 않고 **그 파일에 내용만 채운다.** 용지, 문단 모양, 글자 모양과 크기, 표 구조를 바꾸지 않는다. 표 안 정렬도 양식을 따른다.

도구는 한글 양식은 `scripts/fill_hwpx.py`, 엑셀 양식은 `scripts/fill_xlsx.py`다. 학교 시험지 양식은 문항 출제(assessment-items) 스킬이 시험지 양식 채우기 문서(exam-form-fill.md) 순서대로 채운다. 원본 양식은 고치지 않고 새 파일을 만든다.

## 1. 받은 파일로 갈래 정하기

| 받은 것 | 할 일 |
|---|---|
| hwpx 파일 | 2절 순서대로 채운다 |
| 학교 시험지 hwpx 파일 (문항이 번호와 선택지로 된 양식) | 문항 출제(assessment-items) 스킬이 시험지 양식 채우기 문서(exam-form-fill.md) 순서대로 채운다 |
| hwp 파일 | 채울 수 없다. 아래 안내를 그대로 보내고 hwpx 파일을 기다린다 |
| PDF, 사진, 샘플 인쇄물 | 채울 수 없다. 항목과 순서만 맞춰 새로 만들고 "항목과 순서만 맞췄고 글자·문단 모양은 양식과 다를 수 있습니다"라고 알린다 |
| xlsx 파일 | 6절 순서대로 채운다 |
| 옛 xls 파일, 암호가 걸린 엑셀 파일 | 채울 수 없다. 엑셀에서 암호를 풀고 [파일 > 다른 이름으로 저장하기]에서 xlsx로 저장한 파일을 달라고 한다 |

hwp를 받았을 때 보내는 안내:

> hwp 파일은 직접 채울 수 없습니다. 한글에서 양식을 열고 [파일 > 다른 이름으로 저장하기]에서 파일 형식을 hwpx로 골라 hwpx로 저장한 뒤, 그 파일을 주세요.

교사가 hwpx로 바꿀 수 없다고 하거나 질문 없이 진행해 달라고 했으면 hwp 안의 항목과 순서를 읽을 수 있는 만큼만 맞춰 새로 만든다. 읽을 수 없으면 스킬의 기본 양식으로 만든다. 어느 쪽이든 "기본값으로 정한 내용"에 적고 위 고지 문장을 쓴다.

## 2. 채우는 순서

1. 자리 확인: `python scripts/fill_hwpx.py --inspect 양식.hwpx`로 문단과 표 칸의 번호와 글을 본다.
2. 넣기 전 점검: 스킬이 정한 계산 점검(수행평가는 `rubric` 1절의 기본점수 방식과 점수 관계)을 하고, 양식 안의 규정 문장과 교사 값을 대조한다. 양식의 반영 비율, 영역 만점, 기본점수 규정이 교사 값과 어긋나면 임의로 고치지 않고 그대로 넣지도 않는다. 어느 값이 맞는지 묻는다. 질문 없이 진행할 때는 그 자리를 `[확인 필요]`로 두고 답변 맨 아래 "확인 필요" 목록에 까닭과 함께 모은다.
3. 대응표 만들기: 양식 자리마다 어떤 내용이 들어갈지 정한다. 제목과 항목 이름은 고치지 않는다. 양식에 없는 항목을 더하지 않는다.
4. `지시.json` 쓰기 (3절).
5. 실행: `python scripts/fill_hwpx.py 양식.hwpx 지시.json 결과.hwpx`
6. 실패하면 파일이 만들어지지 않는다. 출력된 문장대로 지시를 고쳐 다시 실행한다. 못 찾은 자리는 한 번에 모두 알려 준다.
7. 확인: `python scripts/fill_hwpx.py --inspect 결과.hwpx`로 글이 맞는 자리에 들어갔는지, 안내 글(`○○`, `[입력]` 등)이 남지 않았는지 본다. 지난 학기 내용이 든 양식은 고치지 않은 자리에 옛 내용이 그대로 남으므로, 남은 자리를 찾아 답변에 적는다. 교사가 주지 않은 과제명, 채점 문장, 평가 시기 같은 옛 내용은 지시에 넣어 `[확인 필요]`로 바꾸고, 바꾼 자리를 답변에 목록으로 쓴다. 제목과 항목 이름은 고치지 않되, 학년도처럼 해마다 바뀌는 값이 남아 있으면 그 자리도 목록에 올린다.
8. 답변에 알린다: "양식 파일에 내용만 채웠습니다. 글이 늘어 쪽이 넘어가는지 한글에서 확인해 주세요." 양식에 넣지 못한 내용이 있으면 그 목록도 적는다.

결과 파일 이름은 양식과 달라야 한다. 이미 있는 파일은 덮어쓰지 않으므로 다른 이름을 쓴다.

## 3. 지시 파일

```json
{"fills": [
  {"find": "○○ 단원", "replace": "일차방정식"},
  {"find": "○월", "replace": "3월", "all": true},
  {"find": "학년", "replace": "2학년", "nth": 2},
  {"table": 1, "row": 2, "col": 3, "text": "내용"}
]}
```

- `find`, `replace`: 양식의 글을 바꾼다. 찾는 글의 첫 글자 모양을 따른다. 여러 곳에 있으면 오류로 알리므로 `all`(모두)이나 `nth`(몇 번째)를 쓴다.
- `table`, `row`, `col`, `text`: 표 칸의 글을 통째로 넣는다. 번호는 1부터 세고 `--inspect`에 나온 번호를 그대로 쓴다. 빈 칸을 채울 때 쓴다.
- 합친 칸은 `--inspect`에 `[합침]`으로 나온 칸의 번호를 쓴다.
- 찾는 자리는 모두 원본 양식에서 정한다. 앞 지시로 넣은 글을 뒤 지시가 찾지 않는다. 한 자리를 두 번 고치면 오류다.
- 바꿀 글의 줄바꿈(`\n`)은 같은 문단의 줄바꿈이 된다.

## 4. 할 수 없는 일

| 원하는 것 | 도구 | 이렇게 한다 |
|---|---|---|
| 표에 행이나 칸 더하기 | 표 구조를 바꾸지 않는다 | 내용을 줄여 억지로 맞추지 않는다. 들어간 데까지 채우고 남은 내용을 답변에 적는다. 교사에게 한글에서 행을 늘린 양식을 달라고 한다 |
| 굵게, 밑줄, 글자색 넣기 | `**굵게**`, `__밑줄__`은 글자 그대로 들어간다 | 지시 파일에 이 표기를 쓰지 않는다 |
| 수식, 분수 넣기 | `{{2/3}}`은 글자 그대로 들어간다 | 2/3처럼 글로 쓸 수 있으면 글로 쓴다. 안 되면 5절의 나누기를 쓴다 |
| 그림, 표, `<보기>` 상자 넣기 | 넣을 수 없다 | 5절의 나누기를 쓴다. 시험지 양식의 표와 `<보기>`는 문항 출제 스킬의 시험지 양식 도구가 틀을 복제해 넣는다 |
| 표·그림·누름틀이 든 칸을 통째로 바꾸기 | 오류로 막는다 | `find`로 그 안의 글만 바꾼다 |
| 바탕쪽의 글 바꾸기 | 찾지 못한다 | 교사에게 한글에서 고쳐 달라고 한다 |
| 메모 글 바꾸기 | 찾지 않는다 | 그대로 둔다 |
| 암호가 걸린 파일 채우기 | 오류로 막는다 | 한글에서 암호를 풀고 저장해 달라고 한다 |

## 5. 나누기

양식에 넣을 수 없는 내용이 있으면 양식에 들어가는 부분만 채운다. 나머지는 `scripts/make_hwpx.py`로 별도 파일을 만들고 답변에 "이 부분은 양식 모양이 아닙니다. 양식으로 옮겨 붙여 주세요"라고 알린다.

## 6. 엑셀 양식 채우기

도구는 `scripts/fill_xlsx.py`다. 칸의 값만 바꾸고 서식, 병합, 조건부 서식, 데이터 유효성, 도형과 그림은 그대로 둔다. 순서는 2절과 같다.

1. 자리 확인: `python scripts/fill_xlsx.py --inspect 양식.xlsx`로 시트 이름, 칸 주소, 합친 칸, 수식 칸, 숨김·보호 시트를 본다.
2. `지시.json` 쓰기, 실행: `python scripts/fill_xlsx.py 양식.xlsx 지시.json 결과.xlsx`
3. 확인: `--inspect 결과.xlsx`로 맞는 칸에 들어갔는지 보고, 고치지 않은 칸에 옛 내용이 남았는지 찾아 답변에 적는다.
4. 답변에 알린다: "양식 파일에 값만 채웠습니다. 합계 같은 수식은 엑셀이 열 때 다시 계산합니다."

```json
{"fills": [
  {"sheet": "1반", "cell": "C5", "value": "홍길동"},
  {"sheet": 1, "cell": "D5", "value": 85},
  {"find": "○○", "replace": "국어", "all": true}
]}
```

- `sheet`는 시트 이름이나 1부터 센 번호, `cell`은 `C5` 같은 한 칸의 주소다. 숫자는 따옴표 없이 쓴다 (`85`). 따옴표를 붙이면 글자로 들어가 합계에 더해지지 않는다.
- `value`가 `null`이나 `""`이면 칸을 비운다. 칸의 서식은 그대로다.
- `find`, `replace`, `all`, `nth`는 hwpx와 같다. `sheet`를 더하면 그 시트에서만 찾는다. 수식 칸의 글은 찾지 않는다. `all`은 시트를 지정하지 않으면 모든 시트에 적용되므로 `sheet`를 지정한다.
- 합친 칸은 왼쪽 위 칸의 주소를 쓴다. 다른 주소는 오류다.
- 수식 칸은 덮어쓰지 않고 오류로 알린다 (합계 자동 계산을 지키기 위해). 값 칸만 지정한다.
- 한 칸의 글은 32,767자까지다 (엑셀 상한, 이모지는 2자로 센다). 넘으면 오류이므로 나눠 넣는다.
- 15자리가 넘는 정수(학번, 전화번호 등)는 엑셀이 끝자리를 바꾸지 않도록 도구가 글자로 넣고 알려 준다. 글자로 들어간 칸은 합계에 더해지지 않으므로, 그 칸이 계산에 쓰이는 자리면 답변에 적는다.
- 양식 범위 밖의 칸, 없는 시트, 못 찾은 글이 하나라도 있으면 파일을 만들지 않고 한 번에 모두 알린다.
- 숨김 시트와 보호된 시트는 `--inspect`에 표시된다. 채웠다면 그 시트 이름을 답변에 적는다.
- 학생을 일부만 채우면 빈 줄의 합계 0이 평균에 들어가는 양식이 있다. 평균 칸이 있으면 값을 확인하고, 왜곡되면 답변에 알린다.

엑셀에서 할 수 없는 일:

| 원하는 것 | 이렇게 한다 |
|---|---|
| 행이나 열 더하기 | 도구가 구조를 바꾸지 않는다. 들어간 데까지 채우고 남은 내용을 답변에 적는다. 교사에게 엑셀에서 행을 늘린 양식을 달라고 한다 |
| 수식 칸에 값 넣기, 수식 바꾸기 | 오류로 막는다. 교사에게 엑셀에서 고쳐 달라고 한다 |
| 글자 색, 굵게, 서식 바꾸기 | 하지 않는다. 양식의 서식을 따른다 |
| 글자별 서식(칸 안 일부만 굵게 등)이 있는 칸의 글 바꾸기 | 칸 전체 서식만 남는다. 도구가 알려 주므로 답변에 적는다 |
| 데이터 유효성(목록) 확인 | 하지 않는다. 목록에 있는 값인지 직접 맞춘다 |
| 차트, 그림 새로 넣기 | 넣을 수 없다 |
