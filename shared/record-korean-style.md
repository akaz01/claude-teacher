# 학생부 문장의 우리말 문체

학생부(세특·창체·행특) 문장을 쓴 뒤 이 파일로 한 번 더 다듬는다. 목표는 한국 교사가 직접 쓴 것처럼 읽히는 문장이다. 번역한 듯한 문장, 사전에서 고른 듯한 순우리말 문장은 학생부에서 어색하다.

## 0. 근거

교육부·한국교육과정평가원의 교과세특 기재 예시 자료(2022)에서 교사가 쓴 기록 부분(184곳)의 문장 928개를 모아 끝맺음, 이음말, 첫머리, 낱말을 셌다 (2026-11 분석). 아래 숫자는 그 문장 수다. 이 자료는 문체의 기준으로만 쓴다. 자료에 많은 평가 표현(능력이 우수함, 적극적으로)은 대학이 "추상어"로 낮게 보는 것이기도 하므로 3장의 제한을 따른다.

- 문장 하나는 평균 70자 안팎이다. 한 문장에 행동 두세 개를 "~하여", "~하고", "~하며"로 잇는다.
- 기록 하나는 문장 4~6개다.

## 1. 끝맺음

명사형으로 끝낸다. 행동 동사는 대부분 한자어 동사 + "함"이다.

| 자주 쓰는 끝맺음 (문장 수) | 쓰는 곳 |
|---|---|
| 설명함(67), 발표함(56), 표현함(31), 작성함(29), 참여함(24), 제시함(21), 노력함(17), 제작함(12), 파악함(12), 완성함(11), 이해함(11), 수행함(9), 정리함(7), 해결함(6), 구성함(6), 확인함(6), 제안함(5), 분류함(5), 전달함(5), 주장함(5), 활용함(4), 탐색함(4), 공유함(4) | 학생이 한 일 |
| 모습을 보임(45), 태도를 보임(14), ~이 돋보임(27), ~이 인상적임(15), ~하는 학생임(52), 모습이 관찰됨(5) | 앞 문장의 행동을 묶는 평가. 기록 하나에 한 번, 근거 문장 뒤에만 |

- "~함."을 연달아 쓰는 것은 자연스럽다. 끝말을 바꾸려고 "~하였음.", "~해 냄.", "~해 둠."처럼 드문 꼴을 섞지 않는다.
- "~할 수 있었음.", "~하게 되었음."은 쓰지 않는다. "~함.", "~하게 됨."으로 쓴다.
- 자료에 많은 "~이 향상됨(30)", "~이 신장됨(7)"은 이전 수준이 낮았다는 뜻으로 읽히므로 이 스킬은 쓰지 않는다. 변화는 학생이 만든 습관과 새로 맡은 일로 쓴다.

## 2. 이음말과 첫머리

| 이음말 (문장 수) | 쓰임 |
|---|---|
| ~하여(437), ~하고(335), ~하며(96), ~하면서(68) | 행동을 차례로 이음 |
| ~을 활용하여(87), ~을 통해(130), ~을 바탕으로(44) | 방법과 근거 |
| ~하는 과정에서(76), 이 과정에서(15) | 활동 안의 한 장면 |
| 이를 통해(21), 이를 바탕으로(7) | 앞 문장의 결과를 다음 행동으로 이음 |
| ~하는 등(37) | 비슷한 행동 둘 이상을 묶음 |
| ~함으로써(6) | 결과를 밝힐 때. 드물게 |

첫머리는 활동 맥락으로 연다.

- `'○○'을 주제로 한 모둠 발표에서`, `○○ 단원에서`, `○○ 수업에서`, `○○ 실험에서`, `○○ 과정에서`
- `○○에 관심을 가지고`, `○○ 활동에서 ○○을 맡아`

## 3. 낱말 고르기

학생부 문장은 교사의 기록 문체다. 교사에게 하는 안내는 쉬운 우리말로 쓰지만, 학생부 문장 안에서는 교사들이 쓰는 한자어 동사를 쓴다. 아래 왼쪽 말은 교사 기록 928문장에 거의 나오지 않는다.

| 어색한 말 | 학생부에서 쓰는 말 |
|---|---|
| 까닭 | 이유, 원인 |
| 낱말 (중·고) | 어휘, 단어 (초등 받아쓰기·국어 낱말 학습은 "낱말" 그대로) |
| 짚다, 짚어 냄 | 언급함, 찾아냄, 제기함 (세특은 "지적함"도 쓴다. 창체·행특에서는 꾸중을 떠올리게 하므로 "지적"을 쓰지 않는다) |
| 따지다, 따져 봄 | 분석함, 검토함 |
| 견주다 | 비교함 |
| 이어 감, 이어 가며 | 지속함, 꾸준히 ~함, 계속함 |
| 넓히다, 넓혀 감 | 확장함, 범위를 확대함 |
| 나누어 맡다 | 분담함, 역할을 나누어 수행함 |
| 고쳐 씀, 고침, 고친 (결과물) | 수정함, 보완함, 퇴고함, 수정한 |
| 씀 (글·기록을) | 작성함, 기록함, 서술함, 정리함 |
| 해냄, 해내며, 해내는 | 완성함, 마무리함, 수행함 |
| ~해 감, 익혀 감, 다듬어 감, 채워 가는 | 꾸준히 ~함, 지속함, ~하는 습관을 들임 |
| ~하려 함, ~하려고 함 (의도로 맺음) | 실제로 한 행동으로 맺음 (예: 해석함, 질문함) |
| 찾아 읽음 | 조사함, 자료를 수집하여 읽음 |
| 내놓다 | 제시함, 제안함 |
| (질문을) 세우다 | 질문을 제기함, 탐구 질문을 설정함 |
| 되짚다 | 점검함, 복습함 |
| 알려 줌 | 안내함, 설명함 |
| 학급원, 반 아이들 | 학급 친구들, 급우, 모둠원 |

평가 낱말은 근거 뒤에 하나만 붙인다. 자료에 많은 "적극적으로(85)", "다양한(132)", "효과적으로(41)", "능력이 우수함(22)"은 근거 없이 쓰면 추상어가 된다. 장면을 먼저 쓰고, 꾸밈말은 한 문장에 하나까지만 쓴다.

## 4. 번역투 고치기

| 번역투 | 고친 말 |
|---|---|
| ~를 가지고 있음, ~를 보유함 | ~이 있음, ~함 |
| ~에 있어서, ~하는 데 있어 | ~에서, ~할 때 |
| ~하는 것을 통해 | ~하여, ~함으로써 |
| ~되어짐, ~하여짐 | ~됨 |
| 그는, 그녀는, 해당 학생은 | 주어를 쓰지 않음 |
| ~에 대한 깊은 이해를 보여 줌 | 이해한 내용을 행동으로 씀 (예: 원리를 그림으로 설명함) |
| 열정을 보여 줌, 통찰력을 보임 | 한 일과 그 결과를 씀 |
| 성공적으로 완수함 | 완성함, 마무리함 |
| ~에 기여함 (거듭 씀) | 무엇을 하여 무엇이 되었는지 씀 |
| ~라는 점에서 의미가 있음 | 쓰지 않음 |
| 데이터 수집 및 분석 과정을 수행함 | 자료를 수집하여 분석함 |
| ~의 중요성을 깨달음 (근거 없이) | 무엇을 하고 무엇을 알게 되었는지 씀 |
| 매우, 굉장히, 정말 | 빼거나 횟수·기간으로 바꿈 |
| ~에 지적 호기심을 품고 | ~에 관심을 가지고, ~에 의문을 갖고 |
| 단순한 ~을 넘어 ~함 | 쓰지 않음. 학생이 한 일만 씀 |
| ~해 냄 (입증해 냄, 확장해 냄) | 입증함, 확장함 |
| 역량이 탁월함·압도적임·최상위권임, ~한 인재임 | 쓰지 않음. 3장대로 근거 뒤 평가 하나만 |
| 독학하여, 스스로 학습함 (수업 맥락 없이) | 수업에서 무엇을 계기로 무엇을 조사했는지 씀 |

인터넷의 세특 "우수사례 예시"와 몇 해 전 합격 사례집의 문장은 위 틀을 거듭 쓰는 경우가 많고, 지금 쓸 수 없는 내용(소논문·논문 실적, 논문·학술지명, 방과후학교, 외부 캠프·기관명, 대학명)과 부족한 점을 앞세운 구조도 자주 섞여 있다 (2026-11 조사: 2020학년도 합격 사례 110건, 2025~2026 인터넷 예시 영상 10개). 교사가 이런 문장을 주며 비슷하게 써 달라고 하면 흐름(계기 → 방법 → 해석 → 산출물)만 따르고, 금지 내용과 부정적 서술은 `record-guide.md` 1장과 `record-common-rules.md` 3장대로 걸러 낸다.

## 5. 문장 부호와 표기

- 활동 이름, 주제, 작품 이름은 작은따옴표로 묶는다: `'임진왜란이 동아시아에 끼친 영향'을 주제로`.
- 날짜는 `내용(0000.00.00.)`으로 쓴다.
- 가운뎃점(·)은 쓰지 않는다. 쉼표나 "와/과", "및"으로 잇는다 (공통 규칙 7장).
- 단위가 붙는 수는 아라비아 숫자로 쓴다 (`3개`, `5명`, `2주`, `42건`). "두 가지", "세 학년", "두 차례"처럼 교사들이 흔히 쓰는 말은 한글로 써도 된다. 문장 첫머리의 순서 번호(①, 1.)와 특수문자는 쓰지 않는다.
- 쉼표는 행동 두세 개를 이은 긴 문장에서 큰 마디를 나눌 때 한 번 찍는다 (`~을 설명하고, ~을 발표함`). 짧은 문장의 이음말마다 찍지는 않는다.

## 6. 고친 예

- 고칠 말: `등비수열의 합 공식이 공비가 1일 때 성립하지 않는 까닭을 질문하고, 항을 직접 나열해 합을 구하며 공식을 두 경우로 나누어 정리함.`
- 쓸 말: `등비수열의 합 공식이 공비가 1일 때 성립하지 않는 이유를 질문하고, 항을 직접 나열하여 합을 구한 뒤 공식을 두 경우로 나누어 정리함.`
- 고칠 말: `모둠 과제 일정과 준비물을 메모로 정리해 모둠원에게 전하는 일을 한 학기 동안 이어 감.`
- 쓸 말: `모둠 과제의 일정과 준비물을 메모로 정리하여 모둠원에게 안내하는 일을 한 학기 동안 꾸준히 함.`
- 고칠 말: `녹지 면적만으로는 접근성을 설명할 수 없다는 점을 짚고`
- 쓸 말: `녹지 면적만으로는 접근성을 설명할 수 없다는 점을 지적하고` (세특)

## 7. 다 쓴 뒤 확인

| # | 확인 |
|---|---|
| K1 | 3장 왼쪽의 어색한 말과 4장의 번역투가 없는가 |
| K2 | 행동 끝맺음이 한자어 동사 + "함"인가. "~할 수 있었음", "~하였음"이 없는가 |
| K3 | 평가 끝맺음("~모습을 보임", "~학생임", "~이 돋보임")이 기록 하나에 한 번이고 근거 문장 뒤에 있는가 |
| K4 | 30자 미만의 짧은 문장이 이어지거나 한 문장이 120자를 넘지 않는가 |
| K5 | 같은 사실을 말만 바꿔 두 번 쓴 문장이 없는가 |
| K6 | 소리 내어 읽었을 때 교사가 쓴 기록처럼 들리는가 |
| K7 | 대학 전공 용어를 한 문장에 여러 개 몰아 쓰지 않았는가. 교사가 수업에서 확인했고 학생이 말로 설명할 수 있는 용어만 쓴다 |
