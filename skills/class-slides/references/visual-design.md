# 수업 PPT 형식 가이드 (인포그래픽 · 핵심 포인트 · 줄바꿈 · 정렬)

내용(무엇을 가르칠지)은 SKILL.md 2절을 따르고, 이 문서는 **어떻게 보여 줄지**만 다룬다. 기본 생성기(`make_deck.py`), 교사 양식 복제(`fill_template.py`), 테마(`make_pptx.py`) 모두 같은 기준을 쓴다.

**적용 범위: 이 문서는 pptx 생성기와 양식 복제(`make_deck.py`, `make_pptx.py`, `fill_template.py`)에만 적용한다.** 앱 슬라이드는 `app-slides.md`와 `house-style.md`가 우선이다(제목·설명·핵심 줄·지시는 왼쪽 정렬, 핵심 줄은 `.key` 모양). 아래 정렬과 핵심 포인트 띠 규칙을 앱 슬라이드에 적용하지 않는다.

## 1. 한 장의 구조

설명 장은 위에서 아래로 같은 뼈대를 가진다. 확인·연습·답 장은 도식 자리에 문제와 지시를 두고, 핵심 포인트 띠를 넣지 않는다.

| 자리 | 내용 | 기준 |
|---|---|---|
| 꼬리표 | 단원·소주제 (예: "03. 전쟁의 전개") | 양식의 작은 글 자리 |
| 제목 | 그 장의 질문이나 핵심 구 | 질문형이면 더 좋다 ("남침은 어떻게 결정되었나") |
| 도식 | 3절의 인포그래픽 하나 | 장의 대부분을 차지한다 |
| 핵심 포인트 띠 | 그 장에서 꼭 남길 문장 하나 | 설명 장에만. 어두운 바탕에 흰 굵은 글씨, 한 줄 |
| 발표자 노트 | 말할 내용, 예상 답과 흔한 오해, 시간, 출처. 확인·연습 장은 답과 다음 행동도 | 화면에서 뺀 자세한 내용은 모두 여기로 |

### 장 역할별 글 규칙

| 역할 | 화면 글 | 글 줄만 있어도 되는가 |
|---|---|---|
| 설명 | 키워드와 짧은 구. 카드 글 2줄 이내 | 안 된다. 3절 패턴을 쓰고, 넣을 도식이 없으면 큰 문장 하나로 둔다 |
| 확인 | 문항은 문장으로 쓴다. 선택지는 짧게 | 된다 |
| 연습 | 지시문은 문장으로 쓴다. 번호, 시간, 산출물을 적는다 | 된다 |
| 답 | 문제 장과 같은 틀. 답만 강조색과 굵기로 얹는다. 답이 여러 개일 수 있으면 예시임을 밝힌다 | 된다 |
| 활동 방법 | 시간, 역할, 준비물, 산출물과 번호 단계. 5줄을 넘으면 학습지로 보낸다 | 된다 |
| 요약 | 2~3문장 | 된다 |

## 2. 핵심 포인트 잡기

- **설명 장마다 핵심 문장은 하나**다. "핵심: …"으로 시작하는 띠에 한 줄로 쓴다. 두 줄이 되면 문장을 줄인다. 표지, 목차, 핵심어, 확인, 연습, 답, 마무리 장에는 띠를 넣지 않는다.
- 핵심어는 굵게, 연도·숫자는 크게 쓴다(원, 꼬리표, 큰 숫자). 학생이 3초 안에 무엇이 중요한지 알아야 한다.
- 강조색은 한 장에 한두 가지만 쓴다. 양식이 무채색이면 양식 분위기에 맞는 낮은 채도의 두 색(예: 남색·적색)을 정하고 덱 전체에서 같은 뜻으로 쓴다(예: 남색 = 한국·유엔군, 적색 = 북한·중국군, 짙은 회색 = 결론).
- 설명 장의 화면 글은 키워드와 짧은 구로 쓰고, 문장 설명은 노트로 옮긴다.
- 제목 안의 핵심어 한두 개만 강조색으로 칠한다 (`make_deck.py`는 `**낱말**`).

## 3. 인포그래픽 패턴

설명 장은 내용의 구조를 먼저 정하고 그에 맞는 패턴을 고른다. 글머리표 목록은 마지막 수단이다. 그림과 도식은 그 자체가 내용일 때만 쓴다.

| 내용의 구조 | 패턴 | 만드는 법 (`add` 도형) |
|---|---|---|
| 시간 순서 | **가로 연표**: 선 위에 연도 원, 아래에 카드 | `line` + `circle`(연도) + `rounded`(제목어 + 한 줄) |
| 원인 → 결과, 과정 | **흐름**: 갈매기형 띠 + 아래 설명 카드 | `chevron` 여러 개를 살짝 겹쳐 잇고, 아래에 `rounded` |
| 두 대상 비교 | **좌우 대비**: 색 머리 띠 두 개, 가운데 vs 원이나 세로선 | `rounded` 머리 띠 2개 + `circle`("vs") 또는 `line` |
| 한 사건의 여러 영향 | **방사형**: 가운데 원에서 선을 뻗어 카드 4개 | `circle` + `line` 4개 + `rounded` 4개 |
| 위치가 시간에 따라 바뀜 | **그래프**: 세로축 장소, 가로축 시기, 번호 점을 선으로 연결 | `line`(눈금·연결선) + 번호 `circle`. 설명은 그래프 위에 쓰지 말고 아래 한 줄 칸에 번호순으로 |
| 단계별 상세 | **단계 장**: 왼쪽 지도, 가운데 세로 연표(날짜 열 + 사건 열), 오른쪽 사진과 설명, 아래 핵심 띠 | `image`(지도) + 세로 `line` + 점 `circle` + 날짜·사건 `box` + `image`(사진) |
| 장소가 중요 | **지도 + 강조**: 지도 위 빨간 원으로 위치를 가리키고 꼬리표를 붙임 | `image` + 테두리만 있는 `circle` + `rounded` 꼬리표 |
| 이유 여러 개와 결과 | **이유 카드 + 결과 흐름**: 위 사건 띠, 가운데 이유 카드, 아래 결과 갈매기형 | `rounded` + `chevron` |
| 두 기준으로 나누기 | **2축 사분면**: 가로·세로 축과 네 칸 | `line` 2개 + 칸마다 `box` |
| 찬반, 입장의 정도 | **입장 축**: 양 끝에 입장을 쓴 선 위에 표시 | `line` + 양 끝 `rounded` + `circle` |
| 낯선 개념을 쉬운 것에 빗대기 | **비유 그림**: 왼쪽 쉬운 것, 오른쪽 개념, 짝을 선으로 | `rounded` 두 줄 + `line` |
| 사진의 부분 설명 | **사진 설명선**: 부분을 가리키는 선을 그어 바로 옆에 이름을 단다 | `image` + `line` + `rounded` (`make_deck.py`는 `figure`의 `callouts`) |
| 맞는 것과 틀린 것 | **좋은 예·나쁜 예**: 두 카드를 나란히 놓고 표시와 굵기로 가른다 | `rounded` 2개 + 표시 글 |
| 둘 사이의 같고 다른 점 | **공통점·차이점 표**: 가운데 공통점, 양옆 차이점 | `box` 3열 |
| 학생이 채워 가는 내용 | **빈 표 → 채운 표**: 같은 표를 두 장에 쓰고 뒤 장에만 답을 얹는다 | 같은 좌표의 `box` |
| 대상별 영역별 정리 | **대상 × 영역 격자**: 행은 대상, 열은 영역 | `box` 격자 |
| 확인 문제 정답 | 정답 카드에 강조색 굵은 테두리와 표시 | `rounded`(fill 없음, line 강조색, line_width 6) |

- 한 덱에 같은 패턴이 계속 이어지지 않게 섞는다. 다만 같은 종류의 장(예: 단계별 상세 4장)은 같은 틀을 반복해 비교하기 쉽게 한다.
- 개요 장(예: 4단계 지도를 한 장에) 뒤에 단계별 상세 장을 두면 큰 그림 → 자세히의 흐름이 된다.
- 한 표상은 여러 장에서 되풀이해 변화를 보게 한다.

## 4. 사진과 지도

- 사진은 교사가 인터넷 자료를 허락했을 때만 쓴다. 퍼블릭 도메인·CC 라이선스(예: 위키미디어 공용)만 쓰고, 장마다 노트에 출처와 라이선스를 적는다.
- 양식의 사진 자리(원, 카드)에 넣을 때는 `images`(도형 비율에 맞춰 자름)를, 지도·도표처럼 잘리면 안 되는 그림은 `add`의 `image`(비율 유지)를 쓴다. 중요한 부분이 한쪽에 있으면 `crop`으로 그 영역을 먼저 잘라 낸다.
- 지도를 직접 그릴 때는 공개 데이터(예: Natural Earth 해안선, 퍼블릭 도메인)를 쓰고 지명은 한국어로 쓴다. 전선·경계처럼 근사한 선은 지도와 노트에 "(대략)"이라고 밝히고 교과서 지도와 함께 쓰도록 안내한다.
- 역사적 장면이나 실존 인물을 AI로 만든 "사진"은 쓰지 않는다.
- 그림 설명은 그림 바로 옆에 둔다.
- 양식에 있던 사진이 주제와 맞지 않으면 바꾸거나 지운다. 양식의 원래 글과 사진이 결과에 남으면 안 된다.

## 5. 글자 크기와 줄바꿈

- 양식 폭이 20인치(18288000 EMU)처럼 크면 양식의 18pt도 화면에서는 작다. 기준: 카드 제목어 22~26pt, 카드 본문 20~24pt, 연표 사건 18pt 이상, 사진 설명 16pt 이상.
- **한 줄 분량의 글이 몇 글자 넘쳐 꺾이지 않게 한다.** "…설명할 수 / 있다.", "1949. / 10"처럼 끝 한두 글자만 다음 줄로 가면 상자를 넓히거나 글을 다듬어 한 줄로 만든다.
- `make_deck.py`와 `make_pptx.py`는 저장 직전에 `slide_check.py`로 다듬는다. 끝 줄에 몇 글자만 남으면 글자를 조금 줄여 한 줄로 만들고, 그래도 안 되면 어절 사이에 줄바꿈을 넣어 줄 길이를 고르게 한다. `fill_template.py`는 양식을 지키려고 경고만 내므로 글을 직접 다듬는다.
- 두 줄이 필요한 글은 두 줄을 고르게 나누거나, 아예 문단 두 개로 나눠(예: `["1949", "10"]`, `["**제목어**", "설명"]`) 줄이 바뀌는 자리를 직접 정한다.
- 끊기면 안 되는 덩어리(연도·날짜, 인명, 고유 명사)가 두 줄로 갈라지지 않게 한다.
- 설명 장의 카드 글은 2줄 이내, 핵심 띠는 1줄이다. 확인·연습·답 장의 문제와 지시문은 이 제한을 받지 않는다.

## 6. 정렬

**글자는 가로·세로 가운데가 기본이다(pptx 생성기·양식 복제 기준. 앱 슬라이드는 `house-style.md` 4절).** 표 안 글자, 지시문, 카드, 연표, 목록도 같다. 교사 양식이 있으면 양식의 정렬이 우선이다.

- `make_deck.py`, `make_pptx.py`와 `add` 도형은 저절로 가운데로 맞춘다.
- 가운데 정렬한 목록에는 글머리표를 쓰지 않는다. 표 위치가 줄마다 어긋나 지저분해 보인다.
- 교사 양식의 칸을 채울 때는 양식이 정한 정렬을 그대로 둔다.
- 그래프 세로축 이름처럼 축에 붙어야 하는 글은 축 쪽으로 붙여도 된다.

- 같은 장에서 같은 역할의 글은 정렬, 크기, 굵기를 똑같이 한다.
- 나란한 카드는 너비, 높이, 간격을 같게 하고 위쪽 끝을 맞춘다. 좌표는 계산해서 정한다(예: 시작 x + i × (너비 + 간격)).
- 원 안의 글, 카드 안의 글은 세로로도 가운데에 둔다(`add` 도형은 자동).

## 7. 배치

- `--inspect`로 양식의 모서리 문양·세로 막대 같은 장식 위치를 확인하고, 도식은 그 안쪽 안전 영역에 둔다.
- 도식이 양식 장식과 겹치면 그 장의 그 장식만 `remove`한다. 배경과 다른 장식은 남긴다.
- **사진, 그림, 글상자, 상자, 선, 묶음 등 모든 도형은 슬라이드 테두리 안에 둔다.** 양식 그림(건물, 꽃, 카드 배경, 사진 칸)이나 장식이 아래나 옆으로 잘려 있으면 `geometry`로 비율을 지켜 줄이거나 옮긴다. `--inspect`("슬라이드 밖으로 나감", "밖으로 나간 장식")와 생성기 경고가 알려 준다. 슬라이드와 크기가 꼭 같은 바탕 배경은 안에 있는 것으로 본다.
- `add`로 그린 도형이 밖으로 나가면 생성기가 크기는 그대로 두고 테두리 안으로 옮긴 뒤 알려 준다. 옮겨진 도형이 다른 것과 겹치지 않는지 그림으로 확인하고, 처음부터 좌표를 테두리 안에서 계산한다.
- 회전된 도형(`--inspect`의 "회전 90°")은 `geometry` 값이 회전 전 기준이다. 90°·-90° 도형은 width가 화면의 세로, height가 화면의 가로가 된다. 보이는 위치를 유지하려면 가운데 점을 기준으로 계산한다.
- 제목 아래부터 핵심 띠 위까지를 도식 영역으로 보고, 위아래 여백이 한쪽으로 쏠리지 않게 채운다. 빈 공간이 크게 남으면 카드를 키우고, 설명 장이면 핵심 띠를 넣는다.

## 8. 확인 절차 (만든 뒤 반드시)

1. `make_deck.py`(또는 `fill_template.py`, `make_pptx.py`)의 "확인 필요" 경고를 모두 본다. 넘침을 추정해 알려 준다. `fill_template.py`와 `make_pptx.py`는 몇 글자 줄바꿈도 알려 준다.
2. 그림으로 내보낼 수 있으면 모든 장을 그림으로 보고 겹침, 넘침, 빈 공간, 정렬을 확인한다.
   - Windows + PowerPoint: `powershell -File scripts/render_slides.ps1 수업.pptx 그림폴더`
   - LibreOffice: `soffice --headless --convert-to pdf 수업.pptx` 뒤 PDF를 본다.
3. Windows + PowerPoint가 있으면 실제 줄바꿈도 센다: `powershell -File scripts/check_wrap.ps1 수업.pptx` → 같은 폴더의 `wraps.tsv`(장, 도형, 줄 수, 첫 줄 글자 수, 마지막 줄 글자 수, 글). 마지막 줄이 첫 줄의 30% 이하인 문단을 모두 고친다.
4. 고친 뒤 다시 만들고 2~3을 되풀이한다. 실측 0건, 겹침 0건이 될 때까지.

### 마지막 점검표

- [ ] 주기마다 확인, 연습, 답이 있다 (활동 중심 차시는 예외를 답변에 밝힌다)
- [ ] 연속 설명이 3장을 넘지 않는다
- [ ] 글만 나열한 설명 장이 없다 (모든 **설명** 장에 3절 패턴이나 큰 문장 하나가 있다)
- [ ] 설명 장마다 핵심 포인트 띠가 한 줄로 있다 (표지, 목차, 핵심어, 확인, 연습, 답, 마무리 제외)
- [ ] 장식 그림이 없다
- [ ] 답이 눈으로 갈린다 (색만이 아니라 굵기나 표시도 함께 쓴다)
- [ ] 글자에 `**` 같은 표시가 남지 않았다
- [ ] 모든 확인·연습 장의 노트에 답이 있고, 노트 시간의 합이 차시 시간 안이다
