# teacher-kit 하우스 스타일 (수업 PPT·학습지 공통, 판 3)

**누가 이 스킬을 쓰든 결과물은 이 스타일로 만든다.** 수업마다, 교사마다 디자인과 형식을 새로 정하지 않는다. 색·글꼴·크기·표시를 아래 값 그대로 쓰고, 예시 코드(`app-deck-example.md`, `app-worksheet-example.md`)의 마크업을 베껴 글만 바꾼다.

예외는 세 가지뿐이다.
1. 교사가 자기 양식(PPT 템플릿 .pptx, 학교 학습지 양식 .hwpx)을 줬을 때: 양식의 디자인이 우선이다.
2. 교사가 색이나 디자인을 직접 바꿔 달라고 했을 때: 말한 부분만 바꾸고 나머지는 이 스타일을 지킨다.
3. 앱 슬라이드 기능이 없어 수업 PPT를 .pptx 생성기로 만들 때: 생성기가 교과마다 정해 둔 색을 쓴다. 같은 교과면 누가 만들어도 같은 색이므로 교사마다 디자인이 달라지지 않는다. 한글(hwpx) 학습지에는 이 예외가 없다(모든 교과가 파랑 한 계열).

클로드 앱에서는 이 스타일을 디자인 시스템 "teacher-kit 수업 디자인"(`design-system-setup.md`)으로 각 교사 계정에 설치해 불러온다. 값은 이 파일과 같다. 그 밖의 디자인 시스템이나 다른 글꼴은 교사가 쓰라고 말하지 않았으면 쓰지 않는다.

## 1. 색

| 이름 (토큰) | 값 | 쓰는 곳 |
|---|---|---|
| 남색 `ink` | `#14213D` | 본문 글자, 표지 왼쪽 칸·학생 활동·차시 예고 장 바탕, 칩 바탕, 굵은 선 |
| 종이색 `paper` | `#F6F3EC` | 슬라이드 설명 장 바탕, 표지 오른쪽 칸 |
| 옅은 하늘색 `sky` | `#EAF0F7` | 슬라이드 확인 문제 장 바탕, 학습지 마디 띠·학습 목표 상자·표 머리 행 |
| 흰색 `page` | `#FFFFFF` | 보기 카드, 정답 띠, 그림 카드, 학습지 종이 |
| 노랑 `amber` | `#F4B23E` | 슬라이드 강조 하나: '핵심'·'지금' 칩, 표지 칩과 짧은 띠, 진행 막대, 연습 번호 원, 요약 장 바탕 |

| 연파랑 `tint-blue` | `#E3EDF9` | 학습지 이름표·종류 칩·시간 칩 바탕 (글자는 `navy`) |

| 크림 `cream` | `#FFF6E3` | 학습지 자료·도움말 상자 바탕 (테두리 `gold-line` `#E6C383`) |
| 연노랑 `fill` | `#FFEFC2` | 학습지 빈칸 바탕 (아래 `ink` 밑줄) |
| 답 파랑 `answer` | `#1D4ED8` | 학습지 교사용 답과 채점 기준 (굵게) |

| 가는 선 `hair` | `#D9D3C7` | 슬라이드 목록·칸 나눔 선, 진행 막대 바탕 |

- 슬라이드의 강조색은 노랑 하나다. 그래프에서 두 계열을 가를 때만 파랑과 노랑을 함께 쓴다. 노랑 위 글자는 남색이다.
- **학습지는 파랑 한 계열**(`navy`·`blue`·`sky`·`tint-blue`·`pale`)로 칠하고, 노랑 포인트(`gold`·`cream`·`fill`)는 빈칸·자료·도움말에만 쓴다. 주제마다 색을 바꾸거나 초록·보라·빨강을 더하지 않는다(알록달록하게 하지 않는다).
- **흑백 인쇄**: 학교는 흑백 인쇄가 많다. 진한 색(`navy`·`blue`·`gold`) 바탕에는 흰 글자, 연한 색 바탕에는 `navy`·`ink` 글자만 올린다. 영역이 바뀌는 곳(머리, 마디, 상자)은 진한 색 띠·머리띠로 표시해 흑백에서도 보이게 한다.
- 정답·중요한 것은 색만으로 가르지 않는다. 굵기, '정답' 글자, 칩을 함께 쓴다.

## 2. 글꼴

- 제목, 큰 번호, 마디·주제 제목, 요약 문장, 예시 답, 큰 공식: 명조 **Hahmlet**(600, 700). 목록 끝에 `'Noto Serif KR', Batang, Georgia, serif`.
- 그 밖의 글자: **Noto Sans KR**(400, 500, 700). 목록 끝에 `'Malgun Gothic', Arial, sans-serif`.
- 내려받은 pptx와 인쇄에서는 바탕·맑은 고딕으로 보일 수 있다.
- 다른 글꼴을 쓰지 않는다. 영문 전용 글꼴로 한글을 쓰지 않는다. 굵기 900은 쓰지 않는다.

## 3. 글자 크기

| 슬라이드 (1920×1080) | 크기 | 학습지 (A4 794×1123) | 크기 |
|---|---|---|---|
| 표지·요약·예고 큰 글 (명조) | 100px, 700 | 학습지 제목 (명조, 흰 글자) | 28px, 700 |
| 장 제목 (명조) | 68px, 700 (확인 문제 질문 64px) | 마디 제목 Ⅰ·Ⅱ (명조) | 20px, 700 |
| 명조 문장·예시 답 | 52~56px | 주제·활동 제목 (명조) | 16px, 700 |
| 본문·보기·핵심 줄 | 40~46px | 문항 글·보기·지시문 | 15px |
| 머리말 칩 | 28px, 700 | 개념 정리 줄·표·상자·학습 목표·용어 낱말 | 14px |
| 칩 | 30px, 700 | 칩·이름표·용어 풀이 글·연표·쪽 번호 | 12px |
| 과목 줄·쪽 번호 | 26px | | |

- 학습지 글자 크기는 위 여섯 가지(12·14·15·16·20·28px)만 쓴다. 안쪽 간격은 4·8·12px, 모서리는 상자 10px·이름표 6px·칩 둥근 끝.
- 슬라이드는 40px(20pt)보다 작은 본문을 쓰지 않는다. 안 들어가면 장을 나눈다.
- 학습지는 12px보다 작은 글자를 쓰지 않는다(그림 속 글자 포함). 안 들어가면 쪽을 늘린다.

## 4. 정렬

- 슬라이드: 제목, 설명, 핵심 줄, 지시는 **왼쪽 정렬**이다. 보기 카드, 연습 카드, 칸(cols), 표 안 글자는 가운데.
- 학습지: 제목·마디 제목·개념 정리 줄·지시문·자료 글·쓰기 칸은 왼쪽. 표 안 글자, 이름표, 칩은 가운데.
- 학습지 줄은 한 줄에 들어가게 쓴다. 쓸데없이 두 줄로 넘기거나 들쭉날쭉하게 줄을 바꾸지 않는다.
- 슬라이드 제목은 모든 장에서 같은 높이(위 막대 바로 아래)에 둔다. 장마다 위아래로 움직이지 않는다.

## 5. 이 스타일의 표시

- **슬라이드 틀**: 왼쪽 위 흰 둥근 머리말 칩(파랑 글자) + 오른쪽 위 과목 줄 / 명조 제목 / 맨 아래 진행 막대(노랑 채움)와 "05 / 17".
- **표지**: 왼쪽 남색 칸(퍼져 나가는 점 무늬, 노란 칩, 명조 제목, 노란 짧은 띠, 부제) + 오른쪽 종이색 칸의 주제 선 그림(SVG). 움직이는 배경을 쓰지 않는다(내려받은 pptx에서 사라진다).
- **'핵심' 칩 + 위쪽 남색 선**: 슬라이드 설명 장 맨 아래의 핵심 한 줄.
- **흰 둥근 카드**: 확인 문제 보기, 그림 카드, 정답 띠. 연습 장에서는 흰 7% 투명 카드.
- **장 바탕의 리듬**: 표지(남색+종이색), 설명 = 종이색, 확인 문제 = 하늘색, 학생 활동·차시 예고 = 남색, 요약 = 노랑 한 장.
- **학습지 머리**: 쪽 위·양옆 끝까지 진한 파랑 띠(흰 교과 칩, 흰 이름 칸, 흰 명조 제목) / 아래 연한 하늘색 학습 목표 상자.
- **학습지 마디 띠**: 연한 하늘색 띠 + 왼쪽 파랑 번호 칸(흰 Ⅰ·Ⅱ) + 아래 파랑 선.
- **학습지 개념 정리**: 파랑 동그라미 번호 주제 + 연파랑 이름표 줄 + 오른쪽 머리띠 상자(용어 풀이). 결론을 미리 주는 '한 줄 정리'는 두지 않는다.
- **학습지 머리띠 상자**: 진한 색 머리띠(흰 명조 글자) + 연파랑 테두리 + 아주 연한 바탕. 용어 풀이·연표·도전 과제·마무리·도달 점검.

## 6. 하지 않는 것

- 슬라이드에서: 왼쪽에 색 띠를 붙인 카드, 그라데이션 바탕.
- 학습지에서: 상자 왼쪽의 굵은 색 막대(상자는 네 변 같은 얇은 테두리), 상자끼리 붙여 놓기, 빽빽한 문항 간격, 머리 띠 밖의 넓은 어두운 면, 파랑·노랑 밖의 색, 주제마다 다른 색, 연한 바탕 위 연한 글자, 배경 그림으로 그린 쓰기 줄(인쇄에서 사라진다).
- 진한 그림자, 이모지.
- 장식용 그림. 그림은 정보를 담을 때만 넣는다(그래프, 도식, 시뮬레이션, 표지의 주제 선 그림, 교사가 준 자료).
- 실존 인물·역사 사건을 꾸며 낸 AI 그림.
- 흐린 회색 글자를 `#767676`보다 옅게 쓰기(인쇄하면 안 보인다).
