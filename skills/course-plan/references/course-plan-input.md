# 교과진도평가계획 입력 형식 (make_course_plan.py)

`python scripts/make_course_plan.py 계획.json 계획.hwpx`

한 과목 한 학기분 "교수·학습 및 평가 운영 계획"을 만든다. 중·고는 학교 교과진도평가계획 기본 양식(`assets/course_plan_form_2.hwpx`, 1·2학기 모두)이나 `--form`으로 준 같은 짜임의 학교 양식에 채우고, 초등은 표 중심 보통 양식(흑백, A4 세로)으로 만든다. 만들 때마다 점검 결과를 `점검:` 줄로 알린다. 맨 앞 줄은 언제나 "형광펜 표시 N곳(메모 M개)"이다.

## 1. 학교 규정 표시

- 학교 학업성적관리규정으로 정해야 하는 문장(정기시험 횟수, 반영 비율, 서술형 비율, 기본점수, 결시 인정점, 부정행위, 동점자 처리 등)은 `{"text": "...", "rule": true}`로 쓴다. 그 문장에 노란 형광펜을 칠하고 한글 메모(바꿀 곳 안내와 형광펜·메모 지우는 법)를 단다(초·중·고 모두).
- 중·고 기본 양식의 Ⅷ 결시 처리 표(전입생, 수행평가가 불가능한 신체장애 학생, 기타 예외)는 양식 학교의 글을 그대로 두므로 머리 칸에 표시가 붙는다.
- 수행평가 기본점수 줄(`base`)과 결시 처리 문장(`absence`)은 `rule`을 적지 않으면 표시가 붙는다(`"rule": false`로 끌 수 있다). 기본점수 줄이 없으면 경고한다.
- 중·고 Ⅳ 표의 반영 비율·서술형 비율 칸(비고 열 합 포함)은 늘 형광펜으로 칠하고 첫 칸에 메모를 단다. 양식에 남는 Ⅷ 결시 처리 표의 글도 형광펜과 메모로 표시한다. 초등은 성취기준별 평가 계획 표의 단계 이름 칸을 형광펜으로 칠하고 첫 칸에 메모를 단다.
- 아래 예시의 값은 `grading-rules.md` 3절의 예시 값이다(정기시험 2회 60% / 수행평가 40%, 서·논술형 30% 이상, 기본점수 영역 배점의 20~30%, 결시 인정점 100%·80%, 미인정 결시 최하점의 차하점). **반드시 교사에게 학교 규정 값을 받아 바꾼다.**

## 2. 칸 설명

### info

| 칸 | 뜻 | 형식 |
|---|---|---|
| year, semester | 학년도, 학기 | 2000~2100, 1 또는 2 |
| level | 학교급 | "고", "중", "초" |
| course_type | 성취도 표 종류 | 고: 공통, 선택, 체육·예술, 교양 / 중: 중학교(기본), 체육·예술, 자유학기, 교양 / 초: 초등(기본) |
| grade | 학년 | 고·중 1~3, 초 1~6 |
| subject | 과목 | 글 (40자까지) |
| classes | 대상 학급 | "1반 ~ 10반" |
| credits | 학점 (고만, 고에서는 꼭) | 1~12. 초등에 넣으면 오류 |
| weekly_hours | 주당 수업 시수 (여러 반을 맡아도 한 반 기준) | 1~35. 예정 시간은 이 값으로 "주당 시수 × 수업일 ÷ 5"로 센다(요일은 쓰지 않는다) |
| teachers | 지도 교사 | 이름 목록. 머리에 "OOO (인), OOO (인)"으로 나온다 |
| school, curriculum | 학교 이름, 교육과정 | 문서 정보용 글 |

### calendar (school_calendar.py 형식)

| 칸 | 뜻 |
|---|---|
| start, end | 첫 수업일(또는 학기 첫 주 월요일)과 마지막 수업일, "YYYY-MM-DD" |
| no_class | 수업이 없는 평일: `{"date", "label"}` 또는 `{"from", "to", "label"}`. 공제일수로 세고 비고 칸에 적는다 (공휴일, 재량휴업일, 정기시험 기간). 100개까지 |
| events | 비고 칸에만 적을 일 `{"date", "label"}` (수업일은 줄지 않는다). label은 꼭 쓴다. 100개까지 |
| group | 진도표 한 줄에 묶을 주 수: 정수 1 또는 2 |
| estimated | 학사일정을 받지 못해 날짜를 어림으로 넣었으면 `true`. 진도표의 기간·공제일수·시수/누계에 형광펜을 칠하고 첫 칸에 확인 메모를 단다. 경고로도 알린다 (기본 false) |

- 주당 시수는 `info.weekly_hours`에서 넣는다(calendar에 다른 값을 쓰면 오류).
- 날짜는 반각 숫자 "YYYY-MM-DD"만 받는다. label은 글자만, 3000자까지.
- 진도표 줄 이름은 group 1이면 "1", "2", …, group 2이면 "1~2", "3~4", …(마지막이 홀수면 "21")이다.
- 학기 밖에 있거나 평일이 하루도 없는 no_class 항목(연도를 잘못 쓴 정기시험 등)은 경고한다. 학기에 평일이 하루도 없으면 오류다.
- 교사에게 학사일정을 묻지 않고 만들 때는 그 학교급의 흔한 일정(3월 2일 무렵 개학, 7월 중순 방학, 법정 공휴일)을 넣고 `"estimated": true`로 둔다.

### progress (진도표 Ⅰ)

`[{"weeks": "1~2", "unit": "단원명", "standards": ["[코드]", "[코드]~[코드]"], "methods": "[강의식 수업]\n- …", "focus": "[형성평가] …", "education": ["교통안전교육(3시간)"]}]`

- `weeks`는 달력 줄 이름과 같아야 한다(다르면 오류, 쓸 수 있는 값을 알려 준다).
- 같은 `weeks`를 여러 번 쓰면(담당 교사별·영역별 진도) 중·고 기본 양식은 그 주 한 행의 단원명·성취기준·수업 방법 칸에 이어 쓰고, 초등 보통 양식은 한 주 묶음 안에 줄이 늘고 주·기간·시간·비고 칸이 합쳐진다.
- `methods`와 `focus`는 "수업 방법 및 수업·평가 연계의 주안점" 칸에 이어서 나온다. 수업 방법은 `[대괄호]`로, 주안점 줄은 `-`로 시작한다(없으면 붙인다). 이 칸은 교사가 준 양식에 있을 때만 쓰인다(기본 양식에는 없어 넣지 않고 경고한다).
- `education`: 학교가 이 과목에 배정해 안내한 교육(안전교육, 성교육·양성평등교육 등). 그 주 비고 칸의 학사일정 행사 뒤에 `[교육명(시간)]`으로 쓴다(대괄호가 없으면 붙인다). 교사에게 받은 것만 쓴다. 진도표 어디에도 없으면 첫 비고 칸에 형광펜 칠한 `[학교 안내 교육]` 자리와 메모가 들어간다.
- 진도가 없는 주는 빈칸으로 두고 경고한다(수업일이 하루도 없는 주는 빼고).
- 중·고 기본 양식: 기간은 "3.2.~3.13."(긴 기간은 '~' 뒤에서 줄바꿈), 공제일수는 빨간 글자 "(1)", 행사는 날짜 순서로 쓰고 공휴일·휴업일은 빨간 글자, 정기시험과 그 밖의 행사는 검은 글자다(학교 양식대로). 열 너비는 양식 그대로다.
- 초등 보통 양식: 기간 칸은 "3.30.~" / "4.10." 두 줄로 쓰고, 칸 너비는 글 폭에 맞춰 잡는다.
- 성취기준 코드는 `[10통사1-01-01]`, `[6국02-01]` 꼴만 코드로 센다(`[전 범위]` 같은 글은 세지 않는다).

### evaluation (중·고)

| 칸 | 들어가는 곳 | 형식 |
|---|---|---|
| purpose | Ⅱ 평가의 목적 | 문장 목록 (가. 나. …) |
| direction, policy | Ⅲ 1. 평가의 기본 방향, 2. 평가의 방침 | 문장 목록. 규정 문장은 `"rule": true` |
| kinds | Ⅳ 표 | `{"name", "type": "정기시험"/"수행평가", "method", "max_score", "ratio", "essay_ratio", "standards", "timing"}` |
| rules | 점검 하한 | `{"performance_min": 40, "essay_min": 30}` (학교 규정 값으로) |
| tasks | Ⅵ 수행평가 세부기준 | 아래 |
| cautions | Ⅶ 수행평가 시 유의 사항 | 문장 목록 |
| absence | Ⅷ 결시생의 성적 처리 | 문장 목록 (rule을 적지 않으면 학교 규정 값으로 표시) |
| use | Ⅸ 평가 결과의 활용 방안 | 문장 목록 |
| remote | Ⅹ 원격수업 운영 시 평가 계획 | 문장 목록 |
| achievement_levels | Ⅺ 성취기준 및 성취수준 | 아래 (없으면 Ⅺ에 [작성 필요]와 경고) |

**achievement_levels** (가. 성취기준별 성취수준, 나. 학기단위 성취수준):

```
{"units": [{"name": "단원 이름 ('(1) 단원 이름'으로 나온다)",
            "standards": [{"code": "[코드]", "text": "고시문 원문",
                           "levels": {"A": "…할 수 있다.", "B": "…", "C": "…", "D": "…", "E": "…"}}]}],
 "semester": {"A": ["줄", "줄"], "B": [...], "C": [...], "D": [...], "E": [...]},
 "minimum": ["최소 성취수준 줄 (고 공통과목만)"]}
```

- 수준 이름은 5개까지(체육·예술은 A~C). 진도표의 성취기준이 units에 빠졌거나 빈 수준 진술이 있으면 경고한다.
- 학기단위 성취수준 줄 앞에는 양식의 글머리(⦁ 또는 ●)가 붙는다. `minimum`이 있으면 맨 끝에 "최소 성취 수준" 행이 생긴다.

- Ⅴ 기준 성취율과 성취도 표는 `course_type`으로 정해진다(공통: A~E, E는 40% 이상~60% 미만 + 최소 성취수준 보장지도 문구 / 선택·중학교: E는 60% 미만 / 체육·예술: A~C / 교양: P / 자유학기: P).
- `ratio`, `essay_ratio`는 학기 성적에서 차지하는 %다. `essay_ratio`는 `ratio`보다 클 수 없다.
- `timing`은 "4월 5주", "3월 3주~4월 2주"처럼 쓴다. 적힌 달이 학기 밖이면 경고한다.

**tasks** (과제마다 성취기준 표, 평가 방법 □/■ 줄, 채점 기준 표):

```
{"name": "Ⅳ 표의 수행평가 이름과 같게",
 "standards": [{"code": "[코드]", "text": "고시문 원문 그대로"}],
 "methods": ["프로젝트", "서술·논술"],          # 서술·논술, 구술·발표, 토의·토론, 프로젝트, 실험·실습, 포트폴리오. 그 밖은 ■기타(이름)
 "timing": "3월 3주~4월 2주",
 "areas": [{"area": "평가 영역", "points": 25,
            "elements": [{"name": "평가 요소", "group": "묶음 이름(선택)", "points": 3,
                          "levels": [{"text": "채점 기준", "score": 3}, {"text": "…", "score": 2}]}]}],
 "base": [{"text": "수행과정 미참여 또는 미제출(기본점수)", "score": "7(28%)"}],
 "notes": ["학생 유의사항 (AI 활용 포함)"]}
```

- `group`을 같은 이름으로 이어 쓰면 초등 보통 양식에서는 "자료 분석(12점)"처럼 묶음 칸이 생기고, 중·고 기본 양식에서는 평가 요소 칸 맨 위에 "[자료 분석]"으로 붙는다.
- 평가 척도 칸에는 요소마다 수준 점수를 하나씩 골라 더해 나올 수 있는 합을 큰 것부터 모두 적는다(40개가 넘으면 "최고 ~ 최저").
- 기본 양식은 수준마다 한 열(배점 행 아래 기준 행)이다. 수준 수가 다른 요소는 마지막 수준 칸이 남은 열을 합친다. 교사가 준 양식이 수준마다 한 행(채점 기준 | 배점)이면 그 모양으로 채운다.
- 표가 쪽에 다 들어가지 않으면 다음 쪽에서 시작하고, 한 쪽보다 긴 채점 기준은 평가 요소 경계에서 나눈다(다음 쪽에 영역 칸을 다시 쓴다).
- `notes`가 비면 학생 유의사항 행을 뺀다.

### evaluation (초등)

초등에는 `kinds`, `rules`, `tasks`(정기시험·반영 비율·배점)를 쓰지 않는다. 넣으면 오류다. `info.credits`도 오류다.

| 칸 | 들어가는 곳 | 형식 |
|---|---|---|
| purpose, direction, policy | Ⅱ, Ⅲ | 문장 목록 |
| scale | 평가 단계 | 서로 다른 이름 2~5개, 예: ["잘함", "보통", "노력요함"], ["매우잘함", "잘함", "보통", "노력요함"]. **학교 규정으로 확인** |
| items | Ⅳ 성취기준별 평가 계획, Ⅴ 평가 세부 기준 | `{"timing", "standards": [{"code", "text"}], "unit", "area", "element", "method", "levels": {단계: 성취수준}, "criteria": {단계: 채점 기준}}` |
| absence | Ⅵ 결시자·학적변동자 처리 | 문장 목록 (결시와 학적변동(전입) 처리를 모두) |
| use | Ⅶ 평가 결과 활용과 통지 | 문장 목록 |
| cautions | Ⅷ 평가 시 유의 사항 | 문장 목록 (AI 도구 활용 안내 포함) |

- `levels`와 `criteria`의 열쇠는 `scale`과 같아야 한다(다르면 경고, 빈 단계는 [작성 필요]).
- 초등 글(purpose, direction, policy, cautions, absence, use, items의 method)에 %, 반영 비율, 정기시험, 지필평가, 성취도, A~E, 배점, "10점" 같은 점수 표현이 있으면 경고한다. "점수로 공개하지 않는다"처럼 점수 자체를 부정하는 문장은 괜찮다.
- 1·2학년은 3월이 입학 초기 적응·진단활동 기간이라 3월 평가 시기를 경고한다.

## 3. 점검 (경고로 알린다)

1. 형광펜 수와 메모 수 (맨 앞). 학사일정이 어림(`estimated`)이면 그다음 줄에 알린다
2. 진도표에서 가르치지만 평가(kinds·tasks·items)에 없는 성취기준, 평가에 있지만 진도표에 없는 성취기준. `[A]~[B]` 범위는 펼쳐서 본다
3. 반영 비율 합 100%, 수행평가 비율 ≥ `rules.performance_min`, 서술형 비율 합 ≥ `rules.essay_min` (중·고). kinds가 비면 한 줄로 알리고 비율·이름 점검을 건너뛴다
4. 수행평가: 요소 배점 합 = 영역 배점, 영역 합 = Ⅳ 표 영역 만점(소수 배점은 반올림 오차를 봐줌), 수준 점수가 위에서 아래로 줄어드는지, 가장 높은 수준 = 요소 배점, 기본점수 줄이 있는지와 '7(28%)'의 %가 맞는지, 학생 유의사항에 AI 안내가 있는지
5. 과제 수 = Ⅳ 표의 수행평가 수, 이름이 서로 맞는지, 이름이 겹치는지
6. 정기시험·과제·초등 평가 시기가 학기 안의 달인지 (Ⅳ 표와 세부기준에 같은 과제가 있으면 한 번만 보고, 두 곳의 시기가 다르면 알린다)
7. 학사일정: 공휴일 누락, 학기 밖이나 주말뿐인 수업 없는 날, 개학일과 학년도, 진도 없는 주, 예정 시간 누계와 기준 수업량(고: 학점 × 16회, 중·초: 주당 시수 × 17주), 학점과 주당 시수 차이
