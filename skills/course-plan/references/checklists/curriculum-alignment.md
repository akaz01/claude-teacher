# 성취기준 정합성 체크리스트

수업 설계, 지도안, 평가 문항, 루브릭을 만든 뒤 이 항목으로 스스로 점검한다.

| # | 항목 | 확인 내용 |
|---|---|---|
| C1 | 교육과정 판별 | `curriculum-transition.md`로 판별한 교육과정(2015/2022 개정)을 결과물에 밝혔는가. 학년도를 그 문서의 판별 절차 1번으로 정했는가 (11~2월이면 이번 학년도인지 다음 학년도인지 확인했거나, 질문 없이 진행해 정한 값을 적었는가) |
| C2 | 성취기준 출처 | 성취기준 코드와 문장은 사용자가 준 것이거나 `curriculum/` 데이터에 있는 것인가. 아니면 [확인 필요]로 표시했는가 |
| C3 | 목표 연결 | 학습 목표가 성취기준의 핵심 동사와 내용을 담고 있는가 |
| C4 | 활동 연결 | 모든 주요 활동이 학습 목표 중 하나 이상에 기여하는가. 목표와 무관한 활동은 없는가 |
| C5 | 평가 연결 | 평가가 학습 목표를 실제로 확인하는가. 배우지 않은 내용을 평가하지 않는가 |
| C6 | 수준 | 학교급과 학년 수준에 맞는가 (`school-levels.md`) |
| C7 | 시간 | 차시 시간 안에 실제로 할 수 있는 분량인가 |
| C8 | 평가 방법 | 평가 방법(선택형/서술형/수행평가)이 성취기준의 핵심 동사(설계·분석·평가·표현 등)가 요구하는 수행을 실제로 끌어내는가. 예: "실험을 설계할 수 있다"를 선택형 지식 문항으로만 평가하면 걸린다. 그 수행을 서술형이나 수행평가로 보거나, 선택형이라면 설계를 고르고 고치는 문항으로 바꾼다 |

문제가 있으면 결과물을 고친 뒤 무엇을 고쳤는지 한두 줄로 알린다. 모두 통과하면 "성취기준 점검 통과"라고만 쓴다.
