# 학생 개인정보 보호

이름을 지운 자료에 남은 단서를 일반화하고, 문서를 밖으로 내보내기 전에 점검한다. 학생 실명이 든 자료는 이 절차로 처리하지 않고 `references/privacy.md` 2장대로 멈춘다.

## 참고 자료

- `references/privacy.md`: 개인정보 종류, 가명 처리 원칙, 점검 목록 (이 절차의 기준)

**질문 없이 진행해 달라고 할 때.** 교사가 "질문하지 말고", "알아서 끝까지"처럼 바로 결과를 원하면 묻고 확인받는 단계를 건너뛴다. 이 경우에도 지어내지 않는다.
- 빠진 값은 이 절차의 기본값(학교급 기본값 포함)으로 채운다. 핵심 수치도 같다.
- 답변 맨 위에 "기본값으로 정한 내용"을 목록으로 적는다.
- 확인이 필요한 사실은 문서에 `[확인 필요]`로 두고, 답변 맨 아래 "확인 필요" 목록에 모은다.

## 작업 1: 남은 단서 일반화

### 절차

1. `references/privacy.md` 1장의 표로 텍스트 안의 개인정보를 찾는다. 학생이나 보호자의 직접 식별 정보가 있으면 "가명 처리해 줘", "개인정보 지워 줘"라는 요청이어도 대신 지우지 않고 2장대로 멈춘 뒤 7장의 지우는 법을 안내한다.
2. 직접 식별 정보가 없으면 아래 규칙으로 바꾼다.

| 찾은 것 | 바꾸는 방법 |
|---|---|
| 교사 실명 | 담임교사 등 역할 이름. 이름이 든 문장을 통째로 일반화하면 이름도 함께 없애고 역할 이름을 따로 덧붙이지 않는다 |
| 학교명 | 항상 "○○중학교"처럼 학교급만 남긴다 |
| 반 번호 | 반을 구분할 필요가 없으면 지운다. 한 반만 나오면 "○반", 여러 반을 구분해야 하면 "가반, 나반" |
| 민감 정보 (질병, 가정 형편 등) | 작업에 필요하면 일반적인 표현으로 줄임 (예: "부모님이 이혼하여" → "가정 사정으로"), 필요 없으면 삭제. 작업 목적을 모르면 지우지 말고 일반화한 뒤, 요약에 "목적을 몰라 일반화함. 필요 없으면 지워 주세요"라고 적는다 |
| 학생을 알아볼 수 있는 경험 소재 | 이름을 바꿔도 문장 속 경험으로 누구인지 알 수 있으면 일반화한다 (예: 그 학교에 한 명뿐인 특기나 수상 경험) |

3. **결과를 출력한다**: 일반화한 텍스트, 그리고 처리 요약을 낸다.

### 처리 요약 형식

삭제한 값을 요약에 다시 쓰지 않는다.

```
| 종류 | 건수 | 처리 |
|---|---|---|
| 학교명 | 2건 | "○○중학교"로 변경 |
| 민감 정보 | 1건 | "가정 사정으로"로 일반화 |
```

### 가명 대응표

- "학생A = 누구"라는 대조표는 교사가 자기 컴퓨터에서 직접 만들어 그곳에만 둔다. 대화에 올리지 말라고 안내한다.
- 대조표는 다시 식별할 수 있는 열쇠이므로 받지도 만들지도 않는다. 대조표가 올라오면 `references/privacy.md` 2장대로 멈춘다.

## 작업 2: 내보내기 전 점검

교사가 만든 문서(가정통신문, 학급 자료, 보고서 등)를 점검한다.

1. 먼저 받는 사람을 확인한다. 학부모·학급·교내용이면 2~4로 간다. **학교 밖**(외부 전문가, 기관, 업체, 연구자)으로 보내는 것이면 아래 "학교 밖으로 보낼 때"를 따른다. 받는 사람을 모르면 교내용으로 점검하고, 결과에 "학교 밖으로 보낸다면 따로 확인이 필요합니다"라고 한 줄 붙인다.
2. `references/privacy.md` 4장의 점검 목록을 하나씩 확인한다.
3. 결과를 표로 보고한다: 항목, 결과(통과/수정 필요), 위치(몇째 문단).
4. 수정이 필요하면 고친 문서를 함께 준다.

### 학교 밖으로 보낼 때

4장 점검 목록은 교내·학부모용 문서 기준이다. 학교 밖으로 보내는 자료에 건강·상담·가정 사항 같은 민감 정보가 있으면 **"통과"라고 답하지 않는다.** `references/privacy.md` 6장의 항목별로 "갖춤 / 확인 필요 / 수정 필요 / 해당 없음"을 표로 보이고, 보내기 전에 해야 할 일을 목록으로 준다.

```
| 항목 | 상태 | 해야 할 일 |
|---|---|---|
| 목적과 필요성 | 확인 필요 | 보내는 목적과, 각 항목이 왜 필요한지 정리 |
| 제공 근거(동의 등) | 확인 필요 | 보호자 동의를 받았는지, 다른 근거가 있는지 담당자에게 확인 |
| 민감 정보 별도 동의 | 확인 필요 | 건강 정보는 다른 동의와 따로 받아야 함 |
| 만 14세 미만 | 확인 필요 | 동의를 보호자(법정대리인)에게 받았는지 확인 |
| 최소한의 정보 | 수정 필요 | 가족 관계 문단은 목적에 필요 없으면 삭제 |
| 다시 알아볼 위험 | 수정 필요 | "3반" + 질병명 + 가족 사항이 겹치면 이름 없이도 누군지 알 수 있음 |
```

- 마지막 줄은 항상 "보내기 전에 학교 개인정보 보호 담당자와 확인해 주세요"로 끝낸다.
- 민감 정보가 없어도 학생 정보가 학교 밖으로 나가면 같은 표로 점검하고, 결과는 "통과" 대신 "큰 문제 없음, 담당자 확인 권장"으로 쓴다.

## 주의

- 학생 실명이 섞여 있으면 바꿔서 진행하지 않고 멈춘다. 안내 문장은 `references/privacy.md` 2장, 지침 안내의 위치는 5장을 따른다.
- 학교폭력, 아동학대 의심 등 법적 절차가 걸린 내용은 "이 내용은 학교의 공식 절차(학교폭력 전담기구, 아동학대 신고 의무 등)에 따라 처리해 주세요"라고 안내한다. 판단이나 처분을 대신 내리지 않는다.
