# 학생부 기록 검토 체크리스트

학생부 초안을 낸 뒤 이 순서로 검토한다. 문장을 쓴 답변에서는 결과를 SKILL.md 5절의 "확인 필요"에 합치고, 교사가 쓴 문장 점검만 할 때는 아래 표로 보고한다. 표는 짧게 쓴다.

## 검토 항목

| # | 항목 | 확인 내용 |
|---|---|---|
| R1 | 기재 금지 내용 | `record-guide.md` 1장의 금지 내용이 없는가: 대회 참여·수상, 교외상, 공인어학·인증시험, 자격증, 논문·출판·특허, 해외 활동, 부모 지위, 장학금, (고) 모의고사·재학 고교를 알 수 있는 내용. 세특이면 K-MOOC·방과후학교·(고) 소논문도. 걸러 낸 것과 뺀 부정적 서술을 알릴 때 종류만 쓰고 구체 값·월·사건을 되풀이하지 않았는가 |
| R2 | 특정 이름 | 대학명, 기관명, 상호명, 강사명, 다른 학생 이름이 없는가 (교육관련기관명 등 예외는 `record-guide.md` 1장) |
| R3 | 글자 수 | 중·고: 항목별 한도(`record-guide.md` 2장, 2026: 세특·창체 500자, 행특 300자)를 넘지 않는가. 가능하면 `scripts/neis_bytes.py`로 확인한다. 초등은 한도 없음 |
| R4 | 근거 | 모든 문장이 교사가 준 자료에 근거하는가. 입력에 없는 활동이나 성과, 겹침을 피하려고 넣은 내용이 없는가. "으레 그렇게 한다"는 짐작으로 더한 행동·산출물이 없는가 (근거 표에 '추정'이라고 적을 내용은 문장에 없어야 한다). 문장의 구절마다 메모의 어느 구절에서 왔는지 짝지어 보고, 짝이 없는 구절(동작, 대상, 결과, 평가)은 지운다. 문장의 근거 자료가 근거 표에 있는가. 근거 쪽수가 `record-guide.md`에 있고 학생의 학교급 판인가, 공식 예시를 확인하지 못했다는 점을 `[확인 필요]`로 밝혔는가 |
| R5 | 구체성 | 평가어만 나열한 문장("성실하고 우수함"), 활동 사실·수량만 있는 문장, 성취기준 문구를 되풀이한 문장이 없는가 |
| R6 | 문체 | 주어 생략, 명사형 어미("~함.") 종결, 특수문자, 가운뎃점(·), 번호 매기기를 쓰지 않았는가. 학생의 실수나 부족했던 모습, "~했으나 ~함" 구조, 이전의 부족을 짐작하게 하는 말("늘어남", "줄어듦", "향상됨", "좋아짐", "정확해짐", "2학기에는 ~을 마침"), 고치기 전의 잘못("오류를 바로잡음"), "빠뜨리지 않음" 같은 부정문, 다툼·갈등 같은 사건을 짐작하게 하는 말, 다른 학생의 부족이나 알아볼 단서("전학 온 친구")를 쓴 문장이 없는가 |
| R7 | 항목 범위 | 과목별 세특은 그 과목 수업 활동만, 영역별 내용은 그 영역에만 담았는가. 글자 수 초과로 옮긴 내용이 없는가 (`record-guide.md` 3-2) |
| R8 | 겹침 | 아래 판정표로 본다 |
| R9 | 개인정보 | 학생 실명이 든 자료로 쓰지 않았는가(`privacy.md` 2장의 멈춤). `privacy.md` 3장(파일 이름·문서 속성 등 첨부 파일 속 식별 정보)과 4장 점검을 통과하는가 |
| R10 | 생성형 AI 안내 | 결과물이 초안이며, 교사가 실제 관찰과 맞는지·허위·과장이 없는지 확인한 뒤 입력해야 한다고 알렸는가 (2026 기재요령 신설 조항) |
| R11 | 수행 주체 | 교사가 직접 보았거나 허용된 학생 자료에서 확인되는가. 수업 밖 과제, 채팅, 댓글, 온라인 모둠 기록만을 근거로 쓴 문장이 없는가 (`record-guide.md` 3-1) |
| R12 | 학생 작성 자료 | 학생부에 쓰려고 받은 글을 쓰지 않았는가. 쓴 자료가 동료평가서, 자기평가서, 수업산출물, 소감문, 독후감 안에 드는가. 학생의 각오·다짐이 문장에 옮겨지지 않았는가. 학생·학부모에게 학생부용 글을 요구하면 안 된다고 직접 알렸는가 |
| R13 | 참여 확인 | 일괄 작성한 활동에 그 학생이 실제로 참여했는가. 결석 등으로 빠진 활동이 문장에 없는가 (`record-guide.md` 3-3) |
| R14 | 평가 연결 | (세특) 평가 과제와 성취기준에서 문장을 거슬러 찾을 수 있는가. 평가 기준이 없는데 수준 낱말을 쓰지 않았는가 |

## R8 겹침 판정

교사가 비교 자료를 주면 전년도, 다른 학년 기록까지 본다. 퍼센트 기준은 공식 수치가 없으므로 만들지 않는다.

| 결과 | 조건 |
|---|---|
| 수정 | 문장 전체나 항목 전체가 다른 학생, 전년도, 다른 학년 기록과 같다 |
| 주의 | 수업 맥락 구절 밖의 문장이 같다. 끝 문장의 평가어·전망이 되풀이된다. 첫 문장 틀이 많은 학생에게 겹친다 |
| 통과 | 수업 맥락을 밝히는 구절 하나만 같다 |

"수정"이 나와도 근거가 같으면 문장만 바꾸지 않는다. 그 학생의 근거를 교사에게 묻는다 (R4가 앞선다). 학교 기준이 있으면 학교 기준을 따른다.

## 보고 형식

**통과가 아닌 행만 쓰고, 나머지는 "그 외 통과" 한 줄로 쓴다.** 모두 통과면 그 한 줄만 쓴다.

```
| 항목 | 결과 | 비고 |
|---|---|---|
| R3 글자 수 | 주의 | 487자 / 500자 |
| R4 근거 | 수정 | "토론 대회 준비" 부분은 입력에 없어 삭제 |
| 그 외 | 통과 | R1, R2, R5~R14 |
```

결과는 **통과 / 주의 / 수정** 세 가지로 쓴다. "수정"이 하나라도 있으면 고친 최종본을 다시 보여 준다.

여러 학생을 썼으면 끝에 한 문장을 더한다: "같은 과제를 쓴 학생들의 문장은 나란히 놓고 다시 읽어 보세요."
