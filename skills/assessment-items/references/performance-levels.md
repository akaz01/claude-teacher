# 공용 용어와 수준 진술

평가 칸을 쓰는 모든 스킬(지도안, 학습지, 수행평가, 출제)이 같은 말과 같은 기준을 쓰도록 모은 표다.
학교 양식이나 교과협의회가 쓰는 말이 있으면 그 말이 먼저다.

## 공용 용어

| 용어 | 뜻 | 주의 |
|---|---|---|
| 내용 영역 | 교육과정의 영역 (예: 듣기·말하기) | 지도안 머리표의 "영역"이 이것이다 |
| 평가 영역 | 만점이 있는 수행평가 단위 | "영역"만 쓰지 말고 앞말을 붙인다 |
| 평가 요소 | 성취기준 도달의 증거로 보여 주기를 기대하는 핵심 내용 | 평가 영역 안에 있고 배점이 있다. 지도안 평가표와 수행평가표에서 같은 뜻이다 |
| 채점 요소 | 평가 요소를 나눈 채점 단위 | 서·논술 표에서 쓴다 |
| 수행 수준 | 칸에 쓰는 학생 행동 진술 | |
| 성취수준 | 성취기준 또는 학기 단위의 A~E 등 | 과제 하나의 점수와 구별한다 |

층의 순서: 평가 영역(만점) → 평가 요소(배점) → 채점 요소(서·논술일 때) → 수행 수준.

## 수준 진술의 원칙

- 학생 답 두 개를 교사가 망설임 없이 가를 수 있어야 한다.
- 평가 요소마다 아래 일곱 축 가운데 **하나**를 고른다. 한 표 안에서 요소마다 다른 축을 써도 된다.
- 수준 사이의 차이는 빠진 것의 이름으로 적는다. 관찰 목록을 괄호에 넣어야 "두 가지"가 판정된다.
- 학생의 가치가 아니라 수행의 상태를 쓴다.
- 단계 수와 단계 이름은 학교·지역이 정하는 값이다. 묻고, 묻지 못하면 스킬의 기본값을 쓰고 가정했다고 밝힌다.
- 학생에게 주는 자료에는 수준 이름을 보이지 않는다.

## 일곱 축

아래 예시는 형식을 보이려고 새로 지은 문장이다.

| 축 | 가르는 방법 | 잘 맞는 곳 | 예시 (높은 수준 → 낮은 수준) |
|---|---|---|---|
| 수 | 다룬 관점·조건·근거의 개수 (괄호에 목록) | 사회, 기술·가정, 영어 쓰기 | 원인을 (정치, 경제, 사회) 가운데 세 측면에서 분석함 → 두 측면 → 한 측면 |
| 과정 | 어느 단계까지 했는가 | 과학 탐구, 실험 | 측정, 표 정리, 그래프, 결론까지 함 → 그래프까지 함 → 측정까지 함 |
| 정확성 | 오류 없는 풀이·근거의 수 | 수학, 과학 | 세 문제를 오류 없이 풂 → 두 문제 → 한 문제 |
| 깊이 | 제시 → 설명 → 평가, 결론 → 정당화 | 국어, 사회, 수학 | 주장과 근거를 쓰고 근거의 한계를 밝힘 → 주장과 근거를 씀 → 주장만 씀 |
| 연결 | 원인·과정·결과나 원리로 이었는가 | 과학, 서·논술 | 원인, 과정, 결과를 이어 설명함 → 원인과 결과만 씀 → 원인이나 결과 하나만 씀 |
| 독립성 | 스스로 → 예시 참고 → 낱말 참고 | 초등, 영어 기초 | 스스로 문장을 씀 → 예시 문장을 보고 씀 → 낱말 목록을 보고 씀 |
| 범위 | 낯선 상황 → 배운 상황 → 주어진 예 | 지도안 평가 | 배우지 않은 상황에 적용함 → 수업에서 다룬 상황에 적용함 → 주어진 예를 설명함 |

## 유일한 차이로 쓰지 않을 말

수준 사이의 차이가 아래 말뿐이면 두 교사가 같은 판단을 내리기 어렵다. 다른 판정 근거와 함께 쓰는 것은 괜찮다.

- 정확하게, 명확하게, 구체적으로
- 비교적, 대략적으로, 어느 정도
- 간단하게, 부분적으로, 제한적으로
- 모두 / 대부분 / 일부
- 약간 미흡 / 미흡

바꾸는 법:

| 이렇게 쓰지 않는다 | 이렇게 바꾼다 |
|---|---|
| 변인을 모두 찾음 / 대부분 찾음 / 일부 찾음 | (조작 변인, 종속 변인, 통제 변인) 가운데 세 가지를 찾음 / 두 가지 / 한 가지 |
| 구체적으로 설명함 / 간단하게 설명함 | 사례를 들어 이유를 설명함 / 이유만 씀 |
| 정확하게 계산함 / 부분적으로 계산함 | 두 단계 모두 오류 없이 계산함 / 첫 단계만 오류 없이 계산함 |
| 약간 미흡함 / 미흡함 | 빠진 조건을 이름으로 적음 (예: 출처를 쓰지 않음) |

부사로 나눌 수밖에 없는 교과는 표와 함께 교과협의회용 어휘표를 낸다. 어휘표에는 그 말을 어떤 답에 쓸지 교사들이 정한 뜻을 적는다.
