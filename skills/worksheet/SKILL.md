# 학습지·활동지 제작

수업 목표에 맞는 학습지를 만들고 학생용과 교사용을 함께 낸다. 결과는 **한글(hwpx) 파일이 기본**이다(6절). 교사가 앱 디자인 학습지를 원할 때만 A4 디자인 학습지(`references/app-worksheet.md`)로 만든다. 디자인은 누가 쓰든 `references/house-style.md` 그대로다.

**교사에게 하는 안내·질문·설명은 모두 한국어로 쓴다.** (작업 중 도구 출력이 영어여도 답변은 한국어)
**답변 순서는 `references/answer-order.md`를 따른다.** (작업 중 설명 문장을 답변 맨 위에 쓰지 않는다)
**시작할 때 꼭 묻는다.** 학습지 양식과 교과서 쪽 PDF는 첫 응답의 1번 질문으로 함께 요청하고 따로 다시 묻지 않는다. 둘 다 받았거나 질문 없이 진행할 때는 1번 질문에서 그 부분을 뺀다.
**교과서 파일을 받으면 범위부터 묻는다.** 교과서 PDF가 첨부되면 "교과서 몇 쪽부터 몇 쪽까지 학습지로 만들까요?"라고 묻고, 답을 받은 뒤 시작한다. 교사가 이미 범위를 말했으면 묻지 않는다. 쪽 번호는 PDF 쪽수가 아니라 교과서에 인쇄된 쪽 번호로 맞춘다. 질문 없이 진행할 때는 첨부 파일 전체를 범위로 잡고 "기본값으로 정한 내용"에 적는다.

## 1. 한 번에 요청하기

`[교사 프로필]`에 있는 정보는 묻지 않는다. 나머지를 한 메시지로 요청한다.

```
학습지를 만들기 위해 알려 주세요. 없는 것은 "없음"이라고 해 주시면 됩니다.

1. 학년, 교과, 단원·차시 (지도안, 교과서 쪽 PDF, 학교 학습지 양식이 있으면 함께 올려 주세요)
2. 유형과 분량: 개념 정리 / 활동지 / 형성평가 / 복습, 몇 쪽 (기본: 개념 정리, 1~2쪽)
3. 학생 수준 차이: 같은 쪽 도전 과제 / 기초·기본·심화 따로 (기본: 같은 쪽 도전 과제)
```

위 문구는 그대로 쓰고 다른 말을 더하지 않는다. 교사가 이미 말한 값은 항목에서 빼고, 모두 빠진 항목은 지운 뒤 번호를 다시 매긴다. 교육과정 설명, 찾은 성취기준, 바로 만들 때의 구성 설명을 질문 앞뒤에 붙이지 않는다. 11~2월이고 교사가 학년도를 말하지 않았으면 `references/curriculum-transition.md` 판별 절차 1번의 학년도 질문을 목록 맨 앞 번호로 넣는다. 교육과정이 두 학년도에 같아도 묻는다.

교사가 올린 양식이 hwp 파일이면 "한글에서 hwpx로 저장해 다시 올려 주세요"라고 안내한다. 쓰임(수업 중·과제·보충 지도)은 묻지 않고 "수업 중"으로 두며, 교사가 말하면 그에 따라 분량과 도움의 양을 달리한다. 교사가 바로 만들어 달라고 하면 기본값(개념 정리 학습지, 1~2쪽, 같은 쪽 도전 과제, 수업 중, 한글 hwpx 파일)으로 진행한다. 묻지 않고 정한 값은 답변 맨 위 "기본값으로 정한 내용"에 적는다.

**질문 없이 진행해 달라고 할 때.** 교사가 "질문하지 말고", "알아서 끝까지"처럼 바로 결과를 원하면 묻고 확인받는 단계를 건너뛴다. 이 경우에도 지어내지 않는다.
- 빠진 값은 이 스킬의 기본값(학교급 기본값 포함)으로 채운다. 핵심 수치도 같다.
- 답변 맨 위에 "기본값으로 정한 내용"을 목록으로 적는다.
- 확인이 필요한 사실은 문서에 `[확인 필요]`로 두고, 답변 맨 아래 "확인 필요" 목록에 모은다.

## 2. 양식 샘플을 받았을 때

샘플의 내용(문제, 학생 답)은 가져오지 않는다. 파일에 채울 수 있으면 아래 "양식 파일을 받으면"을 먼저 따른다. 채울 수 없거나(사진, PDF) 다음에도 같은 양식을 쓰려면 형식만 뽑아 `[학습지 양식]` 블록으로 정리한다.

```
[학습지 양식]
- 머리 부분: (예: 상단 표에 단원명 / 학습 목표 / 학년·반·번호·이름)
- 활동 표시: (예: "활동 1", "STEP 1", "생각 열기 → 생각 넓히기 → 생각 정리")
- 답 칸 형태: (예: 네모 칸 / 밑줄 / 표)
- 마무리: (예: 스스로 평가 표, 배운 점 한 줄 쓰기)
- 분량: (예: A4 1쪽)
```

이 블록을 프로젝트 지침에 저장하면 다음부터 같은 양식으로 만든다고 안내한다.

**양식 파일을 받으면 그 파일에 내용만 채운다.** 용지, 문단 모양, 글자 모양과 크기를 바꾸지 않는다.

1. hwpx 양식은 `references/form-fill.md` 순서대로 `scripts/fill_hwpx.py`로 채운다. 학생용과 교사용을 따로 채운다. 학생용 지시 파일에는 답을 넣지 않고 답 칸을 비워 둔다.
2. 양식의 글자 모양을 따르므로 교사용 답은 파랑·굵게가 되지 않는다. 답변에 이 점을 적는다.
3. hwp 파일은 채울 수 없다. 한글에서 hwpx로 저장해 다시 올려 달라고 안내한다.
4. 양식 파일 없이 샘플을 보고 칸을 새로 짰으면 답변에 "항목과 순서만 맞췄고 모양은 다를 수 있습니다"라고 알린다.

## 3. 내용 구성

### 교육과정과 학년 확인 (만들기 전에)

1. `references/curriculum-transition.md`로 학년의 적용 교육과정(2015/2022 개정)을 판별해 교사용 파일 머리에 적는다 (`references/checklists/curriculum-alignment.md` C1).
2. 성취기준은 교사가 준 것을 쓴다. 주지 않았으면 `references/curriculum-lookup.md` 절차로 단원·주제의 성취기준을 찾는다. 데이터에 없으면 교사에게 붙여 넣어 달라고 요청하고, 받기 전에는 `[확인 필요]`로 둔다. 성취기준 문장과 코드를 기억으로 쓰지 않는다 (C2).
3. 찾은 성취기준의 학년(군)·영역이 요청한 학년·단원과 맞는지 본다. 어긋나면 만들기 전에 알리고 교사의 교과서 단원을 확인받는다. 예: 2022 개정에서 광합성은 [9과12] "식물과 에너지"로 중학교 1~3학년군 성취기준이며 보통 중학교 2학년에서 배운다. "중1 광합성"을 요청받으면 이 점을 알린다. 질문 없이 진행할 때는 요청대로 만들고 어긋난 점을 "확인 필요"에 적는다.

### 기본 형식 (고정)

**누가 이 스킬을 쓰든 같은 형식과 모양의 학습지가 나와야 한다.** 교사가 유형을 말하지 않았으면 아래 개념 정리 학습지로 만든다. 한글(hwpx) 기본 결과는 `scripts/make_worksheet.py`의 `topics` 모드(개념 정리 학습지)가 이 모양으로 만들고, 앱 디자인 학습지(`references/app-worksheet.md` 1·4절)와 같은 모양이다. 색·글꼴·크기는 `references/house-style.md` 그대로다.

1. **머리**: 교과·학년·단원·차시, 제목, 학년·반·번·이름, 학습 목표, 핵심 질문 (지도안의 탐구 질문이 있으면 그 문장을 쓴다)
2. **Ⅰ 주요 개념 및 내용 정리**: 참고서·기존 학습지처럼 체계적으로 정리한다. 번호 주제 3~5개(줄이 많으면 4개) → 주제마다 이름표(배경·과정·결과, 뜻·예·방법 등) → 짧은 줄을 화살표(→)로 잇기. 핵심어 5~8개를 빈칸으로. 오른쪽 칸에 **용어 풀이**(8개 이하, + 연표·순서·식 같은 한눈에 보기 하나). 결론을 미리 주는 '한 줄 정리'는 두지 않는다(학생이 형성평가로 스스로 정리하게). 문장을 카드로 나누지 않고, 줄은 한 줄에 들어가게 쓴다.
3. **Ⅱ 형성평가**: 모두 5~7문항, 학습 목표마다 고르게 나눈다(선택형·단답형·O·X·서술형 섞기. 단답·O·X만이면 10문항까지). 2쪽에 다 들어가야 한다.
4. **도달 점검**: 학습 목표를 "나는 ~할 수 있다."로 바꿔 줄마다 예 / 아니요.

활동지(관찰·탐구·토의)를 원하면 Ⅰ 자리에 아래 활동 구성을 쓴다.

### 활동지 구성

교육청과 학교 공개 활동지의 공통 구조를 따른다. `scripts/make_worksheet.py`의 머리가 이 순서로 나온다.

1. **머리**: 교과·단원·차시 띠 → 활동 제목 → ( )학년 ( )반 ( )번 이름 → 학습 목표, 핵심 질문 (지도안의 탐구 질문이 있으면 그 문장을 쓴다)
2. **쉬운 입구**: 첫 활동을 일상 소재, 그림, 구체물, 이전 학년 개념 가운데 하나로 연다.
3. **활동 블록** 2~4개: 소제목 → 지시문 → 자료 상자(있으면) → 답 칸. 칸은 아래 "칸 설계"대로 고른다.
4. **마무리**: 유형에 맞게 하나를 고른다 (`closing`).

| 마무리 | 값 | 어울리는 유형 |
|---|---|---|
| 도달 점검: "나는 ~할 수 있다." 줄마다 예 / 아니요 | `reach` | 개념 정리 |
| 스스로 평가: 줄마다 별 다섯 개에 색칠 | `check` | 활동지 |
| 배움 성찰: 새롭게 알게 된 점 / 더 알고 싶은 점 | `reflect` | 활동지 |
| 스스로 평가와 배움 성찰 둘 다 | `auto` (기본값) | 활동지 |
| 생략 | `none` | 형성평가, 복습 |

교사 양식에 마무리 칸이 있으면 양식을 따른다.

### 유형별

| 유형 | 구성 |
|---|---|
| 개념 정리 (빈칸형) | 교과서 핵심 문장을 요약해 핵심어를 `[[답]]`으로 비움. 빈칸은 한 문장에 1~2개. 규칙 나열, 순서 배열, 기호 빈칸은 예외다 |
| 활동지 | 관찰·탐구·토의 활동의 단계별 지시와 기록 칸 |
| 형성평가 | 수업 중에 푸는 한 장. 학습 목표마다 1~2문항, 선택형과 서술형 섞기. 문항 품질은 `assessment-items` 스킬 기준을 따름. 문항정보표나 정답 및 채점기준 파일이 따로 필요한 평가는 `assessment-items` 스킬이 맡음 |
| 복습 | 개념 확인 → 적용 문제 → 종합 문제 (결론을 미리 주는 정리 상자는 두지 않음) |

### 칸 설계

활동은 나열하지 않고 앞 칸의 결과가 뒤 칸의 재료가 되게 잇는다. 칸이 곧 학생이 할 생각의 틀이다.

1. **거꾸로 짠다.** 마지막 활동에서 학생이 해낼 일을 먼저 정하고, 그 일에 필요한 칸을 앞에 놓는다.
2. **사슬로 잇는다.** 뒤 활동의 지시문에 앞 활동의 결과를 쓰라고 밝힌다. 예: "활동 1의 표를 보고 두 조건의 차이를 쓰세요."
3. **낮은 칸에서 높은 칸으로.** 고르기·빈칸 → 표 → 문장 틀 → 자기 말로 쓰기 순으로 놓는다.
4. **표의 행과 열에 분석 틀을 넣는다.** 칸 이름에 답의 구조를 쓴다. 학생이 사례를 더할 수 있게 빈 행을 하나 남길 수 있다.
5. **서술 칸에는 도움을 하나 넣는다.** 문장 틀, 칸 이름, 회색 첫 문장 가운데 고른다. 도전 과제는 뺄 수 있다.
6. **예시가 답을 대신하지 않게 한다.** 다른 소재의 예시나 첫 문장만 주고, 예시만 준 채 바로 쓰게 하지 말고 단계 칸과 함께 준다. 수행평가 대비 활동지라면 정답이 드러나는 기준은 교사용에 두고 학교 평가 규정을 따른다.
7. **도움은 그 자리에 둔다.** 필요한 개념은 그 문항 바로 앞 도움말 상자에 쓴다. 앞쪽 설명으로 돌려보내지 않는다. 어려운 낱말은 처음 나올 때 풀이한다.
8. **칸 크기는 답 길이에 맞춘다.** 단답은 1줄, 서술은 3~5줄. 수학 풀이와 그림은 줄 없는 공간으로 둔다.

**빈칸 만드는 법**

- 문장은 완성해 두고 핵심 낱말만 비운다. 한 문장에 1~2개가 원칙이다. 규칙 나열, 순서 배열, 기호 빈칸은 여러 칸을 쓸 수 있다.
- 한 상자에서 여러 개념을 가를 때는 ㉠, ㉡ 기호를 넣고 아래에 기호별 답 줄을 둔다.
- 답이 여럿 나올 수 있으면 단서, 보기, 첫 글자로 좁히거나 인정 답안을 적는다.
- 순서 배열과 표는 첫 칸을 채워 답하는 법을 보여 줄 수 있다.
- 조사가 답을 드러내면 "을/를"처럼 열어 둔다.

**칸 종류** (`parts`의 `kind`)

| 칸 | 쓰는 때 |
|---|---|
| `text` | 지시문. 문장 속 빈칸 `[[답]]`도 여기에 쓴다 |
| `card` / `source` | 개념 상자 / 자료 상자 |
| `hint` | 문항 바로 앞 도움말. 다음 칸과 같은 쪽에 놓인다 |
| `choices` | 보기 상자 |
| `lines` / `space` | 점선 쓰기 줄 / 줄 없는 풀이·그림 공간 |
| `labels` / `grid` | 왼쪽 이름표 칸 / 머리행이 있는 표 |
| `frame` | 문장 틀. `starter`는 회색 첫 문장, `text`는 앞뒤가 인쇄된 문장 |
| `steps` | 활동 순서, 단계 표. 기록할 단계에 `lines`를 준다 |
| `challenge` | 같은 쪽 도전 과제 |

**교과별 활동 흐름**

| 교과 | 흐름 | 알맞은 칸 |
|---|---|---|
| 국어 | 문단 정리 → 비교 → 평가. 쓰기는 일상 소재 → 개요 → 초안 → 고쳐쓰기 | 문단별 `grid`, 비교 `grid`, `frame` |
| 영어 | 그림 → 문장 → 순서 → 글. 쓰기는 구조 → 문장 → 개요 → 초안 | 문장 빈칸, 첫 칸을 채운 `grid`, `choices`, `frame` |
| 수학 | 선수 학습 점검 → 구체물 → 개념 상자 → 기본 문제 → 적용 | `card`, `space`, 문장 빈칸 |
| 사회 | 자료 → 개별 정리 → 모둠 분석 → 개별 정리 | `source`, 행이 분석 틀인 `grid`, `steps`, `frame` |
| 과학 | 의문 → 가설 → 실험 설계 → 결과 → 결론 | `frame`, 변인·결과 `grid`, `space` |

### 작성 기준

- 지시문은 할 일이 바로 보이게 동사로 끝낸다. 예: "그림을 보고 알맞은 낱말을 쓰세요."
- 지시문 하나에 할 일은 하나만 준다. 순서가 많은 모둠 활동은 맨 위에 `steps`로 순서를 주고 아래에 기록 칸을 둔다.
- 개별, 모둠, 읽기 자료 구분을 활동 제목에 적는다. 예: "활동 2. (모둠) 결과를 비교해 봅시다."
- 활동마다 예상 시간을 교사용에 적는다 (`time`). 합이 차시를 넘으면 활동을 줄이고 줄인 내용을 답변에 적는다.
- 교과서 PDF를 받았으면 내용과 용어를 교과서에 맞추고, 관련 쪽을 "교과서 ○○쪽"으로 안내한다.

### 학교급별

| 학교급 | 기준 |
|---|---|
| 초 1~2학년 | 큰 글씨, 한 문장 15자 안팎, 활동 2~3개, 그림 중심 |
| 초 3~6학년 | 해요체, 학습 용어는 처음에 뜻 풀이, 활동 3개 안팎 |
| 중·고 | 교과 용어 정확히, 자료 해석과 서술형 비중 높임 |

### 그림과 자료

- **교사가 준 PDF와 자료 파일은 수업용이므로 그대로 가져다 쓴다.** 지문, 표, 핵심 문장을 옮겨 쓰고 출처 쪽("교과서 ○○쪽")을 함께 적는다.
- 교사가 준 자료에 그림이 있으면 그 그림을 쓴다. A4 디자인 학습지에서는 사실을 담은 도식(입자 모형, 순서 그림, 간단한 구조도)을 SVG로 직접 그릴 수 있다. 사진이나 실물 그림이 필요하면 `[그림: 씨앗이 싹트는 모습]`처럼 무엇을 넣을지 적어 둔다. hwpx 파일에는 그림을 그리지 않고 자리만 적는다.
- 교사가 주지 않은 외부 자료(인터넷 글, 다른 출판사 자료)를 기억에 의존해 옮기지 않는다.
- 자료 상자 끝에 출처를 적고, 재구성했으면 재구성했다고 적는다. 영상과 누리집은 검색일을 적는다.
- 활동 중에 나눌 읽기 자료는 별도 쪽으로 두고 언제 나눌지 교사용에 적는다 (`tip`).
- 특정 앱이 꼭 필요한 활동은 앱 없이 하는 방법도 교사용에 적는다.
- 실존 학생 이름, 학생 글, 학교 이름을 예시로 쓰지 않는다. 예시 인물은 가상으로 둔다.

## 4. 수준 차이 다루기

**기본은 한 장이다.** 세 벌은 교사가 요청할 때만 만든다. 교사가 고른 방식을 따르고, 고르지 않았으면 같은 쪽 도전 과제로 만든다.

| 방식 | 만드는 법 |
|---|---|
| 같은 쪽 도전 과제 (기본) | 한 장 끝에 `challenge` 칸을 둔다. 앞 활동을 마친 학생이 이어서 한다. 개념 정리 학습지(기본 형식, `topics`)는 최상위 `challenge` 칸(`text`, `lines`, `answer`)에 새 상황에 적용하는 과제를 쓴다. 학생에게는 "도전 과제" 칸으로 Ⅱ 형성평가 문항 뒤에 나온다. 넣지 않고 건너뛰지 않는다 |
| 한 장 + 교사용 수준별 피드백 | 학생용은 그대로 두고 활동의 `tip`에 수준별 피드백을 적는다. 답을 말하지 않고 다시 떠올리게 하기, 단서 주기, 예시 보여 주기로 나눈다 |
| 진단 후 보충·기본·심화, 기초·기본·심화 세 벌 | 요청할 때만. 같은 학습 목표로 아래 표처럼 만든다 |

| 수준 | 바꾸는 방법 |
|---|---|
| 기초 | 내용을 줄이지 않고 도달할 최소 행동에서 시작한다. 쉬운 말 풀이 → OX나 보기 확인 → 예시 상자와 빈칸 → 사례 고르기 → 간단한 마무리 → 예·아니요 도달 점검 순으로 놓는다 |
| 기본 | 표준 버전 |
| 심화 | 보기 없음, 적용·설명 문항 추가, 새로운 상황에 적용 |

고등 공통과목의 최소 수행 특성은 교사가 준 것이나 공식 자료에서 확인한 것만 쓴다. 기억으로 쓰지 않는다.

학생에게 수준 이름이 보이지 않게 한다. 세 벌이면 제목 끝에 기호(★ / ★★ / ★★★ 또는 A·B·C 코스)만 붙인다. 교사용 평가 칸을 요청받으면 `references/performance-levels.md`의 축으로 학생 행동의 차이를 쓴다. 특수교육 대상이나 한국어 학습자를 위한 변형을 요청받으면 같은 성취기준을 유지하고 도움의 양만 달리하며, 진단명은 쓰지 않는다.

## 5. 점검

`references/checklists/curriculum-alignment.md`의 C1~C8로 점검한다 (C1, C2는 3절 처음에 확인한 것). 특히:
- 모든 활동이 학습 목표와 연결되는가
- 차시 시간 안에 끝낼 수 있는 분량인가
- 정답이 하나로 정해지는가 (빈칸형, 형성평가). 답이 여럿이면 단서로 좁히거나 인정 답안을 적었는가
- 정답을 다시 풀어 검산했는가 (계산, 수식, 빈칸 답은 문제를 처음부터 다시 풀어 교사용에 적은 답과 맞춘다)
- 뒤 활동이 앞 활동의 결과를 쓰는가
- 서술 칸에 도움이 있는가 (도전 과제 제외)
- 활동 번호와 칸 구성이 학생용과 교사용에서 같은가
- 학생용에 답, 교사 안내, 수준 이름이 남지 않았는가
- 교사용의 모든 빈칸과 서술 칸에 답이나 채점 포인트가 있는가 (`--teacher`로 만들 때 나오는 "답이 없는 칸" 주의를 확인한다)
- 흑백으로 인쇄해도 답과 회색 예시가 구분되는가 (답은 색과 굵기를 함께 쓴다)
- 형식이 기본 형식(또는 교사가 고른 유형)과 같고, 부품과 색이 `house-style.md` 밖으로 나가지 않았는가
- 개념 정리의 줄, 용어 풀이 줄이 한 줄에 들어가는가 (쓸데없이 두 줄로 넘기지 않는다)

## 6. 파일 만들기

### 만드는 방법 고르기

| 상황 | 방법 |
|---|---|
| 교사가 학교 학습지 양식(hwpx)을 줬다 | 2절에 따라 그 파일에 채운다 (`fill_hwpx.py`) |
| 양식이 없다 (기본) | **한글(hwpx) 학습지.** 아래 `make_worksheet.py`로 학생용·교사용 hwpx를 만든다 |
| 교사가 앱 디자인 학습지를 원했고, 환경에 클로드 앱의 디자인 기능이 있다 (claude.ai) | **A4 디자인 학습지.** `references/app-worksheet.md`와 `references/house-style.md`를 따른다. 학생용·교사용 쪽을 앱 캔버스로 만들고, 교사가 고친 뒤 PDF로 인쇄한다 |

어느 방법이든 3~5절 내용 규칙을 같게 지킨다. 아래는 hwpx로 만들 때의 설명이다.

교사 양식 파일이 있으면 2절에 따라 그 파일에 채운다. 없으면 입력 파일 하나로 두 파일을 만든다.

```bash
python scripts/make_worksheet.py 입력.json 학습지_학생용.hwpx
python scripts/make_worksheet.py 입력.json 학습지_교사용.hwpx --teacher
```

모든 교과가 같은 파랑 계열 색이다(`house-style.md`). 표 안 글자와 지시문은 기본으로 가운데 정렬한다. 교사 양식이 있으면 양식이 우선이다.

1. **학생용**: 문제와 답 칸만. `answer`와 교사용 값은 파일에 들어가지 않는다.
2. **교사용**: 학생용과 같은 칸 구성을 유지하고 칸 안에 답을 파랑·굵게 넣는다. 답 칸을 문단으로 바꾸지 않는다. 머리에 적용 교육과정과 성취기준을 적는다 (`curriculum`, `standards`).
   - **입력 쓰는 법**: 빈칸 `[[답]]`, 답 칸 `answer`, 예시 답안 `model`, 채점 포인트 `point`, 인정 답안 `accept`, 입력 예시, 쪽 나뉨은 `references/worksheet-hwpx-input.md`를 따른다.
   - **기본 깊이**: 답, 풀이·인정 답안, 채점 포인트까지다. 번호별 지도 메모와 수준별 피드백은 요청받으면 `tip`에 쓴다.

- **분수·수식**: `{{2/3}}`처럼 `{{ }}`로 감싸면 한글 수식이 된다. 안은 LaTeX가 아니라 한글 수식 문법이다(`references/equations.md`). **수식이 든 칸은 넓게** 잡는다. 분수 밖의 복잡한 식은 한글에서 열어 확인하라고 답변에 적는다.
- **쪽 수**: 생성기는 만든 파일이 몇 쪽인지 알려 주지 않는다. "A4 2쪽 이내"처럼 쪽 수를 정했으면 답 칸 줄 수와 표 높이를 넉넉히 잡아 보수적으로 어림하고(1쪽에 활동 2개 안팎), 답변에 "쪽 수는 한글에서 열어 확인해 주세요"라고 적는다. 교사용은 교사용 칸이 더해져 쪽 나뉨이 학생용과 다를 수 있다. 쪽 수를 맞췄다고 단정하지 않는다.
- 세 벌을 요청받았으면 버전마다 파일을 만든다 (예: `학습지_★.hwpx`). 파일 이름에도 수준 이름을 쓰지 않는다.
- 파일로 낼 때는 한글 hwpx로 낸다. 학교는 워드를 쓰지 않으므로 .docx로 만들지 않고, hwp가 아니라 hwpx로 저장한다.
