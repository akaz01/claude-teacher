# A4 디자인 학습지 (클로드 앱 디자인 캔버스, 교사가 원할 때)

**쓰는 때**: 교사가 앱 디자인 학습지를 원했고, 지금 환경에 클로드 앱의 디자인(Design) 기능이 있을 때 (claude.ai 등). 기본 결과는 한글(hwpx) 파일이다(SKILL.md 6절). 결과는 앱 캔버스의 A4 쪽들이고, 교사는 브라우저에서 글을 고친 뒤 PDF로 내려받아 인쇄한다.

**쓰지 않는 때**
- 교사가 학교 양식 hwpx를 줬다: SKILL.md 2절에 따라 그 파일에 채운다.
- 교사가 한글 파일(hwpx)을 달라고 했거나 앱 디자인 기능이 없다: SKILL.md 6절의 `make_worksheet.py`로 만든다.

**형식과 스타일은 고정이다.** 누가 이 스킬을 쓰든 같은 모양의 학습지가 나와야 한다. 1절의 형식, `house-style.md`의 색·글꼴·크기, `app-worksheet-example.md`의 마크업을 그대로 쓰고 글만 바꾼다. 학습지마다 새 색, 새 배치, 새 부품을 만들지 않는다. 디자인 시스템은 "teacher-kit 수업 디자인"만 설치한다(`design-system-setup.md`). 다른 디자인 시스템은 교사가 말하지 않았으면 쓰지 않는다.

앱 디자인 기능의 자체 안내(파일 구조, 올리는 방법, 형식 제한)는 따른다. 내용은 SKILL.md 3~5절, 모양은 이 파일과 `house-style.md`가 우선이다.

## 1. 형식 (고정)

**개념 정리 학습지 (기본)** — 교사가 유형을 말하지 않았으면 이 형식이다.

| 쪽 | 차례 | 부품 |
|---|---|---|
| 1쪽 | 머리 | 파랑 머리 띠(교과 칩 · 이름 칸 · 명조 흰 제목 · 교과서 쪽) + 학습 목표·핵심 질문 상자 |
| | Ⅰ 주요 개념 및 내용 정리 | 마디 띠 → 왼쪽 개요(번호 주제 3~5개, 주제마다 이름표 줄) + 오른쪽 옆 칸(용어 풀이 + 교과에 맞는 둘째 상자) |
| 2쪽 | Ⅱ 형성평가 | 마디 띠(맞은 문항 칸) → 문항 5~7개(선택형·단답형·O·X·서술형 섞기) → 도달 점검 |

- **개요는 참고서·기존 학습지처럼 체계적으로** 쓴다. 문장을 카드로 나누지 않는다. 주제마다 이름표(배경·과정·결과, 뜻·예·방법, 원인·전개·영향처럼 교과에 맞는 2~3글자)를 달고, 짧은 줄을 화살표(→)로 잇는다.
- **줄은 한 줄에 들어가게 쓴다.** 개요 줄은 한 줄 약 28자(14px), 용어 풀이 줄은 약 13자(12px), 연표·순서 내용은 약 9자다. 넘치면 말을 줄이거나 줄을 나눈다. 쓸데없이 두 줄로 넘기거나 들쭉날쭉하게 줄을 바꾸지 않는다.
- **빈칸**은 개요에 5~8개, 핵심어만 비운다(SKILL.md 3절 빈칸 만드는 법). **한 학습지 안의 빈칸은 모두 같은 너비**(가장 긴 답이 들어가는 너비)로 써서 답 길이를 드러내지 않는다. 단답 답 칸도 문항끼리 같은 너비(220px)다.
- **옆 칸 첫 상자는 언제나 '용어 풀이'**다. 남는 높이만큼 늘어나 용어 사이를 고르게 띄우고, 아래 끝을 왼쪽 개요 끝에 맞춘다(예시 그대로). 용어가 적어 사이가 너무 벌어지면 용어를 더한다.
- **옆 칸 둘째 상자**: 역사는 '한눈에 보는 연표', 과학은 식·과정 순서, 수학은 푸는 순서, 국어는 갈래·개수 변화처럼 한눈에 볼 정리 하나. 없으면 용어 풀이만 둔다.
- 결론을 미리 주는 **'한 줄 정리'는 두지 않는다.** 학생이 개요와 형성평가로 스스로 정리하게 한다.
- 문항 품질은 SKILL.md 3절과 `assessment-items` 기준을 따른다. 도달 점검 문장은 학습 목표를 "나는 ~할 수 있다."로 바꾼 것이다.

**활동지** — 교사가 활동지(관찰·탐구·토의)를 원하면 Ⅰ 자리에 활동 2~4개를 둔다: 활동 머리 → 지시문 → 자료·도움말 상자 → 표·쓰기 칸. 끝에 도전 과제와 마무리(스스로 평가 + 배움 성찰). 예시 2가 이 모양이다.

**형성평가지·복습지** — 머리 뒤에 Ⅰ 형성평가(또는 Ⅰ 개념 확인 → Ⅱ 적용 문제)를 같은 부품으로 쓴다.

## 2. 캔버스 구성

- 캔버스 제목: "학습지 – 교과 학년 주제". 예: "학습지 – 한국사2 주제 19 5·16 군사 정변으로 민주주의가 후퇴하다"
- 캔버스 페이지 두 개: `student`(학생용), `teacher`(교사용). 교사는 페이지마다 PDF를 내려받는다.
- 쪽마다 아트보드 하나, A4 세로 794×1123 고정(`print` 키 없음 = 한 아트보드가 PDF 한 쪽).
- 학생용 쪽: `Main.dc.html`(1쪽), `Page2.dc.html`(2쪽), `Page3.dc.html`… 학생용 페이지에 왼쪽부터 80px 간격으로 놓는다.
- 교사용 쪽: `TeacherP1.dc.html`, `TeacherP2.dc.html`… 각 파일은 학생용 쪽을 `<dc-import name="Main" teacher="{{ true }}">`로 불러오기만 한다. 그래서 **학생용 글을 고치면 교사용에도 그대로 반영된다.** 교사용 쪽에 내용을 따로 쓰지 않는다.
- 학생용 쪽은 `teacher` 속성(체크 칸 "교사용")을 가진다. 기본은 꺼짐이고, 켜면 그 쪽에서 바로 답이 보인다.
- 세 벌(★ / ★★ / ★★★)이면 수준마다 학생용·교사용 페이지 쌍을 만든다(예: `student-1`, `teacher-1`). 파일 이름 앞에 `L1`, `L2`, `L3`을 붙인다. 화면에 수준 이름은 쓰지 않고 제목 끝 기호만 쓴다.
- `app-worksheet-example.md`의 `canvas.json`을 본떠 만든다.

## 3. 쪽 설계와 높이 예산

A4 고정 쪽은 넘친 부분이 잘리고 다음 쪽으로 넘어가지 않는다. **쓰기 전에 높이를 더해 1,040px을 넘지 않게 한다.** 넘으면 주제·문항을 다음 쪽으로 옮기거나 쪽을 하나 늘린다. 글자 크기를 줄이지 않는다.

- 쪽 틀: 여백 `40px 48px 34px`, 본문 너비 698px, 쪽 안 큰 블록 사이 16px, 맨 아래 쪽 번호 줄. 개념 정리 쪽은 왼쪽 개요 488px + 사이 14px + 옆 칸 196px.
- 쪽 안의 블록은 줄어들지 않게 한다(`flex: none`, 예시 그대로). 줄어들면 마디 띠가 찌그러진다.
- 상자는 네 변 같은 얇은 테두리만 쓰고 왼쪽에 굵은 색 막대를 붙이지 않는다. 상자끼리 붙여 놓지 않는다.
- **형성평가 쪽은 빽빽하게 두지 않는다.** 문항 사이 간격 칸이 쪽에 남는 높이를 고르게 나눠 갖고 점선은 문항 사이 한가운데에 놓인다(예시의 간격 칸 그대로). 도달 점검 앞은 선 없이 더 넓게 띄운다. 문항이 많아 간격이 16px 밑으로 줄면 문항을 줄이거나 쪽을 늘린다.
- 부품 높이(어림):

| 부품 | 높이 |
|---|---|
| 머리 (1쪽만) | 185px (교사용 교육과정 줄 +40px) |
| 마디 띠 (Ⅰ·Ⅱ) | 40px |
| 주제 머리 | 28px, 주제 사이 12px |
| 이름표 줄 한 줄 | 21px (분수 같은 두 층 글자가 있으면 34px) |
| 옆 칸 머리띠 상자 | 머리띠 30px + 용어 하나(풀이 두 줄) 52px, 연표 한 줄 22px |
| 문항 | 문항 글 한 줄 34px(두 줄 60px) + 보기 한 줄 26px + 교사용 해설 18px, 문항 사이 4px |
| 단답 줄 | 30px |
| 쓰기 칸 n줄 | 30 × n + 40px |
| 자료·도움말 상자 | 한 줄 40px, 두 줄 65px |
| 도달 점검 | 35px + 줄마다 34px |
| 활동 머리 (활동지) | 36px (쪽의 첫 활동은 28px) |
| 쪽 번호 줄 | 30px |

- **교사용 1쪽이 가장 빠듯하다**(교육과정 줄 +40px). 1쪽은 교사용 기준으로 더한다. 2쪽도 교사용 해설 줄을 더해 잰다.
- 교사용은 학생용보다 커지면 안 된다. 답과 채점 기준은 **빈칸 안이나 쓰기 줄 위에 얹고**(줄 수 안에서), 새 칸을 더하지 않는다.
- **쪽을 채운다.** 1쪽 아래가 120px 넘게 비면 주제를 하나 더하거나(꼭 기억할 점, 확인 실험, 더 알아보기 등 교과서 범위 안에서), 사실을 담은 도식(SVG)을 넣는다. 2쪽이 비면 문항을 더한다. 장식으로 채우지 않는다.
- 분량 기본은 2쪽이다. 교사가 쪽 수를 말하면 따른다.

## 4. 부품 (모두 예시 코드 그대로)

| 부품 | 모양 | 예시 위치 |
|---|---|---|
| 머리 | 쪽 위·양옆 끝까지 `navy`→`blue` 띠: 흰 교과 칩(아이콘 + 학년·교과·단원·차시), 학년·반·번·이름 흰 칸, 흰 명조 제목 28px, 오른쪽 교과서 쪽 / 아래 `sky` 학습 목표 상자('학습 목표'·'핵심 질문' 칩, 교사용은 '교육과정' 줄) | 예시 1 `Main.dc.html` 앞부분 |
| 마디 띠 | `sky` 띠 + 왼쪽 파랑 번호 칸(흰 명조 Ⅰ·Ⅱ) + 남색 명조 제목 20px + 아래 파랑 선. 형성평가는 오른쪽 '맞은 문항 _ / n' | 예시 1 |
| 주제 | 파랑 동그라미 번호 + 명조 제목 16px + 연파랑 칩(연도·교과서 쪽, 선택) + 연한 선 / 아래 [연파랑 이름표 \| 14px 줄] | 예시 1 개요 |
| 빈칸 | 연노랑 바탕 밑줄 칸(한 학습지 안에서 모두 같은 너비, 줄바꿈 안 됨). 교사용은 칸 안에 답(답 파랑 굵게) | 예시 1 개요 |
| 옆 칸 | 머리띠 상자(첫 상자 남색, 다음 파랑): 용어 풀이(낱말 14px 굵게 + 풀이 12px), 연표·순서(세로선 위 점), 식(가운데 정렬) | 예시 1 오른쪽 |
| 문항 | 남색 동그라미 번호 + 문항 글 15px + 오른쪽 종류 칩, 문항 사이 점선. 보기 ①~⑤(짧으면 3칸, 길면 2칸), 단답 '답' 칩 + 밑줄, O·X, 제시문 상자. 교사용은 정답 굵게 밑줄 + 해설 줄 | 예시 1 `Page2.dc.html` |
| 쓰기 칸 | 아주 연한 파랑 바탕 + 회색 첫 문장 + **실제 선으로 그린** 쓰기 줄(30px). 교사용은 줄 위에 예시 답 + "채점:" 줄 | 예시 1 문항 7, 예시 2 |
| 도달 점검 | 남색 머리띠 상자 + "나는 ~할 수 있다." 줄마다 예 / 아니요 | 예시 1 2쪽 끝 |
| 활동 머리 (활동지) | 파랑 동그라미 번호 + 명조 제목 16px + 오른쪽 시간 칩 "개별 · 10분". 활동 사이 점선, 쪽의 첫 활동은 선 없음 | 예시 2 |
| 표 (활동지) | 머리 행 `sky` 바탕 + 남색 굵은 글자, 연파랑 선, 글자 가운데. 학생 칸은 쓰기 줄 또는 빈칸 | 예시 2 활동 1·4 |
| 자료·도움말 상자 | 크림 바탕 + 황토 칩 '자료'/'도움말' | 예시 2 활동 2·3 |
| 도전 과제·마무리 (활동지) | 머리띠 상자(도전 과제 파랑, 마무리 남색) + 쓰기 줄·별 다섯 개 | 예시 2 2쪽 |
| 그림 | 사실을 담은 도식만 SVG로 직접 그림(그래프, 입자 모형, 잎 모형, 분수 막대 등). 그림 속 글자도 12px 이상. 교사가 준 그림은 올려서 넣음 | 예시 2 활동 1·3 |
| 쪽 번호 | 맨 아래 연파랑 선 위: 왼쪽 파랑 짧은 막대 + "교과 · 제목", 오른쪽 남색 칩 "1 / 2" | 쪽마다 |

- 교과 아이콘은 남색 선 그림(48×48 틀)으로 교과를 나타내는 것 하나를 고른다. 예시의 아이콘(입자, 비커, 잎, 원그래프, 말풍선, 책, 건물 등)에서 고른다.
- 학생용에만 보일 것은 `<sc-if value="{{student}}">`, 교사용에만 보일 것은 `<sc-if value="{{teacher}}">`로 감싼다.
- 스타일은 모두 요소의 `style="…"`에 쓴다(예시처럼). `<helmet>`에는 글꼴 링크와 `body{margin:0;word-break:keep-all;text-wrap:pretty}`만 둔다.
- 칸 종류는 위 부품으로 옮긴다: `text`→지시문, `card`/`source`→자료 상자, `hint`→도움말 상자, `choices`→보기 줄, `lines`/`space`→쓰기 칸(풀이 공간은 줄 없는 같은 높이 칸), `grid`/`labels`→표, `frame`→문장 틀, `steps`→번호 목록, `challenge`→도전 과제.

## 5. 순서

1. SKILL.md 1~5절에 따라 묻고, 내용을 짜고, 점검한다. 개념 정리는 1절 형식대로 주제·이름표·줄·빈칸·용어를 먼저 표로 정한다.
2. `design-system-setup.md`대로 교사 계정의 디자인 시스템 "teacher-kit 수업 디자인"을 준비한다(없으면 만들고, 판이 낮으면 올린다). 캔버스를 만들 때 이것을 설치한다.
3. 3절 높이 예산으로 쪽 나눔을 정하고, 줄마다 글자 수가 한 줄에 드는지 센다.
4. 앱 디자인 캔버스를 만들고 `canvas.json`과 `Main.dc.html`을 먼저 올린 뒤, 나머지 쪽을 하나씩 올린다(학생용 → 교사용).
5. 앱 안내가 확인 렌더를 막으므로 렌더해 보지 않는다. 대신 높이 예산과 줄 글자 수를 한 번 더 센다.
6. 6절 출력대로 답한다.

## 6. 출력

SKILL.md 7절 출력에서 "만든 파일 목록" 자리에 아래를 쓴다.

1. 학습지 링크
2. 보는 법 한 줄: "위쪽에서 '학생용'과 '교사용' 페이지를 바꿔 볼 수 있습니다."
3. 인쇄 안내 한 줄: "인쇄할 페이지를 연 상태에서 내보내기로 모든 쪽을 PDF 하나로 내려받으실 수 있습니다."
4. 고치는 법 한 줄: "학생용 글을 화면에서 바로 고치시면 교사용에도 같이 반영됩니다. '활동 2를 더 쉽게'처럼 말씀하셔도 고쳐 드립니다."
