# 학습지 hwpx 입력 쓰는 법 (make_worksheet.py)

SKILL.md 6절에서 `scripts/make_worksheet.py`의 입력 JSON을 쓸 때 본다. 칸 종류와 모든 값은 스크립트 상단 설명이 기준이고, 이 파일은 자주 틀리는 곳과 예시를 모았다. 학생용·교사용을 가르는 원칙과 쪽 수 안내는 SKILL.md 6절에 있다.

## 1. 답과 교사용 값

- **빈칸**: 문장에 `[[광합성]]`처럼 쓴다. 학생용은 답 길이와 상관없이 같은 너비의 괄호, 교사용은 괄호 안에 답이 들어간다(개념 정리 형식은 한 학습지 안 모든 빈칸이 같은 너비의 음영 밑줄 칸). 제목·제시문·보기·용어 풀이 등 어느 칸에 써도 학생용에는 답이 남지 않는다. `___`는 밑줄 서식으로 처리되니 쓰지 않는다.
- **개념 정리 형식 값 범위**: 서술형 `lines`는 1~8, 선택형 `cols`는 1~5. 쪽이 넘치거나 도달 점검이 빠지면 "확인:" 경고가 나온다. 경고가 나오면 주제·줄·문항을 줄여 2쪽에 맞춘다.
- **답 칸**: 칸마다 `answer`를 넣는다. 표와 이름표 칸은 값을 `{"answer": "답", "lines": 2}`로 쓴다. 수학은 풀이를 한 줄씩 쓴다.
- **칸보다 긴 답**: 활동의 `model`에 쓰면 활동 바로 뒤 "예시 답안" 칸에 들어간다.
- **서술형**: 예시 답안과 함께 `point`에 채점 포인트(꼭 들어가야 할 낱말이나 내용, 어디서 인정이 갈리는지)를 쓴다.
- **인정 답안**: 같은 뜻으로 인정할 답이 있으면 `accept`에 쓴다. 없으면 쓰지 않는다.

## 2. 입력 예시 (활동지)

```json
{
  "subject": "과학", "unit": "물질의 상태 변화", "title": "입자의 운동", "lesson": "3/8차시",
  "goal": "확산을 입자의 운동으로 설명할 수 있다.", "question": "향수 냄새는 어떻게 방 안 전체로 퍼질까?",
  "curriculum": "2022 개정", "standards": ["[9과04-01] 확산 및 증발 현상을 관찰하여 물질을 구성하는 입자가 운동하고 있음을 추론할 수 있다."],
  "activities": [
    {"title": "(개별) 관찰한 내용을 정리해 봅시다.", "time": "10분", "parts": [
      {"kind": "text", "text": "물질이 스스로 퍼져 나가는 현상을 [[확산]]이라고 한다."},
      {"kind": "grid", "header": ["관찰 조건", "잉크가 퍼지는 모습"], "widths": [30, 70], "rows": [
        ["찬물", {"answer": "천천히 퍼진다", "lines": 2}], ["더운물", {"answer": "빠르게 퍼진다", "lines": 2}]]}
    ]},
    {"title": "(개별) 활동 1의 표를 보고 차이가 나는 까닭을 쓰세요.", "time": "15분",
     "model": "온도가 높을수록 입자의 운동이 활발해 잉크 입자가 더 빨리 퍼진다.",
     "point": "온도와 입자의 운동을 이어서 쓰면 인정", "parts": [
      {"kind": "frame", "label": "내 설명", "starter": "더운물에서 더 빨리 퍼진 까닭은", "lines": 3},
      {"kind": "challenge", "text": "겨울과 여름에 향수 냄새가 퍼지는 빠르기를 비교해 쓰세요.", "lines": 2,
       "answer": "여름에 더 빨리 퍼진다. 기온이 높아 입자의 운동이 활발하기 때문이다."}
    ]}
  ],
  "check": ["나는 확산을 입자의 운동으로 설명할 수 있다."], "closing": "check"
}
```

## 3. 그 밖의 입력

- **쪽 나뉨**: 활동 소제목, 지시문, `hint`, `choices`는 다음 칸과 같은 쪽에 놓인다. 행이 많은 표는 쪽을 넘어 나뉠 수 있다.
- **분수·수식**: 분수는 `{{2/3}}`, 대분수는 `{{1 7/12}}`처럼 `{{ }}`로 감싸면 한글 수식(위아래로 쌓은 분수)으로 들어간다. 문단, 표 칸, 목록 어디서나 쓴다. 안은 LaTeX가 아니라 한글 수식 문법이다(`\frac` 금지, 한글 금지). 식 쓰는 법과 자주 쓰는 식(`over`, `sqrt`, `lim`, `int`, `inf`, `LEQ` 등)은 `references/equations.md`를 따른다. 지수는 `{{x^2+1}}`처럼 붙여 써도 생성기가 묶어 준다. **수식이 든 칸은 넓게** 잡는다(칸보다 긴 식은 잘리고 생성기가 경고한다). 교사용 답이 수식이면(`"answer": "{{x=2}}"`) 파랑·굵게로 나온다. 분수 밖의 복잡한 식은 한글에서 열어 확인하라고 답변에 적는다.
- 교사 양식을 채울 수 없어 칸을 직접 짜야 할 때만 `python scripts/make_hwpx.py 입력.json 출력.hwpx`를 쓴다. 칸 합치기(`colspan`, `rowspan`), 음영(`shade`), 높이(`lines`)는 `scripts/make_hwpx.py` 상단 설명과 같다.
