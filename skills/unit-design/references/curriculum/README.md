# 성취기준 데이터

이 폴더에는 교육과정 고시문 원문에서 옮긴 성취기준과 핵심 아이디어, 내용 요소만 넣는다.
**원문에서 확인하지 않은 성취기준은 절대 넣지 않는다.** 이 데이터의 정확성이 스킬 전체의 정확성을 결정한다.

## 현재 상태

| 교육과정 | 학교급 | 수록 | 찾는 법 |
|---|---|---|---|
| 2022 개정 | 초·중·고 (직업계 전문교과 제외) | 성취기준 4,451행(서로 다른 코드 4,440개), 해설 포함, 과목 264개, 파일 66개 | `2022/INDEX.md`에서 학교급·교과로 파일을 찾는다 |
| 2015 개정 | 중·고 (2026학년도 중3, 고3) | 수록하지 않음 | 교사에게 붙여 넣어 달라고 요청하거나 [확인 필요] |

- 2022 개정 데이터 출처: greatsong/k-curriculum-2022 v3.0.1 (CC BY 4.0). 원문은 교육부 고시 제2022-33호와 국가교육위원회 고시 제2024-3호다. 데이터 제작처는 교육부 별책 PDF 본문과 전수 대조해 본문 오류 0건이라고 밝혔다 (자동 대조이며 사람이 눈으로 전수 확인한 것은 아니라고 함). 이 키트를 만들 때 한국교육과정평가원 학생평가지원포털 목록과도 대조해 99.5%가 일치했다 (문장부호·띄어쓰기 차이 제외). 맞지 않은 약 0.5%(약 20행)의 목록은 남아 있지 않다 [확인 필요]. 그래서 성취기준 문장을 학교 제출 문서에 그대로 옮길 때는 교사에게 원문 대조를 권한다.
- 초1~2 "즐거운 생활"은 국가교육위원회 고시 제2026-1호로 새 문장이 정해졌지만 2028. 3. 1.부터 적용된다. 이 데이터는 지금 적용되는 문장이다.
- 데이터를 다시 만들 때: `python tools/import_curriculum.py standards.json`
- **코드가 겹치는 과목**: 코드 11개가 두 과목에 함께 나온다. `[12심독01-01]`~`[12심독02-04]` 8개는 영어 "심화 영어 독해와 작문"과 제2외국어 "심화 독일어", `[12스문01-01]`~`[12스문01-03]` 3개는 체육 "스포츠 문화"와 제2외국어 "스페인어권 문화"에 있다. 문장은 과목마다 다르다. 코드로 찾을 때는 2022 폴더 전체를 검색하고, 둘 이상 나오면 모두 보여 준다.
- **같은 해설이 여러 코드에 붙은 경우**: 해설 문장이 둘 이상의 코드에 똑같이 붙은 묶음이 64개(43개 파일) 있다 (예: 중학교 과학 `[9과06-02]`, `[9과06-03]`). 원문에서 해설 하나가 여러 성취기준을 함께 설명한 것을 코드마다 옮긴 것으로 보인다. 원문 대조는 하지 못했다.
- **띄어쓰기 정리**: 원문 PDF 추출 과정에서 한 낱말 안에 들어간 띄어쓰기(예: "특징으 로는", "개괄 적으로", "파 형을") 37곳을 고쳤다 (모두 과학 교과 파일). 낱말 사이 띄어쓰기는 원본 그대로 두었다. 같은 수정 목록이 `tools/import_curriculum.py`의 `SPACING_FIXES`에 있어 데이터를 다시 만들어도 유지된다.

- **핵심 아이디어**: `core-ideas/`에 국어, 수학, 영어, 사회(역사·한국사 포함), 과학의 전 과목 문장 576개가 있다. 교육부 고시 제2022-33호 별책 5·7·8·9·14의 내용 체계표에서 옮긴 506개에, 별책 20(과학 계열 선택 과목) 15개 과목의 70개를 더했다. 별책 20에는 전문 수학, 이산 수학, 고급 대수, 고급 미적분, 고급 기하와 정보과학도 들어 있어 `science.md` 맨 아래에 함께 있다. 506개는 교육부 누리집 고시 게시물의 한글 문서(별책 5·7·8·9·14)와 글자가 모두 같다(띄어쓰기 무시). 원문 파일은 경기도교육청이 연결한 자료 묶음의 고시문 사본이고, 이후 고시로 바뀐 문장이 있는지는 대조하지 못했다 [확인 필요]. 2026-11-20에 나머지 교과 12개 파일(도덕 `moral`, 실과·기술⋅가정·정보 `practical-arts`, 체육 `pe`, 음악 `music`, 미술 `art`, 바른·슬기로운·즐거운 생활 `integrated`, 제2외국어 `second-language`, 한문 `hanmun`, 중학교 선택 `middle-electives`, 고등학교 교양 `liberal-arts`, 체육 계열 `pe-track`, 예술 계열 `arts-track`)의 557문장을 더했다. 교육부 배포 고시문 한글 파일(별책 6·10~13·15~19·21·22)에서 표의 '핵심 아이디어' 칸을 옮겼고, 같은 도구를 기존 다섯 교과에 돌려 기존 문장과 모두 같음을 확인했다(과학 계열 별책 20은 기존 과학 파일에 있음). 이 12개 파일은 원문 쪽 번호를 적지 못했다.
- **내용 요소**: `content-elements/`에 국어, 수학, 영어, 사회(역사·한국사 포함), 과학 다섯 파일이 있다(과학 파일에 별책 20의 15개 과목 포함). 별책 5·7·8·9·14·20의 내용 체계표 146개에서 지식⋅이해, 과정⋅기능, 가치⋅태도 칸의 항목 4,062개를 옮겼다(국어 506, 사회 942, 수학 509, 과학 914 + 과학 계열 선택 457, 영어 734). 과목 → 영역 → 구분 → 범주 → 학년(군) 순서이고 원문 쪽을 `###` 제목에 적었다. 원문에서 칸이 합쳐졌거나 비어 있는 곳은 그렇게 밝혔다. 원문은 교육부 누리집 고시 게시물(boardSeq=93458)의 한글 문서이며, 이후 고시로 바뀐 문장이 있는지는 대조하지 못했다 [확인 필요].
- **교수⋅학습 및 평가**: `teaching-assessment/`에 18개 교과 파일(249과목)이 있다. 과목마다 영역별 '성취기준 적용 시 고려 사항'(955곳)과 '3. 교수⋅학습 및 평가' 절(교수⋅학습의 방향·방법, 평가의 방향·방법)을 고치지 않고 옮겼다. 원문은 교육부 고시 제2022-33호 별책 5~22의 교육부 배포 한글 파일이다. 고려 사항 개수는 교과마다 원문과 맞췄다. 4MB가 넘어 단원 설계(unit-design) 스킬만 싣는다(`tools/build.py` 제외 목록).
- **소제목과 내용 영역**: 아래 파일 형식의 `##` 소제목은 성취기준 묶음이다. 과학처럼 교육과정의 내용 영역보다 작은 교과가 있으므로 내용 영역은 `core-ideas/`의 이름을 쓴다.

데이터에 없는 교과는 스킬이 사용자에게 성취기준을 붙여넣어 달라고 요청하거나 [확인 필요]로 표시한다.

## 파일 위치

```
curriculum/
├── README.md
├── core-ideas/                        핵심 아이디어: 17개 교과 (korean, math, english, social, science, moral …)
├── teaching-assessment/              과목별 성취기준 적용 시 고려 사항, 교수⋅학습 및 평가: 18개 교과
├── content-elements/                  내용 요소: korean, math, english, social, science
└── 2022/
    ├── INDEX.md                       학교급·교과군·과목 → 파일, 성취기준 수
    ├── elementary/e001.md ~           예: 초등 과학 = e001.md
    ├── middle/m001.md ~
    └── high/h001.md ~
```

파일 이름은 학교급 첫 글자와 순번(3자리)이다. claude.ai 스킬 업로드가 한글·괄호·+ 가 든 경로를 거부해서 ASCII 이름만 쓴다. 또 스킬 하나에 파일 200개까지만 올라가므로, 같은 학교급·교과군 과목을 한 파일에 40KB까지 묶는다(과목 264개 → 파일 66개). 한 과목은 쪼개지 않는다. 과목마다 `# 2022 개정 / 학교급 / 교과군 / 과목` 제목으로 시작한다. 교과군·과목 → 파일은 `INDEX.md` 표에 있다.

2015 개정 데이터 폴더는 없다. 찾을 때는 `INDEX.md`에서 파일 하나를 고른 뒤 그 파일만 연다.

## 파일 형식

```markdown
# 2022 개정 / 중학교 / 과학 / 과학

- 학년(군): 중1-3
- 구분: 공통
- 성취기준 수: 87
- 데이터: (출처와 라이선스, 원문 고시 번호)

## 과학과 인류의 지속가능한 삶          ← 영역 이름

| 코드 | 성취기준 |
|---|---|
| [9과01-01] | (고시문의 문장 그대로) |

### 성취기준 해설

- **[9과01-01]** (해설 문장)
```

## 데이터 다시 만들기

1. 원본 JSON(`standards.json`)을 받아 `python tools/import_curriculum.py standards.json`을 실행한다. 과목 파일과 `INDEX.md`가 다시 만들어진다.
2. 문장을 요약하거나 고치지 않는다. 원문에서 확인하지 않은 성취기준은 넣지 않는다.
3. `python tools/build.py`를 다시 실행하면 성취기준을 쓰는 스킬(`lesson-plan`, `worksheet`, `rubric`, `assessment-items`)의 zip에 각각 들어간다.
