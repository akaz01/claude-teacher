# 수업지도안 작성

성취기준에서 출발해 평가, 활동, 정리가 하나로 이어지는 지도안을 만든다. 표를 채우는 문서가 아니라 앞 칸의 결과가 뒤 칸에 들어가는 문서다.

**서식의 근거와 한계.** 아래 구조는 서울시교육청 초등교육과 게시물(2022 개정 약안·세안 서식)을 뼈대로 하고 경기 자료를 참고했다. 공식 서식은 초등 게시물이며 중·고 공식 서식은 찾지 못했다. **학교 양식이 우선**이고, 양식이 없을 때만 이 구조를 쓴다.

**교사에게 하는 안내·질문·설명은 모두 한국어로 쓴다.** (작업 중 도구 출력이 영어여도 답변은 한국어)
**답변 순서는 `references/answer-order.md`를 따른다.** (작업 중 설명 문장을 답변 맨 위에 쓰지 않는다)
**교과서 파일을 받으면 범위부터 묻는다.** 교과서 PDF가 첨부되면 "교과서 몇 쪽부터 몇 쪽까지 지도안에 담을까요?"라고 묻고, 답을 받은 뒤 시작한다. 교사가 이미 범위를 말했으면 묻지 않는다. 쪽 번호는 PDF 쪽수가 아니라 교과서에 인쇄된 쪽 번호로 맞춘다. 질문 없이 진행할 때는 첨부 파일 전체를 범위로 잡고 "기본값으로 정한 내용"에 적는다.

## 맡지 않는 요청

학년·학기 진도표, 교수학습 및 평가 운영 계획 문서만 요청받으면 이 스킬의 질문·양식·생성기를 쓰지 않는다. 그 요청은 course-plan 스킬이 맡는다. 단원 설계(백워드·개념기반·GRASPS) 요청은 unit-design 스킬이 맡는다. 단원 설계를 바탕으로 차시 지도안을 요청하면 이 스킬의 절차로 쓰고, 단원 설계서의 그 차시 학습 목표·탐구 질문·활동·평가 시점·성취기준을 그대로 가져와 이미 정한 값은 다시 묻지 않는다.

## 1. 정보 확인

**성취기준 조회나 프로필 설정 요청이면 지도안 질문을 하지 않는다.** "성취기준 찾아 줘", "[9과01-01] 뭐야", "2022 개정 적용 학년"처럼 성취기준이나 적용 교육과정만 묻는 요청은 `references/curriculum-lookup.md` 절차로 바로 답한다. "프로필 설정", "새 학년도 준비"처럼 교사 프로필을 만들거나 고치는 요청은 `references/teacher-profile.md` 절차로 간다. 두 경우 모두 아래 지도안 질문 문구와 기본값 표를 쓰지 않는다.

`[교사 프로필]` 블록이 있으면 학교급, 학년, 교과를 거기서 가져온다. 첫 응답은 아래 문구로 한 메시지에 묻고, 묻는 횟수를 늘리지 않는다. 교사가 이미 말한 값과 이미 받은 양식·교과서는 목록에서 빼고 남은 항목의 번호를 다시 매긴다. 문구는 인용 표시 없이 쓰고, 문구에 다른 말을 더하지 않는다. 받은 자료를 다시 언급하는 문장도 넣지 않는다.

> 지도안을 만들기 위해 알려 주세요.
> 1. 학년, 교과, 단원 또는 주제
> 2. 차시 (예: 3/8)
> 3. 쓰시는 학교 양식(hwpx)과 교과서 해당 쪽 PDF (주시면 더 잘 만들어 드립니다. 양식은 그 파일에 내용을 채우고, 교과서는 내용과 쪽수를 맞춥니다. hwp 파일이면 한글에서 hwpx로 저장해 주세요)
>
> 있으면 알려 주세요: 세안 여부(기본은 약안), 공개수업 여부, 학습 환경
>
> 질문 없이 바로 만들어 달라고 하시면 기본값으로 만들어 드립니다.

자료를 일부만 받았으면 3번을 아래 문구로 바꾼다. 둘 다 받았으면 3번을 뺀다. 교과서 범위를 물어야 하면 그 질문을 목록 맨 앞에 둔다. 11~2월이고 교사가 학년도를 말하지 않았으면 `references/curriculum-transition.md` 판별 절차 1번의 학년도 질문을 그보다 앞, 목록 맨 앞에 둔다(교육과정이 두 학년도에 같아도 묻는다).
- 교과서를 받았을 때: 쓰시는 학교 양식(hwpx) (주시면 그 파일에 내용을 채웁니다. hwp 파일이면 한글에서 hwpx로 저장해 주세요)
- 양식을 받았을 때: 교과서 해당 쪽 PDF (주시면 내용과 쪽수를 맞춥니다)

교사가 첫 메시지에 단원을 말했으면 2절에 따라 찾은 성취기준 후보를 같은 응답에 보여 주고 고르게 한다. 단원에 든 성취기준은 개수를 줄이지 않고 모두 보여 준다. 단원 이름이 자료에 없어 뜻으로 찾았을 때만 가까운 것을 3개 이내로 고른다. 코드와 문장만 쓰고 해설과 고른 이유는 쓰지 않는다. 단원을 모르면 답을 받은 뒤 찾는다.

아래 값은 교사가 말하지 않으면 묻지 않고 기본값을 쓴다. 쓴 값은 답변의 "기본값으로 정한 내용"에 적는다.

| 항목 | 기본값 |
|---|---|
| 형식 | 약안 |
| 용도(평소, 공개수업, 연구수업) | 평소 |
| 학습 환경(1인 1기기, 모둠 수, 특별실) | 기기 없이 되는 활동 |
| 수업 모형 | 내용에 맞게 제안. 맞는 모형이 없으면 생략 |
| 제재(작품·글·자료) | 아래 기준으로 고름 |
| 시도교육청 | 평가를 상·중·하 3단계로 둠 |
| 학생 실태(잘 틀리는 곳, 선수 학습) | 비워 두고 표시 |
| 수행평가 연계 여부 | 형성평가 |

지원이 필요한 학생 유형은 교사가 말할 때만 이름 없이 받는다. 학생 이름과 진단명은 받지 않고, 받았으면 지도안에 쓰지 않는다.

**제재를 고를 때.** 교사가 작품이나 글을 정하지 않았으면 교과서 수록 작품이나 저작권 보호기간이 끝난(공유저작물) 작품을 고르고, 무엇을 골랐는지 밝힌다. 저작권이 있는 작품은 전문을 옮기지 않고 제목·작가와 필요한 한두 구절만 쓴다. 기억으로 옮긴 구절에는 "(원문 대조 필요)"를 붙여 교사가 교과서나 원문과 맞춰 보게 한다.

**지어내지 않는다.** 학생 실태와 설문 결과, 학생 소감, 효과 수치, 영상·웹 주소, 교과서 쪽수, 핵심 아이디어, 내용 요소, 성취기준 해설을 기억으로 쓰지 않는다. 없으면 `[확인 필요]`, `[학습자 실태 입력 필요]`, `[영상 선정 필요]`로 둔다.

**질문 없이 진행해 달라고 할 때.** 교사가 "질문하지 말고", "알아서 끝까지"처럼 바로 결과를 원하면 묻고 확인받는 단계를 건너뛴다. 이 경우에도 지어내지 않는다.
- 빠진 값은 이 스킬의 기본값(학교급 기본값 포함)으로 채운다. 핵심 수치도 같다.
- 답변 맨 위에 "기본값으로 정한 내용"을 목록으로 적는다.
- 확인이 필요한 사실은 문서에 `[확인 필요]`로 두고, 답변 맨 아래 "확인 필요" 목록에 모은다.

## 2. 성취기준

- 교사가 성취기준을 주면 그대로 쓴다.
- 주지 않았으면 `references/curriculum-lookup.md` 절차로 성취기준 데이터베이스에서 찾아 제안하고 확인받는다. 질문 없이 진행할 때는 찾은 것을 쓰고 "확인 필요"에 적는다. 성취기준 문장과 코드를 기억으로 쓰지 않는다.
- 데이터에도 없으면 **코드와 문장을 지어내지 말고** `[확인 필요]`로 둔다.
- 적용 교육과정(2015/2022 개정)을 판별해 둔다.

## 3. 설계 순서

표를 채우기 전에 아래 순서로 정한다. 출력 순서는 양식 순서를 따른다.

1. **평가 요소**: 성취기준에서 이번 차시의 평가 요소를 1~2개 뽑는다.
2. **탐구 질문**: 차시를 이끄는 질문을 정한다. 맞지 않는 차시는 학습 문제로 쓴다.
3. **도달의 증거**: 학생이 무엇을 보여 주면 도달인지 정한다.
4. **활동**: 그 증거가 나오는 활동을 놓는다. 증거와 무관한 활동은 뺀다.
5. **정리에서 탐구 질문에 답하기**: 학생이 직접 답하는 장면을 넣는다.

머리 정보표는 마지막에 채운다. 성취기준, 탐구 질문, 학습 목표, 활동, 평가의 내용어가 서로 맞아야 한다.

**탐구 질문과 학습 문제를 구분한다.**
- 학습 문제는 "~해 봅시다"로 방향을 안내하는 문장이다. 탐구 질문은 여러 관점과 해석을 끌어내는 질문이다.
- 모든 차시가 탐구 질문일 필요는 없다. 개념을 처음 익히는 차시는 학습 문제로 쓴다.
- "~을 이해하는가?", "~할 수 있는가?"는 쓰지 않는다. 학습 목표를 의문문으로 바꾼 점검 문장이다. 교과서 한 곳에서 답을 찾는 질문도 탐구 질문이 아니다.
- 사실 질문은 도입의 안내 질문으로 쓴다.
- 논쟁적 질문은 근거에 따라 판단이 갈려야 한다. 갈리지 않으면 논쟁적 질문이라고 적지 않는다. 세 유형을 억지로 채우지 않는다.

예: "확산 현상을 이해할 수 있는가?"는 쓰지 않고 "바람이 없는 방에서도 냄새가 퍼지는 까닭을 어떻게 설명할 수 있을까?"로 쓴다.

| 학교급 (1차시) | 도입 | 전개 | 정리 |
|---|---|---|---|
| 초등 (40분) | 5분 | 30분 | 5분 |
| 중학교 (45분) | 5분 | 33~35분 | 5~7분 |
| 고등학교 (50분) | 5분 | 38~40분 | 5~7분 |

이 표는 기본값이며 수업에 맞게 조정한다. 차시 시간은 총론의 원칙이고 학교가 조정할 수 있으므로 교사가 말한 시간을 먼저 쓴다. 합계는 차시 시간과 같아야 한다.

| 내용 영역 | 교육과정의 영역 이름 | | | | |
| 핵심 아이디어 | 그 영역의 문장 가운데 이번 차시에 해당하는 것 | | | | |
| 내용 요소 | 그 영역·학년(군) 칸의 내용 요소 가운데 이번 차시에 해당하는 것 | | | | |
| 성취기준 | [코드] 문장 | | | | |
| 탐구 질문 | 차시를 이끄는 질문 하나 | | | | |
| 학습 목표 | 관찰 가능한 동사로 1~2개 | | | | |
| 학습 주제 | "~하기"나 명사형으로 짧게. 학습 목표를 되풀이하지 않는다 | | | | |
| 수업자 의도 | 2~4문장: 왜 이 자료, 왜 이 순서인지 | | | | |
| 자료 | 교사: … / 학생: … | | | | |

- 수업자 이름, 학급 인원 등 교사가 주지 않은 정보는 비워 두거나 `○`로 둔다.
- 2022 개정 학년은 위 표대로 쓴다. 2015 개정 학년은 핵심 아이디어 대신 "핵심 개념"으로 쓰고, 교과 역량과 내용 영역은 교사 자료에서 받아 쓴다. 이 스킬의 데이터는 2022 개정뿐이므로 교사가 주지 않은 칸은 `[확인 필요]`로 둔다. 탐구 질문은 "학습 문제"로 바꿔도 된다.
- **학습 문제로 쓰는 차시**: 3절에 따라 학습 문제를 쓰면 칸 이름을 `학습 문제`로 바꾸고 칸에는 학습 문제만 쓴다. 왜 그렇게 썼는지는 문서에 적지 않는다. 학교 양식의 칸 이름은 그대로 둔다.
- **교과 역량**: 교사가 주지 않았으면 `references/subject-competencies.md`에서 고른다. 표에서 `[확인 필요]`인 교과(과학, 역사)는 칸에 `[확인 필요]`를 두고 기억으로 역량 이름을 지어내지 않는다.
- **내용 영역**: 이 칸의 영역은 교육과정의 내용 영역이다. 수행평가의 평가 영역(만점이 있는 단위)과 다른 말이므로 앞말을 붙여 쓴다. 학교 양식의 칸 이름이 "영역"이면 그대로 둔다. 영역 이름은 `references/curriculum/core-ideas/`의 것을 쓴다. 성취기준 파일의 소제목은 내용 영역보다 작을 수 있다 (예: 과학의 "물질의 상태 변화"는 내용 영역 "물질" 안에 든다).
- **핵심 아이디어**: `references/curriculum/core-ideas/`에서 찾아 문장 그대로 쓴다. 영역을 나누지 않은 고등 과목은 과목의 문장에서 고른다. 없으면 `[확인 필요]`로 둔다.
- **내용 요소**: `references/curriculum/content-elements/`에서 단원이 속한 과목·영역·학년(군) 칸을 찾아 문장 그대로 쓴다. 원문 표에서 칸이 합쳐졌거나 비어 있다고 밝힌 곳은 그대로 밝힌다. 2022 개정 학년에만 쓰며, 2015 개정 학년의 내용 요소와 교과 파일이나 과목이 없는 경우는 교사 자료에서 받고 없으면 `[확인 필요]`로 둔다.

### 5-2. 교수·학습 활동표

학교급에 따라 열 구성이 다르다. 학교급 기본값이며 교사가 바꿀 수 있다.

| 학교급 | 열 구성 |
|---|---|
| **중·고 (분리형)** | 단계 \| 학습 형태 \| 교수·학습 활동 (교사 \| 학생) \| 시간(분) \| 자료(▣) 및 유의점(※) \| 평가 |
| **초등 (통합형)** | 단계 \| 학습 형태 \| 교수·학습 활동 \| 시간(분) \| 자료(▣) 및 유의점(※) \| 평가 |

- **단계 칸은 세로로 합친다.** 단계 이름은 도입·전개·정리 또는 수업 모형의 단계(예: 문제 확인–탐구–일반화).
- 분리형은 "교수·학습 활동" 머리칸 아래를 교사·학생 두 칸으로 나눈다 (2단 머리행).
- 통합형은 한 칸에 교사 발문과 학생 예상 반응을 함께 쓴다.
- **학습 형태**: 전체, 모둠, 짝, 개인으로 쓴다. 활동이 바뀌면 다시 적는다.
- **평가**: 평가 계획의 방법을 그대로 적는다 (관찰, 활동지, 쪽지 등). 평가가 없는 행은 비운다. 걷는 방법이 있으면 유의점에 적는다.
- 칸 안 기호: **◉** 활동 → **○** 세부 → **-** 학생 예상 반응. 핵심 발문은 따옴표로 실제 말할 문장을 쓴다.
- 도입에 동기 유발과 탐구 질문(학습 문제) 확인을 넣는다.
- 정리에서는 학생이 탐구 질문에 직접 답하게 한다 (한 문장 쓰기, 짝에게 설명 등). 그다음 성찰과 차시 예고를 쓴다.
- 학생 칸에 바른 반응 외에 예상되는 틀린 반응을 하나 넣고, 유의점에 되묻는 발문을 쓴다. 정답을 알려 주는 문장을 쓰지 않는다.
- 자료는 ▣, 유의점은 ※로 쓴다. 안전, 모둠 구성, 지원, 자료를 고른 까닭처럼 이 수업에서만 쓸 말을 쓴다. 영상은 제목, 출처, 사용 구간을 쓰고 주소를 지어내지 않는다.
- 앱이 필요한 활동은 기기 없이 대신할 방법을 유의점에 한 줄 적는다. 도구 이름은 교사가 쓰는 것을 쓰고, 모르면 기능으로 적는다.
- 학교 밖 실천을 넣을 때는 수업 안에서 끝나는 대안을 함께 쓰고, 채점 대상으로 삼지 않는다.

### 5-3. 평가 계획표

| 평가 요소 | 평가 방법 | 상 | 중 | 하 | 피드백(하) |
|---|---|---|---|---|---|
| 입자 운동으로 확산 설명 | 활동지 | 입자 운동으로 설명하고, 온도가 다른 새 상황에도 같은 설명을 쓴다 | 향수 냄새가 퍼지는 까닭을 입자 운동으로 설명한다 | 모형 그림을 보며 입자가 움직인다고 말한다 | 모형 그림을 순서대로 짚게 한 뒤 짝에게 다시 설명하게 한다 |

위 예시는 "범위" 축으로 갈랐다.

- 평가 요소는 1~2개면 된다. 평가 요소의 내용어가 성취기준과 학습 목표에 있어야 한다.
- 상·중·하는 `references/performance-levels.md`의 일곱 축 가운데 **하나**를 평가 요소마다 골라 가른다. 그 파일의 "유일한 차이로 쓰지 않을 말"만 바꾼 진술을 쓰지 않는다.
- 완성한 뒤 시험한다. 학생 답 두 개를 떠올렸을 때 교사가 망설임 없이 가를 수 있어야 한다.
- 단계 수와 단계 이름은 지역과 학교마다 다르다. 교사가 말하지 않으면 상·중·하 3단계로 두고 가정했다고 밝힌다.
- 하 수준은 학생이 할 수 있는 것으로 쓴다. 피드백은 다음 행동을 쓴다. "다시 지도한다"는 쓰지 않는다.
- 가치·태도는 관찰이나 자기평가로 두고, 억지로 세 단계로 가르지 않는다.
- 학생에게 주는 자료에는 수준 이름을 보이지 않는다.

### 5-4. 판서 계획 (선택)

공식 서식에는 없는 선택 항목이다. 교사가 원하면 위에 단원명, 왼쪽에 탐구 질문과 활동 순서, 오른쪽에 핵심 내용을 적는다. 세안에서는 참고 자료에 넣는다.

| 물질의 상태 변화 (○/○차시) | |
|---|---|
| 탐구 질문: 바람이 없는 방에서도 냄새가 퍼지는 까닭을 어떻게 설명할 수 있을까? | 핵심 내용 |
| 1. 냄새가 퍼지는 모습 관찰 | 확산: 물질을 이루는 입자가 스스로 운동하여 퍼져 나가는 현상 |
| 2. 입자 모형으로 그리기 | (학생이 그린 모형을 붙일 자리) |
| 3. 탐구 질문에 한 문장으로 답하기 | 답을 미리 적지 않고 학생 문장을 받아 적는다 |

### 작성 기준

- **학습 목표**: "~을 설명할 수 있다", "~을 비교할 수 있다"처럼 관찰 가능한 동사로 쓴다. "이해한다", "안다"는 피한다. 성취기준의 동사와 내용어를 담되, 성취기준 동사가 "이해한다"이면 이해를 보여 주는 행동으로 바꿔 쓴다 (예: "광합성 과정을 이해한다" → "광합성에서 빛에너지가 화학 에너지로 바뀌는 과정을 설명할 수 있다").
- **활동 이름**: "~하기" 꼴의 명사구 (동기 유발하기, 활동 1 ○○ 알아보기).
- **유의점**: "~할 수 있도록 지도한다", "~에 유의한다".
- **평가**: 학습 목표마다 확인 방법이 하나 이상 있어야 한다.

## 6. 세안 형식

공개수업, 연구수업 등에서 세안을 원하면 아래 순서로 쓴다. 괄호 안 "학교 양식에 있으면" 항목은 서울 서식에 없으므로 학교 양식에 있을 때만 쓴다.

1. **표지**: "(○○)과 교수·학습 과정안", 일시·장소·대상·수업자 표, 학교명
2. **단원명**: 대·중·소단원
3. **단원의 개관**: 3문단 (교육과정상 의의 / 단원 내용과 이론적 배경 / 학습자 실태에서 나온 시사점)
4. **단원 분석**
   - 단원의 계열: 선수 → 본 → 후속 학습 표
   - 단원의 이해: 내용 영역, 핵심 아이디어, 내용 요소(지식·이해 / 과정·기능 / 가치·태도 3칸 표), 성취기준과 해설, 성취기준별 학습 요소와 실생활 연계. 내용 요소는 `references/curriculum/content-elements/`의 교과 파일에서 과목 → 영역 → 구분(지식·이해 / 과정·기능 / 가치·태도) → 범주 → 학년(군) 칸을 찾아 문장 그대로 옮긴다. 그 파일에 없는 과목(국어·수학·영어·사회·과학 밖의 교과 등)은 교과서나 교사 자료에서 받고, 없으면 `[확인 필요]`로 둔다
   - 탐구 질문 개발: 단원 핵심 아이디어, 단원 탐구 질문. 단원 핵심 아이디어는 교과 문장을 단원의 내용어가 드러나게 다시 쓰고, 초안임을 알린다
   - 단원 지도 계획: 차시 | 탐구 질문 | 학습 주제·활동 | 평가(요소, 방법) 표. 본시 행은 "(본시)"로 표시하고 음영을 넣는다
   - 단원 평가 계획: 성취기준 | 수준(상/중/하) | 수행 수준 | 피드백
5. (학교 양식에 있으면) **단원 목표**: 지식·이해 / 과정·기능 / 가치·태도로 나눠 쓴다
6. (학교 양식에 있으면) **학습자 실태**: 교사가 준 정보만 쓴다. 없으면 `[학습자 실태 입력 필요]`로 두고, 실태 조사 문항 예시를 제안한다
7. (학교 양식에 있으면) **지도상의 유의점**: 번호 목록
8. **본시 교수·학습 과정안**: 5절 약안 형식 전체에 아래를 더한다
   - 수업자 의도: 세 묶음(수업자 의도 / 탐구 중심 학습 / 평가)
   - 보편적 학습 설계: 자료 제시, 표현, 참여의 다양화 세 칸. 이 수업의 어느 장면에서 무엇을 바꾸는지 쓴다. 일반론, 학생 이름, 진단명을 쓰지 않는다
   - 차시 평가 계획: 평가 요소, 평가 과제, 채점 기준표(채점 요소 × 수행 수준, 피드백)
9. **참고 자료**: 학습지, 판서 계획, PPT 목록

## 7. 여러 차시

"단원 전체 지도안"이나 여러 차시를 요청받으면:
1. 먼저 **차시별 계획표**(차시 | 탐구 질문 | 학습 주제·활동 | 평가(요소, 방법))를 보여 주고 확인받는다. 수행 과제가 있으면 과제를 먼저 쓴다. 질문 없이 진행할 때는 계획표를 보여 준 뒤 바로 이어서 쓴다.
2. 확인되면 차시마다 약안을 쓴다. 분량이 많으면 몇 차시씩 나눠서 낸다.

## 8. 자가 점검

완성한 뒤 `references/checklists/curriculum-alignment.md`의 C1~C8을 점검하고, 아래를 더 본다. 고친 것이 있으면 맨 아래에 한두 줄로 알린다.

- 탐구 질문이 학습 목표를 의문문으로 바꾼 꼴이 아닌가. 정리에서 학생이 그 질문에 답하는가
- 상·중·하가 부사만 다르지 않은가
- 평가하는 장면에 적은 방법(활동표 평가 칸, 기본 양식 분리형이면 자료 칸의 `★ 평가:`)이 평가 계획표와 같은가. 그 장면에 증거가 남는가
- 차시 수, 탐구 질문, 학습 주제, 평가 요소가 표끼리 같은가
- 역량, 내용 영역, 핵심 아이디어가 해당 개정의 이름이거나 `[확인 필요]`인가
- 시간 합이 차시 시간과 같은가

## 9. 파일 만들기

지도안은 **늘 한글(hwpx) 파일로 만든다.** 교사가 대화 글만 원한다고 할 때만 파일을 만들지 않는다.

**학교 양식을 받았을 때.** 새로 만들지 않고 그 파일에 내용만 채운다. 순서는 `references/form-fill.md`를 따른다.
- hwpx 양식: `scripts/fill_hwpx.py`로 채운다. 활동표 행이 모자라면 행을 늘린 양식을 교사에게 요청하고, 남은 활동을 답변에 적는다.
- hwp 양식: 채울 수 없다. 한글에서 hwpx로 저장해 다시 올려 달라고 안내한다. 그럴 수 없으면 아래 방식으로 항목과 순서만 맞추고 고지 문장을 쓴다.

**양식이 없을 때: 기본 양식(학습과정안).** 교사가 양식을 주지 않으면 약안은 `scripts/make_lesson_form.py`로 만든다. 기본 양식 `assets/lesson_plan_form.hwpx`의 머리 띠("Ⅰ" + 제목 줄), 수업 정보표, 활동표의 테두리·글꼴을 그대로 쓰고, 칸과 행은 내용에 맞게 늘리고 나눈다. 활동표 아래에는 5-3절의 평가 계획표가 같은 선·음영으로 붙는다.

```
python scripts/make_lesson_form.py 지도안.json 지도안.hwpx
```

**활동표 형식은 5-2절의 학교급 기본값을 따른다.** 학교급은 1절대로 `[교사 프로필]`이나 교사가 말한 학년으로 정한다. 교사가 형식을 정했으면 그것을 따른다.
- 초등: `"layout": "integrated"`(통합형)로 만든다. 칸은 5-2절 초등 열 구성(단계 | 학습 형태 | 교수·학습 활동 | 시간 | 자료 및 유의점 | 평가)이다. 활동마다 `group`(학습 형태), `activity`(교사 발문(◉, ○)과 학생 예상 반응(-)을 차례대로, 예: `"◉ 그림자 관찰하기\n○ “무엇이 보이나요?”\n- 나무 그림자가 길어요"`), `time`, `materials`, `assess`(평가 칸. 평가 계획표의 방법을 그대로, 평가가 없는 행은 비움)를 쓴다. 칸 너비 합과 선·음영·글꼴은 분리형과 같다.
- 중·고: `layout`을 빼면 분리형(기본)이다. 교사·학생 칸을 `teacher`·`student`에 나눠 쓴다.
- 평가 계획표(`evaluation`)는 두 형식 모두 활동표 아래에 붙는다.

입력 형식은 스크립트 상단 설명을 따른다. 요점:
- `title`(맨 위 제목 줄), `topic`(대주제)·`period`(차시), `subtopic`(소주제·쪽수)·`time`(시간), `goals`(학습 목표 목록, 번호 자동), `style`(수업 형태), `prep`(`teacher`·`student` 학습 준비).
- `rows`: 학습 목표 아래에 더할 행. 성취기준, 탐구 질문(또는 학습 문제)을 넣는다. 핵심 아이디어·내용 요소 등 5-1절 항목도 필요하면 같은 방식으로 더한다.
- `stages`: 단계마다 `name`(도입·전개·정리 또는 수업 모형의 단계)과 `steps`. **활동 하나가 한 행**이다. 활동마다 `content`(학습내용), `teacher`(교사), `student`(학생), `materials`(학습자료 및 유의점), `time`(예: "12'")를 쓴다. 통합형은 `content`·`teacher`·`student` 대신 위 초등 항목의 `group`·`activity`·`assess`를 쓴다. 단계 칸은 세로로 합쳐진다.
- `evaluation`: 5-3절 평가 계획표. 평가 요소마다 `element`(평가 요소), `method`(평가 방법), `levels`(상·중·하 기준을 이 순서로), `feedback`(하 수준 학생에게 줄 다음 행동)을 쓴다. 예: `{"element": "입자 운동으로 확산 설명", "method": "활동지", "levels": ["…새 상황에도 같은 설명을 쓴다", "…입자 운동으로 설명한다", "…입자가 움직인다고 말한다"], "feedback": "모형 그림을 순서대로 짚게 한 뒤 짝에게 다시 설명하게 한다"}`. 표는 평가 요소 | 평가 방법 | 평가 기준(상·중·하) | 피드백(하)이다.
  - 3절 설계 순서로 정한 평가 요소를 늘 넣는다. 비운 칸은 `[확인 필요]`로 찍힌다. `evaluation`을 빼면 평가 계획표 없이 활동표까지만 만든다.
  - 교사가 단계 수나 이름을 정했으면 `"evaluation_levels": ["잘함", "보통", "노력 요함"]`처럼 쓰고 `levels`도 그 수만큼 쓴다. 피드백 칸 이름은 마지막 단계를 따른다.
  - 가치·태도처럼 세 단계로 가르지 않는 요소는 `levels`에 한 문장(예: `["자기평가 체크리스트로 확인"]`)만 쓰면 기준 칸이 합쳐진다.
- 칸 안 줄은 `\n`으로 자유롭게 나눈다(줄마다 새 문단). 교사·학생·자료 칸은 "◉ ", "○ ", "- ", "▣ ", "※ " 뒤 글에 맞춰 내어쓴다. 분리형 활동표에는 평가 칸이 없으므로 평가하는 장면의 자료 칸에 `★ 평가: 활동지`처럼 평가 계획표의 방법을 그대로 적는다. 통합형은 평가 칸(`assess`)에 적는다.
- 학습내용 칸은 좁으므로 `"활동 1\n명제\n고르기"`처럼 낱말 단위로 줄을 나눈다.
- 식은 `{{x>4}}`처럼 `{{ }}`로 감싸면 한글 수식이 된다.
- 활동표는 쪽을 넘어 나뉘고 다음 쪽에 머리행이 되풀이된다. 소요시간의 합은 차시 시간과 같아야 한다.

**기본 양식으로 담기 어려울 때** (세안, 공개수업처럼 교사가 기본 양식에 없는 칸(교과 역량 머리칸, 분리형 활동표의 학습 형태·평가 칸, 판서 계획 등)까지 든 지도안을 원할 때만). `scripts/make_hwpx.py`로 표를 직접 짠다. 입력 예시(JSON), 칸 합치기, 열 너비, 표가 쪽을 넘을 때의 규칙은 `references/lesson-plan-wide-form.md`를 따른다.

- **쪽 설정**: `"page": "compact"`는 위아래 여백을 좁혀 한 쪽에 더 담는다. 약안을 A4 2쪽 안에 넣으려면 꼭 쓴다(없으면 `normal`로 위아래 여백이 넓어 3쪽이 되기 쉽다). 여백을 넓게 둘 학교 양식은 `normal`(기본)이다.
- **수식**: 식이 든 글은 `{{x^2+1}}`처럼 `{{ }}`로 감싼다. 쓰는 법은 `references/equations.md`를 따른다.
- 실행: `python scripts/make_hwpx.py 지도안.json 지도안.hwpx`
- 결과물은 한글 hwpx로 낸다. 학교는 워드를 쓰지 않으므로 .docx로 만들지 않고, hwp가 아니라 hwpx로 저장한다.
